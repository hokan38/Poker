# ポーカーGTO解説シリーズ — 動画制作コンテンツ

このディレクトリは、YouTubeシリーズ「ポーカーGTO解説（全30回）」の**制作物**（台本・スライド・メタデータ）を管理する場所です。
リポジトリ本体の Web アプリ（`app/` `components/` `lib/`）とは独立しており、動画コンテンツのみを扱います。

## フォルダ構成

```
content/
├── README.md            ← このファイル（制作ガイド）
├── series-plan.md       ← 全30回のマスタープラン（章立て・各回の狙い）
├── sources/             ← 情報源の基盤（ファクトチェック・出典運用）
│   ├── README.md            … ソーシング基準（裏付けルール）
│   ├── reference-library.md … 精査済みソース集（Tier付き）
│   └── episode-source-map.md… 各回に割り当てる主ソース
└── episodes/
    └── ep01-gto-toha/   ← 第1作
        ├── script.md    ← 収録台本（ナレーション／画面表示／図解指示・尺つき）
        ├── slides.html  ← 録画用スライド（自己完結・オフライン動作）
        ├── metadata.md  ← タイトル案／概要欄／タグ／チャプター／サムネ案
        └── video/       ← Remotionで自動生成する動画版（MP4・日本語ナレーション）
```

各エピソードは `episodes/epNN-スラッグ/` に台本・スライド・メタデータ（＋動画版）で置きます。

## 情報源・ファクトチェック

「本格的なGTO解説」を掲げるため、**主張は必ず裏付けを持つ**ことを前提にします。
専門的・数値的な回ほど厳格に。詳細は **`sources/`** を参照：

- `sources/README.md` … 出典の格付け（Tier）と、各回の裏付けフロー
- `sources/reference-library.md` … 書籍・査読論文・ソルバー・教育サイトの精査済みリスト
- `sources/episode-source-map.md` … 各回で参照する主ソース

原則：**数値（頻度・サイズ・EV・レンジ）はソルバー（Tier 1）で確定し、前提条件を必ず併記**。
導出できる数学は台本内に導出を書く。二次情報だけで意外な主張を断定しない。

## 収録の手順

1. **スライドを開く**：`episodes/epNN-.../slides.html` をブラウザで開く（ダブルクリックでOK。ネット接続不要）。
2. **全画面にする**：ブラウザを全画面表示（F11）にし、スライドを最初のページに戻す。
3. **操作方法**：
   - `→` / `Space` / `PageDown` … 次のスライド
   - `←` / `PageUp` … 前のスライド
   - `F` … このHTML内蔵のフルスクリーン切り替え
   - `Home` / `End` … 最初 / 最後へ
   - 画面右下に「現在ページ / 総ページ」を表示。
4. **録画**：OBS等の画面キャプチャで録画しつつ、`script.md` のナレーションを読む。台本には各スライドの切り替えタイミングを記載。
5. **編集**：撮った音声・映像を編集ソフトへ。`metadata.md` のチャプター（タイムスタンプ）とタイトル/概要欄をYouTubeに転記。

## スライドの仕様

- **外部依存なし**：CDN・フォント・画像をネットから取得しません。オフラインでもレイアウトが崩れません。
- **16:9**：1920×1080 を想定したレスポンシブ。全画面録画に最適。
- **ダークテーマ**：フェルトグリーン＋ゴールドのポーカー配色。長時間視聴でも目が疲れにくい。
- **編集しやすい**：各スライドは `<section class="slide">…</section>` の単位。文言はHTMLを直接編集すれば変えられます。

## 台本の読み方

`script.md` は「スライド番号 → ナレーション → 画面表示メモ」の順で並びます。
- **【ナレーション】**：実際に読み上げる原稿。
- **【画面】**：そのとき映すスライド番号・アニメ・図解の指示。
- **（尺の目安）**：各セクションのおおよその所要時間。合計で本編尺になります。

## 用語・トーンの基準

既存アプリのシステムプロンプト `lib/prompt.ts` に準拠します。
- 「GTO的にバランスを取るため」で終わらせず、必ず「なぜ+EVなのか」をレンジ・エクイティ・ボードの言葉で説明する。
- 3bet / ポラライズ / ブロッカー等の専門用語は**初出時に1行で噛み砕く**。
- 断定しすぎず、頻度（〜%くらい）や状況依存を丁寧に伝える。

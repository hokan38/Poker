# ソーシング基準（台本の裏付けルール）

本シリーズは「本格的なGTO解説」を掲げる。そのため、**主張は必ず裏付けを持つ**ことを制作の前提とする。
このディレクトリはその基盤：

- `reference-library.md` … 精査済みの情報源（格付け Tier 付き）
- `episode-source-map.md` … 各回に割り当てる主ソース
- 各エピソード側 `references.md` … その回で使った出典と、主張→出典の対応

第1回は導入（理論の骨格）で、核心的主張は検証済み・数学的に導出可能なため現状のままでよい。
**より専門的・数値的になる回（第6回以降）ほど、本基準を厳格に適用する。**

---

## 情報源の格付け（Tier）

- **Tier 1（一次）**：ソルバー出力（Pio / GTO Wizard / MonkerSolver / HRC）と査読論文。
  → 特定スポットの**数値**（頻度・サイズ・EV・レンジ）はここでのみ確定する。
- **Tier 2（定評ある理論）**：主要書籍と GTO Wizard 解析ブログ。→ 概念・導出・枠組みの根拠。
- **Tier 3（教育サイト）**：Upswing / Red Chip / SplitSuit 等。→ 説明・図解・導入。数値は Tier 1/2 で裏取り。
- **不可**：出典なしの個人ブログ／フォーラムの体験談／マーケ記事／未検証のAI生成文。

---

## 主張の種類と、必要な裏付け

| 主張の種類 | 例 | 必要な裏付け |
|-----------|-----|-------------|
| 導出可能な数学 | ポットオッズ、MDF=1/(1+s)、α、EV、無差別条件 | **導出を併記**（＋Tier 2で枠組みを引用） |
| 概念・定義 | ポラライズ、ブロッカー、レンジ優位 | Tier 2（書籍／GTO Wizard） |
| 数値・ソルバー結果 | 「BTN の RFI は約X%」「このボードでCベットY%」 | **Tier 1（ソルバー再現）必須**＋設定明記 |
| 歴史・事実 | ICMの由来、"解かれた"の経緯 | 査読論文／一次資料 |

**設定依存の鉄則**：GTOの数値は前提で変わる。台本・`references.md`には
「Cash 100bb 6max, single-raised, board=… , bet sizes=…」のように前提を必ず書く。

---

## 各回の制作フロー（専門回は必須）

1. **草稿**：台本（`lines.json` / `scenes.tsx` / `script.md`）を書く。
2. **主張の洗い出し**：断定している事実・数値・概念を箇条書きにする。
3. **分類**：導出可能／概念／数値ソルバー／歴史 のどれかにタグ付け。
4. **裏付け**：
   - 導出可能 → 導出を書く。
   - 概念 → Tier 2 を引く。
   - 数値 → ソルバーで再現（またはユーザー提供の出力）→ Tier 1。無ければ「目安」と明示し断定しない。
   - 歴史 → 一次資料。
5. **相互確認**：重要・議論のある主張は**2ソース以上**で照合（Web検索可）。
6. **記録**：その回の `references.md` に「主張 → 出典（Tier）」を残し、台本に出典タグを付ける。

## 台本内の出典タグ（軽量記法）

台本のコメントや `references.md` で、主張の末尾に短いタグを付ける：

- `[MPT]` = The Mathematics of Poker
- `[MPTheory]` = Modern Poker Theory (Acevedo)
- `[Janda-App]` / `[Janda-Adv]`
- `[POP1]` / `[POP2]` = Play Optimal Poker
- `[Tipton1]` / `[Tipton2]`
- `[GTOW: 記事名]` = GTO Wizard ブログ
- `[Science2015/2017/2019]` = Cepheus / Libratus / Pluribus
- `[solver: 設定]` = 自前またはユーザー提供のソルバー出力（設定を併記）
- `[derive]` = 台本内に数学的導出あり

例：「ポットベットのブラフは約1/3 `[derive][GTOW: Mathematical Misconceptions]`」

---

## レッドフラグ（避けること）

- ソルバー数値を**設定なし**で断定する（"GTOでは常に〜"）。
- 一つの二次情報だけで新規・意外な主張を断定する。
- 書籍の**ページ番号や引用文**を、確認せずに書く（記憶での精密引用は禁止。必要なら現物・検索で確認）。
- Tier 3 の記事の数値をそのまま数値ソースにする。

---

## この環境でできること

- **Web検索は使える** → 事実確認・書誌・URL確認に常用する。
- **ソルバーは有料** → 数値が要る回は、ユーザーがPio/GTO Wizardで実行し出力を共有 → Tier 1として反映するのが最短で最も確実。

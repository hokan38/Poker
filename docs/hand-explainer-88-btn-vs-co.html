ターンでスペード3枚（モノトーン）になった盤面。8♠8♣はターンでは打てて、リバーでは打てない。 鍵はポラライズと「エクイティの切り離し・押し上げ」——レンジEQがあるだけでは戦略は決まらない。

前提

読む前の物差し

  • 位置COが2.5bbオープン→BTNがコール。CO=攻め手(PFR)でOOP、私(BTN)は受け手だがIP（最後に動ける）。
  • 盤面フロップ2枚・ターンで3枚のスペード。以降は「スペードを1枚持つか」で同じ88でも戦略が変わる（ブロッカー＝相手の該当コンボを減らす手札）。私の手は8♠8♣。
  • 打つ資格Value bet は相手のcallレンジに勝って初めて成立。そしてサイズが大きい（ポラー）ほど、打てるのはナッツ級バリュー＋ブラフだけ——中間の手はチェックに落ちる。この2つが全ストリートの物差し。
  • 数値各ブロックでレンジ全体の%と私の88の答えを分けて示す。EQ（生の勝率）・EV（獲得期待値）・EQR（実現率）は別物。数値はGTO Wizardのソルバー表示値。

なぜチェックなのか

  • Value=callレンジ打つと勝っている手（相手のトラッシュ）は全部降り、負けている手（9・Jヒット、オーバーペア）だけコール。callレンジに負けるのでバリューにならない。
  • ポットコントロール88には多少のショウダウン価値がある。チェックで安く見せ、相手のレンジも広いまま次へ。
  • キャップCOが2枚スペードのボードでチェック＝強い手が上限を切られた（キャップ）状態。BTNは無理に仕掛けず様子を見る。

88はスートで割れる（ブロッカー × プロテクション）

  • ブロッカー8♠は相手の完成フラッシュ／ナッツフラッシュドローのコンボを減らす。だから8♠を持つ88はベット寄り——相手の強い続行手を削れる。
  • 混合／スートスートを持たない88はブロッカー価値がなく、ほぼチェック。混合頻度は手札のスートが決める（下のコンボ内訳）。
  • Protection88はモノトーン盤の脆い（Vulnerable）ワンペア。ターンはまだ引くカードが残るので、相手のオーバーカードやスペード目のEQを否定する価値がある——このプロテクションがリバーでは消えるのが最大の分岐点。

ポラー構造（α / MDF）

ポット100%ベット（b=p）だと、バリュー:ブラフ = (b+p):b = 2:1、相手の最小防御頻度 MDF = p/(b+p) = 50%。 つまり打てるのはナッツ級バリューと、それに見合うブラフだけ。8♠8♣はどちらでもない——だからベットレンジに席が無い。

88の"仕分け"── 値／ブラフ／ブラフキャッチャー

リバーの各ノードで問うのは1つ：「相手のcallレンジに勝つバリューか、SD価値ゼロで使えるブラフか？」どちらでもなければチェック。

  • ポラーポット100%で打つのはA♠T♠などのフラッシュ・ストレート＝ナッツ級＋ブラフだけ。88はその真ん中。
  • 切り離し相手のcallレンジ（フラッシュ・Q以上・ストレート）だけを切り離して見ると、88はほぼ全部に負けている→バリュー不成立。
  • 押し上げ／SD価値一方、相手がチェックで見せる崩れたスペード目・エアには88が勝つ→ショウダウン価値がある→ブラフにも使えない。
  • Protection無しリバーは残りカードが無くプロテクション価値ゼロ。ターンで88を打てた理由がここで消える。
仕分けの結論  8♠8♣ = ブラフキャッチャー（バリューでもブラフでもない）→ チェック
Key idea — EQ ≠ EV ≠ EQR

リバーの生エクイティがほぼ互角でも、IP＋ポラライズなら実現率(EQR)は100%を超え、EVは打ち手側に傾きうる。だから「EQがあるからベット」ではなく、打てるハンド（ナッツ級＋ブラフ）だけがベット、中間の88はチェック。これが切り離し・押し上げの実例。

結果： ショウダウンで相手はTT。88もTTも「役なしのペア」だがTT>88でポットは負け。しかしトレーナー採点は91%＝全ストリート正解。負けたがプレーは完璧。
まとめ

持ち帰る4つ

  • サイズが「どのハンドを打てるか」を決める
    ポット100%（ポラー）はバリュー:ブラフ=2:1で、ナッツ級とブラフだけ。中間の88は席が無い。小さいレンジベットとは別物。
  • Value か否かは"相手のcallレンジ"で判断
    自分の手の強さではなく、ベットにコールしてくる範囲に勝っているか。88はそれに負けているので打てない（切り離し）。
  • 同じ88でもストリートで逆になる
    ターンは8♠ブロッカー＋プロテクションで打てる。リバーはプロテクションが消え、脆いワンペアはただのブラフキャッチャー→チェック。
  • 生EQがほぼ互角でもEQRは100%超になりうる
    IP＋ポラライズで過剰実現できる。EQの数字だけを見て「あるから打つ」としない。結果（TTに負け）と正誤（91%正解）は分けて考える。

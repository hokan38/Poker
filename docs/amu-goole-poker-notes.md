## 1. GTOの基礎的な考え方 / GTO Wizard の位置づけ

### GTOとは何か（記事群の立場）
- **GTO（Game Theory Optimal / ゲーム理論的最適戦略）** とは、相手にエクスプロイト（弱点を突いて搾取されること）されない均衡戦略のこと。ポーカー上達の中心的な学習対象です。
- Amu の立場は「**世間で語られるGTOの約8割は誤り**」というもので、まず正確な概念定義から学び直すことを勧めています（詳細は無料記事「GTOとは何か-誤解と理解-」「-対GTO-」。後者では **MES（Maximum Exploit Strategy／最大搾取戦略）** との関係も扱う）。

### GTOツールとは（Pio vs GTO Wizard）
ポーカーのGTO学習は事実上「GTOツール」に依存します。主要ツールは2種類。

**Pio Solver（計算機タイプ）**
- **買い切り型**のPCインストール型ソフト。自分でレンジ・ベットサイズを指定すると、GTO近似解を「**計算してくれる**」＝本質は計算機。
- 費用感: Proプラン **$475**（約5万円）＋高性能PC（約20万円）で **初期費用30万円程度**。スマホ不可。
- 計算に**最低10分以上**かかり、あらかじめ計算して後日参照する方式。
- **Node Lock機能**: 相手が均衡的でない（非GTO）レンジのとき、どう対応（エクスプロイト）すべきかを計算できる。toy game 作成も可能で、勉強に欠かせないが**使いこなしが難しい**。

**GTO Wizard（図書館タイプ）**
- **サブスク型**のブラウザ型サービス。Wizard が用意したレンジ・ベットサイズの「**計算済み結果を閲覧**」できる＝本質は計算結果の図書館。
- 料金区分: Cash / MTT / Spin / Str+Ante の4つ。各区分に Starter・Premium・Elite があり **Premium以上推奨**。年間契約で **月約$62（約8,000円）**、Elite は **月$134**。
- ブラウザ型で **PC・スマホ両対応**、追加初期費用なし。ボタン押下後 **1秒以下**で結果表示。
- 2023年に solver「RuseAI」を買収し「**WizardAI**」として統合。solver機能も拡張中（現状 Elite プランで制限付き利用可）。

**使い分けの推奨**
- 初心者・大半のプレーヤーは **GTO Wizard を選ぶ**。Pio は持て余しやすく、Node Lock を有効に使うのは難しい。
- **Wizard をベースに使い、疑問が残るスポットだけ Pio で計算し直して理解を深める**のが理想。Range Copy 機能でレンジをそのまま Pio に移せる。
- ソリューションの精度は代表的なもので **0.1〜0.3%**、Simplified（簡略化）系も驚くほど高精度で、標準的スポットでは実用上問題なし。

### GTO Wizard の主要機能（かいつまみ）
- **Study — ハンドレビュー**: ソリューションを選び、レンジ表にカーソルを合わせるとコンボごとのアクション／**EV / EQ / EQR** を参照できる。表示モードは Strategy+EV（基本）/ Strategy / Strategy+EQ / EQR。**選択頻度が極端に低いアクションは計算精度が不十分なことが多く、深追いしない**。
- **Study — EQグラフ（Rangesタブ）**: 縦軸＝そのハンドの相手レンジに対するEQ、横軸＝自分レンジ内でのEQ順位置。**両者のグラフが離れるほど一方のレンジが全体的に強く、CB（継続ベット）が正当化されやすい**。アグレッサー（オリジナル）のグラフが上に来やすい。
- **Study — 集合分析（Report機能、キー「4」）**: 全フロップ（ターンまで対応、**Riverは非対応**）を横に並べ、各ボードのレンジ全体のアクション頻度やEVを棒グラフで俯瞰。Filter で条件（例: モノトーン以外）を絞ると加重平均頻度が見える。**bet頻度の高いボード＝IPのEVが高い**を視覚化できる。
- **Practice — Trainer（GTOと対戦）**: 実戦形式の練習。**Show hints は必ずOFF**（でないと答えが常に表示される）。RNG mode の Low はサイコロで頻度通りのアクションを要求し難易度が上がる。採点は **Best / Correct / Inaccuracy / Wrong / Blunder** の5段階。
- **Practice — Range Builder（塗り絵）**: レンジ表に自分でアクションを塗り、実解と比較して適合率で採点。open レンジや BB defence の暗記に有効。著者は25%刻みで塗り、100%適合を目指して繰り返す。
- **小技**: モバイル版が重い場合は**言語設定を英語にすると大幅に高速化**する。
- **登録の注意**: アフィリエイトURL（`gtowizard.com/p/名前`）を踏むと初回10%割引。アフィリエイト先は**登録時に確定**し、後から変更できない。

## 2. EV と EQ、エクイティの「切り離し」と「押し上げ」

### 用語の整理
- **EV（Expected Value／期待値）**: あるアクションから期待される平均的な利得。
- **EQ（Equity／エクイティ）**: そのハンド／レンジが相手レンジに対して持つ勝率的な取り分。
- **EQR（Equity Realization／エクイティ実現率）**: 持っているEQを実際にどれだけ利益として実現できるかの指標。生のEQと**正味EQ（EQRを加味したもの）**は異なる（詳細は無料記事「EVとEQ」）。

### River における EQ の「切り離し」と「押し上げ」（本テーマの核心）
中〜上級者向け。GTO Wizard の 6max 100bb 50nl 均衡を題材にした River 戦略の理論です。中心メッセージは **「River でレンジEQがあるだけでは戦略は決まらない。切り離しと押し上げという補正を経て初めて均衡が理解できる」**。

**メインケースの設定**
- プリフロップ: BTN オープン、BB コール。
- フロップ Q-9-5: BTN が 50% CB → BB コール。
- ターン Q（ペアボード化）: BTN が 50% ダブルバレル → BB が XR（チェックレイズ）。
- リバー 8c: BB はどのレンジをどのサイズでベットすべきか？
- BB のブラフ素材だった FD/SD（フラッシュ／ストレートドロー）がリバーで全て完成し、BB はほぼ全ハンドが **Trips+（Qのトリップス以上）** に強化される。
- 多くの人は「レンジEQがあるからレンジベット」と考えるが、**実際の解は低頻度・極小ベット、ほとんどがチェック**。この直感とのズレを説明するのが記事の目的。

**なぜ River は特殊か（Case1 との対比）**
- フロップ・ターンは**ボードが未完成で相手のトラッシュ（ゴミ手）も一定のEQを持つ**ため、ベットでそのEQを放棄（フォールド）させる価値があり、レンジベットが機能する（例: K-K-5 で UTG のレンジEQが63%超なら全レンジ33%ベット）。
- **River はEQが確定し、トラッシュのEQがほぼ0**。降ろさせる価値がないので、EQを根拠にしたレンジベットは無意味になる。

**EQの切り離し（セパレーション）**
- River で相手は真0に近いトラッシュ帯を**無抵抗で捨てる**（どうせ降りる、という心構えで対抗してくる）。
- したがって相手レンジからそのトラッシュを除外し、実際に抵抗してくる「**拮抗レンジ**」だけを相手として想定し直す。これにより相手レンジのEQ下限が引き上げられる。この修正後の相手レンジグラフを記事では **Figure1** と呼ぶ。

**EQの押し上げ（レンジ強化の補正）**
- 自分のレンジEQを「相手の全レンジ」基準で見ると、相手のトラッシュ帯が自分の**見かけEQを不当に高く押し上げている**。
- しかしそのトラッシュは River で降りるので、本当に戦うべきは拮抗レンジ。拮抗レンジ基準で測り直すと、**自分のEQグラフはこの押し上げ分だけ下降する**。修正後の自EQグラフを **Figure2** と呼ぶ。
- 例: 見かけEQ60%超の Ahit がブロックベットしないのは、「相手の拮抗レンジに対してはそこまでのEQがない」から。

**帰着する構造**
- 補正後の状況はしばしば **01（ゼロワン）ゲーム**（0〜1の乱数でハンド強度を表すトイゲーム。EQの高さがベットサイズに単調対応し、最上位はトラップ、最下位はブラフ、中間はチェックまたはEQに応じた固定サイズ）に帰着する。
- トラッシュが消滅してレンジが Trips+ に強化されるケースは、片方が **ポーラ（バリューとブラフの二極）レンジ**を持つ **AKQ ゲーム**構造になる。**誰がポーラ側かでベット主体か否かが決まり、同じ「レンジEQあり」でも戦略が対照的**になり得る。

| ケース | 発生要件 | 補正後モデル |
|---|---|---|
| Case3 | ターン時点のレンジEQをリバーへ持ち込み | 01 ゲーム |
| Case4（亜形ドンクジャム） | リバーでドローが完成しトラッシュが消滅 | OOP ポーラ AKQ ゲーム |
| Main Case | リバーでドローが完成しトラッシュが消滅 | IP ポーラ AKQ ゲーム |

> 補足: 「補正後モデル」欄の OOP／IP は、補正後に**ポーラ（バリュー＋ブラフの二極）レンジを持ってベット主体になる側**を指す。Main Case では BB（=OOP）のレンジが Trips+ に凝縮して均一化するため、ポーラ側は相対的に弱いハンドまで残る BTN（=IP）になる。Case4 は逆に OOP がポーラ側で、その OOP がドンクジャムを実行する。

> 余談: ターンでレンジEQを持ち込むこと自体はGTO均衡では稀。ターンにレンジEQがあれば通常はレンジベットを採用する。

## 3. ベットサイズの基礎

「bet sizeの第一歩」の要点。核心は **「打ってはいけないサイズが存在するので、それを避けてbetに意味を持たせる」**。

### pot% で考える
- betの割に合うかは**絶対金額ではなく pot%（potに対する比率）で決まる**。相手側から見れば、pot% によって call に必要なEQが決まる。
- 具体例:
  - **Case1**: pot 1000点に500点bet → 500点賭けて2000点勝負＝**4倍の賭け**、pot% = 50%。
  - **Case2**: pot 10000点に500点bet → 500点賭けて11000点勝負＝**22倍の賭け**、pot% = 5%（同じ金額でも割がいい）。
  - **Case3**: pot 10000点に5000点bet → 結局**4倍の賭け**でCase1と同じオッズ、pot% = 50%。
- pot% が低いほど弱いハンドでも call の期待値が合い、高いほど強いハンドで守る必要が出る。
- **代表的サイズ**: 33% / 75% / 100% / 150% / All-in。中間が欲しければ50%等を打つ。このサイズ選定がスキル。
- リーク注意: 「大サイズ＝ブラフ、小サイズ＝バリュー」と決めつけて大サイズに沢山callし小サイズに降りすぎるのは、Exploit にはなり得ても**均衡的には誤り**。

### Value bet は callレンジに勝っていて初めて成立
- **Value bet の可否は「自分のハンドの強さ」ではなく「相手のcallレンジに勝っているか」で判断する。** 自分が強いことは十分条件ではない。
- 教訓ハンド: BB の Qc9c（2ペア）が Turn で 125%、River で 150% と打ちすぎ、相手 T7 の上の2ペアに即callされて負け。Turn 時点で Q9 のEQは70%あったが、**50%以上のEQ＝Value betすべき、ではない**。打つと相手は弱いハンドを捨て、残る callレンジが強化される。その強化されたレンジと戦って勝てなければ Value にならない。

### Elasticity（弾力性）
- **bet size によって相手の抵抗（call）レンジは弾力的に変化し、サイズが大きいほど残るcallレンジは強くなる。**
- 均衡での目安（相手が弱いハンドを捨てる頻度）:
  - **50% bet** → 弱いハンドから **40%** を捨てる
  - **75% bet** → **50%** を捨てる
  - **125% bet** → **60%** を捨てる
- **禁忌級のミス**: ある程度強いハンドを、打つことで Value でなくなる大きすぎるサイズで打つこと。

### Small bet と Protection
- **33%以下**を small と呼ぶことが多い（実戦は 10/20/25/33%）。初心者はまず「small = 33%」でよい。
- small bet は相手の降り頻度がそこまで高くならず、レンジが極端に強化されない → **「打ってはいけないサイズ」になりにくい**。
- **Flop/Turn の 33% は、あたかもチェックするかのようにどんなハンドで打ってもよい**（強い手でも弱い手でも）。弱い相手を安く降ろすこと自体に **Protection（プロテクション）** の価値がある（降ろした相手には捲り目があった）。
- **River には Protection がない**ため、しっかり Value か Bluff かを厳密に判断する。

### レンジ全体でサイズを設計する（発展）
- River のハンドランク例と打てるサイズの目安:
  - A（上位20%）: 125%含むお好きなサイズ
  - B（20〜40%）: 50%や75%まで
  - C（40〜60%）: 50%や33%程度
  - D（60〜80%）: betできない
  - E（下位20%）: bluff bet
- よくあるリーク: 「33%を打ったらCランクしか出てこない」構築。すると相手はBランク以上でNuts級扱いになり搾取される。
- 正しい構築: **すべてのbetサイズに「より大きなサイズも打てる強いハンド」と「bluffハンド」の両方を用意する**。
- **最重要**: 自分のハンドを見る前に、そのスポットで打ちうる**全betサイズの集合を意識し、レンジ全体で戦略を決める**。

> 関連: この記事は「Range bet と Polar bet の違い」を扱う位置づけでもあります（詳細は中級記事「ポラライズ」「純粋戦略と混合戦略」、上級記事「Geometric Betsize（幾何級数的bet）」）。**Geometric Betsize** は、マルチストリートの AKQ game でポットを幾何級数的に膨らませるベットサイズの考え方で、ポラライズ時の重要概念です（有料部分に導出）。

## 4. 初心者が押さえるべき基本（"超"初心者講習の要点）

**100bb持ちのキャッシュゲーム**を想定。著者は初心者が迷わず再現性高く・舐められずプレーできるよう、あえて断定的な指針（例外は多い）を提示しています。

### ポジション用語
- **UTG（Under The Gun）**: SB・BBの次で最初にアクション。
- **CO（カットオフ）**: BTNの前。
- **BTN（ボタン）**: SBの前。フロップ以降は必ず最後にアクションできる。

### 10ポイント総括
1. **BB・BTN以外はレイズで参加**。参加人数が増えるほど勝率が下がる（**AAでも5人で約50%**）。コール参加で「大人数のじゃんけん」にしない。
2. **BTN・BBはopenに対してコールOK**。BTNは位置的優位、BBは既にブラインドを払いclose（後ろにアクションする人がいない）できるため。
3. **リンプ（最低額コール参加）をしない**。相手がリンプしたら、**リンパーの人数分の額を通常open額に上乗せ**してopenする（例: BB=10でリンパー2人 → 通常30 + 20 = **50でopen**）。
4. **3betに横から（コールドコール）参加しない**。
5. **レイズ額は基本3倍**。詳細は下記サイジング。
6. **フロップ以降のbetはpotを把握して {33%（必須）, 75%, 100%, 150%, All-in} から選ぶ**。「かなり強い or かなり弱い→大きく」「ちょっと強い or ちょっと弱い→小さく」（ポラライズの発想）。
7. **openレンジ表に従う**（Range Painter の色分け。赤=常にopen / 緑=条件付き / 青=常に降りる）。オフスートは絞り、後ろの人数が多いほど絞る。**UTGでは緑は全て降りてよい**。
8. **3bet関連レンジに従う**（赤=All-inまでレイズ継続可 / 緑=3betする or 3betにコール / 青=降りる）。
9. **オリジナルまでcheckで回し、ドンクベットをしない。CBは高頻度（50〜100%）で打つ**。
10. **「ナッツから考える」信念を持ち、betはボードに対して行う**。

### ベットサイジングの詳細
- **Open額**: SBからは3倍、その他は2.5倍。
- **3bet額**: OOP（SB・BB）からは4倍、IPからは3倍。
- **4bet額**: 2〜2.5倍。
- 具体例（SB5-BB10）: open=30、3bet=90（openの3倍）。

### オリジナルレイザーとフロップ以降
- **オリジナルレイザー**: 前ストリートで最後にレイズした人＝最強ハンドの可能性を主張した人。
- アクション順は **OOP（不利な位置）が先、IP（有利な位置）が後**。
- **ドンクベット**（オリジナルがアクションする前にOOP側から先打ちすること、「馬鹿のbet」の意）は**しない**。OOPにプレーヤーがいればオリジナルまで check で回す。
- **CB（コンティニュエーションベット）**: オリジナルが次のストリートで継続して打つベット。非常に強力で **50〜100%の高頻度**で打ってよい。

### ナッツから考える
1. ボードで作れる最強ハンド（**ナッツ**）を考える。
2. セカンドナッツ、その次…と順序付ける。
3. 自分のハンドが上から何番目かを判定。
4. リバーでナッツを持っていればアグレッシブに。
- **betはハンド単体でなくボードに対して行う**。例: ボード 7c8c9c（フラッシュ・ストレートが完成しやすい）でのAAは、K84r（レインボー）でのAAより価値が低い。

### EVpoker と 快楽poker
- **EVpoker**: 期待値を追求し運の要素を極力排除。ドローへの対応で「そのコールは利益になるか」を確認し、負けるコールで相手に利益を与えない。長期的には実力で利益が決まる。**記事はこちらを推奨**。
- **快楽poker**: 楽しさ優先。合理的でない判断（引けたら大きいpotが取れる快楽）を好み、結果が運に依存する。
- 見分け例: 大きめのbetを打たれたフラッシュドローの場面で、EV的に降りるか快楽的にコールするか。

> 使用ツール: Range Painter（ぱいにゃんさん開発）。参考サイト: 「ポーカー道」。

## 5. 用語集（グロッサリー）

- **GTO**: ゲーム理論的最適戦略。相手にエクスプロイトされない均衡戦略。
- **Exploit（エクスプロイト）**: 相手の傾向・弱点を突いて利益を最大化する考え方。
- **MES（Maximum Exploit Strategy）**: 相手を最大限に搾取する戦略。
- **EV（期待値）**: あるアクションから期待される平均的な利得。
- **EQ（エクイティ）**: そのハンド／レンジが相手レンジに対して持つ勝率的取り分。
- **EQR（エクイティ実現率）**: 持っているEQを実際にどれだけ利益化できるかの指標。正味EQ。
- **レンジEQ**: レンジ全体の対相手EQ。Riverでは切り離し・押し上げ補正後のEQで判断する必要がある。
- **拮抗レンジ**: Riverのベットに対し降りずに抵抗してくる、トラッシュを切り離した後の相手レンジ。真のEQ計算はこれに対して行う。
- **EQの切り離し（セパレーション）**: 相手の真0近いトラッシュを無抵抗で降りると想定し、レンジから除外する補正。相手レンジのEQ下限が上がる（Figure1）。
- **EQの押し上げ**: 見かけEQが相手トラッシュに底上げされている分を、拮抗レンジ基準で測り直して下方修正すること（Figure2）。
- **01（ゼロワン）ゲーム**: 0〜1の乱数でハンド強度を表すトイゲーム。EQとベットサイズが単調対応する均衡モデル。
- **AKQ game / toy game**: 単純化したモデルゲーム。理論をここから学び実践へ落とし込む。
- **ポラライズ（ポーラ）**: レンジをバリューとブラフの二極に構成すること。単なる「大きなbet」の意味ではない。
- **トラップ**: 01ゲームで最上位（Nuts）をあえて各ベットサイズに混ぜて残すこと。
- **マンハッタングラフ**: ハンドをEQ順に並べて戦略頻度を可視化したグラフ。
- **インディファレント**: 降りてもコールしてもEVが等しい無差別点。
- **pot% bet**: betをpotに対する比率で決める考え方。オッズとcallに必要なEQを決定する。
- **Value bet**: 相手のcallレンジに対してなお勝っていて初めて成立するbet。
- **bluff bet**: 相手を即座に降ろすことを目的とするbet。
- **Elasticity（弾力性）**: bet sizeで相手の抵抗レンジの強さが弾力的に変わる性質。大きいほど残るcallレンジが強い。
- **Protection（プロテクション）**: Flop/Turnで捲り目のある相手を安く降ろすこと自体の価値。Riverには存在しない。
- **CB（コンティニュエーションベット／継続ベット）**: プリフロップのアグレッサーがフロップで続けて打つベット。50〜100%の高頻度で可。
- **DB（ダブルバレル）**: ターンで続けて打つ2発目のベット。
- **XR（チェックレイズ）**: チェック後、相手のベットにレイズすること。
- **ドンクベット**: オリジナルがアクションする前にOOP側から先打ちすること。初心者は禁止。
- **ドンクジャム**: OOPがリードでオールインするドンクベットのオールイン版。
- **オリジナル（オリジナルレイザー）**: 前ストリートで最後にレイズした人。
- **ナッツ**: そのボードで現状作れる最強のハンド。
- **リンプ（Limp）**: プリフロップで最低額をコールして参加すること。本記事群では禁止行為。
- **OOP / IP**: OOP（Out Of Position）は先にアクションする不利な位置、IP（In Position）は後にアクションする有利な位置。
- **3bet / 4bet**: 3bet=openへのリレイズ、4bet=その再リレイズ。
- **レンジベット**: レンジ全体で同一サイズを打つ戦略。Flop/Turnで高レンジEQ時に採用、Riverでは通常不採用。
- **純粋戦略 / 混合戦略**: 常に同一アクション（純粋）と、複数アクションを一定頻度で混ぜる（混合）。ソルバーでbet優位でも一定頻度でcheckが混ざる。
- **Robust Equity（EQの堅牢性）**: ボード変化に対して崩れにくい堅牢なエクイティの概念。
- **Geometric Betsize（幾何級数的bet）**: マルチストリートでポットを幾何級数的に膨らませるベットサイズ。
- **FD / SD / OESD**: フラッシュドロー / ストレートドロー / オープンエンドストレートドロー。
- **SPR / SRP**: SPR=スタックポットレシオ、SRP=シングルレイズドポット（PFが1レイズで進んだポット）。
- **Ante**: MTT等で全員が事前に払う強制ベット。あるとレンジが全く異なり、Cashとは別ソリューション（別課金）。
- **BTN / SB / BB / UTG / CO**: ポジション。UTG=SB/BBの次、CO=BTNの前、BTN=SBの前で最後にアクション。
- **Node（ノード）**: ゲームツリー上の意思決定地点。選択頻度が極端に低いnodeは計算精度が不十分で深追い非推奨。
- **Node Lock**: 相手が非均衡のとき自分がどう対応すべきかを計算する機能。
- **RNG mode**: Trainerで頻度通りのアクションを求めるモード。Lowはサイコロが表示され難易度が高い。
- **Blunder / Inaccuracy**: Trainerの採点区分。BlunderはEVloss特大、InaccuracyはWizard上3.5%以下の軽微なズレ。
- **Simplified**: ベットサイズ等を簡略化した解。標準ソリューションの精度は0.1〜0.3%で高精度。

## 6. 実戦チェックリスト（actionable takeaways）

### プリフロップ参加・サイジング
- [ ] 参加するならレイズで入る。**BBとBTN以外はコール参加・リンプをしない**。
- [ ] 相手がリンプしたら、リンパーの人数分の額を通常open額に**上乗せ**してopenする。
- [ ] openは2.5〜3倍、3betはOOP4倍/IP3倍、4betは2〜2.5倍を基本にする。
- [ ] 3betに横からコールしない。
- [ ] 色分けレンジ表に従い、赤は必ずopen、青は必ず降りる。UTGでは緑も降りて絞る。

### フロップ以降
- [ ] OOPはオリジナルまでcheckで回し、ドンクベットは打たない。オリジナルはCBを高頻度で打つ。
- [ ] アクション前に必ずナッツから強さを並べ、自分が上から何番目かを確認する。betはハンドでなくボードに対して行う。
- [ ] ドローには「そのコールは利益になるか」を確認し、快楽で負けるコールをしない（EVpoker志向）。

### ベットサイズ
- [ ] betは絶対金額ではなくpot%（potに対する比率）で決める。
- [ ] Value betの可否は「自分のハンドの強さ」ではなく「相手のcallレンジに勝っているか」で判断する。
- [ ] ある程度強いハンドを、打つことでValueでなくなる大きすぎるサイズで打たない（禁忌級のミス）。
- [ ] 目安を覚える: **50%betで相手は弱いハンド40%、75%で50%、125%で60%を捨てる**。
- [ ] Flop/Turnの33% small betはprotection効果もあり、強弱どんなハンドでもチェックのように打ってよい。
- [ ] Riverはprotectionが効かないので、Value/Bluffを厳密に判断する。
- [ ] 自分のハンドを見る前に、そのスポットで打ちうる全betサイズを想定し、各サイズに強いハンドとbluffの両方を配置してレンジ全体で戦略を組む。
- [ ] 「大サイズ=ブラフ、小サイズ=value」と決めつけて大サイズにcallし小サイズに降りすぎるのは均衡的に誤り。

### River（切り離し・押し上げ）
- [ ] RiverでレンジEQが高くても即ベットと考えない。多くの解は低頻度・極小ベットかチェック主体。
- [ ] 相手のトラッシュ帯はRiverでは無抵抗で降りると想定し、切り離して「拮抗レンジ」だけを相手にEVを測る。
- [ ] 見かけEQは相手トラッシュに押し上げられている。拮抗レンジに対する真のEQはそれより低いと補正する。
- [ ] EQ60%級でもブロックベットしないことがある。相手が拮抗レンジのみならそのEQでは足りないため。
- [ ] Riverカードでドローが完成しトラッシュが消えたケースはAKQゲーム（ポーラ vs 拮抗）に帰着。自分がポーラ側かで戦略が真逆になる。

### 学習・ツール運用
- [ ] 初心者・大半はPioよりGTO Wizardを選ぶ。プランはPremium以上。CashとMTT（Ante）は別課金。
- [ ] 登録時にアフィリエイトURL（gtowizard.com/p/名前）を踏むと初回10%割引（登録時に確定、後から変更不可）。
- [ ] ハンドレビューでは選択頻度が極端に低いアクションを深追いしない。均衡の傾向理解に使う。
- [ ] 集合分析（Report、キー4）とFilterでボード性質ごとの戦略傾向を俯瞰し、EV表示でアグレッサー有利ボードを掴む。
- [ ] TrainerではShow hintsを必ずOFF。RNG mode Lowで頻度まで含めて練習する。
- [ ] Range Builderでopenレンジ・BB defenceを25%刻みで繰り返し塗り、100%適合を目指して暗記する。
- [ ] スマホが重い場合は言語を英語にして高速化する。
- [ ] Wizardをベースに使い、疑問が残るスポットだけPioで計算し直す（Range Copyでレンジを移せる）。
- [ ] GTOは世間の理解の約8割が誤りとされるため、まず正確な概念定義から学び直す。
- [ ] EQは生の数値だけでなくEQR（実現率）を加味した正味EQで捉える。

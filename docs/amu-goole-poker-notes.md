## GTOの基礎

（記事: 「はじめに」「GTOとは何か -誤解と理解-」「GTOとは何か -対GTO-」）

### GTOとは何か

- **GTO = Game Theory Optimal（ゲーム理論的最適戦略）**。ポーカーというゲームにおいて、ゲーム理論から「最適である」と考えられた戦略を、コンピュータが近似的に計算したもの。
- Amu は「**世間で語られるGTOの多くは誤り**」という立場で、まず正確な概念定義から学び直すことを勧めています。

### ポーカーが持つ3つの性質

ポーカーは次の3性質を同時に持ちます。まとめると **「非協力型ゼロサム不完全情報ゲーム」**。

1. **非協力ゲーム**: 各プレイヤーは自分のチップ（利得）を最大化し、協力はしない。1人を狙って他プレイヤーがカード情報を共有する、といったことは起きない。
2. **ゼロサムゲーム**: （レーキ等がなければ）全プレイヤーの合計チップは不変。誰かが勝てば誰かが負け、**全員の期待値の和は0**。重要な帰結として **GTO を取ったときのEVは0**（相手もGTOなら戦略が同じで、理論上どちらも得をしない）。
3. **不完全情報ゲーム**: 相手と自分の手札が異なり、情報が非対称。将棋・囲碁と違い、相手がopenしても手が何か・どんな戦略なのかは分からない。得られるのは「相手がopenした」という事実のみ。だからこそ、**相手がどんな戦略でも自分のEVがマイナスにならないよう戦略を立てる**必要がある。
   - 補足: 「不完全情報」≠「不完備情報」。ポーカーのルール自体は全員に等しく与えられている（不完全なのは各自の私的な手札情報）。

### じゃんけんによる直感的説明

同じ「非協力型ゼロサム不完全情報ゲーム」であるじゃんけんで説明できます（勝者はチップ1枚獲得、敗者は1枚喪失）。

- **最適戦術＝均等戦略（グー33%/チョキ33%/パー33%）**。これを「戦略S」と呼ぶ。均等に出さないと、上手い相手に搾取される。
- **exploit（搾取）の例**:
  - 相手がグー100% → こちらパー100%で100%勝利、EV = +1。
  - 相手がグー40%/チョキ30%/パー30% → こちらパー100%なら、+0.4（勝）-0.3（負）±0（あいこ）= **EV +0.1**。ゼロサムなので相手は -0.1。
- 一般化: 偏った相手には、高頻度で出す手に勝つ手を出し続けることでEVをプラスにできる。これがポーカーで言う **exploit（搾取）**。

### GTO戦略の定義

- 均等戦略Sは、相手のどんな戦略に対してもEVがマイナスにならない。2人ゼロサムゲームには、相手の全戦略に対して期待値をマイナスにしない戦略が存在し、それが **GTO戦略**。
- したがって **GTO戦略とは exploit されない戦略**。GTO が保証するEVは **0**（相手もGTOなら差はつかない）。

### exploit / adjust / MES

- 相手の戦略が分かっており、それがGTOでないなら、**adjust（適応）した exploit戦略の方が一般に期待値が高い**（グー100%の相手にはパー100%でEV=1）。
- ただし exploit戦略には穴ができ、その exploit に対する exploit（チョキ100%）で今度はこちらが搾取され返す。この読み合いの層が **メタゲーム**。
- **MES（Maximally Exploitative Strategy／最大搾取戦略）**: exploit戦略のうち最もEVが高いもの＝相手戦略へのベストレスポンス。

### 命題「GTOに対するMESはGTO」と対GTO

- **核心命題: 「GTO に対する MES は GTO である」**。GTO相手に最大限搾取しようとしても、たどり着く最適応答はGTO自身になる。
- この命題から、実戦での「脳内GTO」の組み立て方が導かれる:
  > **「相手が GTO 戦略を取っていると仮定し、その GTO に対する MES を考える」** → 出来上がる戦略は結局 GTO になり、決して exploit されない。
- 帰結: **相手が実際にはGTOでなくても、GTOを仮想敵に最適応答を詰めておけば、自分は搾取されない安全な戦略を持てる**。だから **GTO vs GTO の研究には価値がある**。
- よくある批判「相手がGTOでないのにGTOだと思い込むと痛い目を見る」は**誤り**。誤った仮定（相手をGTOと見なす）でMESを組んでも出来上がるのはGTOなので、搾取はされない（取りこぼす＝EVを最大化しきれないだけ）。

### GTOは至高ではないが、exploitの良否を測る基準

- 著者は **「GTO戦略が至高」とは主張していない**。むしろ **「exploit戦略ないしMESが至高」** と考えている。
- ただし (a) 相手戦略を正しく認識し、(b) それへのMESを構築し、(c) 相手の adjust に反応してメタゲームを制する——この能力は **GTO学習より遥かに難しい**。
- exploitの落とし穴: exploitを語る者がGTOを最低限理解していなければ、その戦略が本当にGTOより高EVでカウンターされないかを**判断できない**。**GTOは exploit の良し悪しを測る「ものさし」**になる。
- 実戦の指針: 相手不明→GTO寄せで搾取されない土台を作り、逸脱が明確に見えたところだけexploitへ振る。**「GTOに比べ、（MESに対する）EVlossが少なく再現性のある戦略を学ぶことは非常に有益」**。

> 参考ツール（「はじめに」で言及）: 連載では実践応用のため **solver+**（piosolverの代表的計算結果を保存したアプリ）を基にGTOを考える。100bb持ちのHUで有用でライブ中にスマホで確認できるが、ノードロック不可・スクイーズ/リンプ非対応・betサイズが check/30%/70%/100% 中心という制約がある。

## 純粋戦略と混合戦略

（記事: 「純粋戦略と混合戦略」。中級者〜上級者向け）

### 定義とNashの定理

- **混合戦略**: 「2種類以上の戦略から、確率で戦略を選択する方法」。例: UTG-6maxのopenレンジ下限に「中途半端に色がついたハンド」があるのは、その比率でのみopenする＝混合戦略。
- **純粋戦略**: 1つの戦略を確率100%で選ぶ方法。
- **Nashの定理**（ブラウアーの不動点定理から導かれる）: 「混合戦略を許せば基本的なゲームはNash均衡をもつ」。Nash均衡の存在は混合戦略を許すことで担保される。

### Nash均衡とGTOの関係

- **Nash均衡**: ゼロサムゲームで、各プレーヤーが自分の戦略だけを変えてもEVが向上しない戦略の組み合わせ。
- ポイント:
  1. Nash均衡は「戦略の組」に対する言葉。相手がGTOを取らないとき、自分がGTOでもそれはNash均衡ではない。
  2. 2人ともがGTOを取るとき、Nash均衡が成立する。
  3. GTO戦略はNash均衡から来ており、Nash均衡は混合戦略によって担保されている。

### インディファレンス（無差別）— 混合される各アクションのEVは等しい

- **原則: 混合戦略における各アクションのEVは必ず同じ**（＝無差別、インディファレント）。
- 例: UTGの55で open と fold を混ぜているなら、その2つのEVは等しい。
- **論証（背理法）**: もし一方のEVが高ければ、それを高頻度で取る「GTO改戦略」が元のGTOより高EVになり、GTOがMES（それ以上改善できない最善応答）であるという前提に矛盾する。よって混ぜられる各アクションのEVは等しい。
- **ソルバーで bet 優位でも一定頻度で check が混ざる理由**: 複数アクションが混合される＝それらのEVが等しい（無差別）状態だから。あるアクションが厳密に優位ならソルバーはそれを100%選ぶ（純粋戦略化）。混合が出る＝均衡上でEVが同点で、**比率は相手を無差別化するために決まる**。

### なぜ混ぜるのか — 混合を守ることが被Exploit耐性

- GTOには2つの性質が同居する: ①GTOはGTOに対するMES、②GTOはExploitされない戦略。
- この2性質を両立させる秘密が混合戦略。**「複雑な混合比率を守ることでGTOはExploitされない戦略となっている」**。EVが同じでも純粋戦略に崩さず混ぜるのは、混合比率を守ることが被Exploit耐性の源泉だから。

### 実戦への応用（3状況）

1. **GTO的プレーヤーと弱いプレーヤーが隣同士**: 弱い相手と多くぶつかりたいなら、混合ハンドを全て100%参加にする。混合比率は「間違い」だが混ぜる各アクションはEVが同じなので、GTOマシン相手にEVlossはゼロ、かつ弱者との対戦機会が増える。
2. **相手が純粋戦略を大きく間違えている／読めない**: 焦ってExploitしなくてよい。「相手が純粋戦略をミスして失ったEVは、こちらがGTOを取っているだけで全て入ってくる」。
3. **相手が極めてGTO的だが混合比率にリークがある**: ここはアグレッシブにExploitすべき。相手が混合比率のリークを抱えているのにこちらがGTOのままではEVは変わらない。上手いプレーヤー同士の勝負どころ。

### 乱数化（混合比率を守るコツ）

- 前回のアクションと今回のアクションは**独立に決める**必要がある。推奨される乱数の取り方:
  - 時計の秒針の位置 / 目に入った数字の下一桁 / 適当に思い浮かべた数字を演算した後の割り算の余り。
  - できるだけ簡単に乱数が取れる方法を事前に決めておく。
- 実戦補足: Exploit戦略を適切に立てられる相手はほとんどいないため、混合比率を厳密に守る必要性は実はそこまで高くない。ただしGTO相手には純粋戦略のミスをしないこと。Exploitする際は、まず混合比率を変えることが重要。

## EVとEQ：期待値とエクイティ

（記事: 「EVとEQ」）

### EVは頭の中で計算できない

- **EV = Expected Value（期待値）** = 将来的に獲得できる平均的なチップ量。ポーカーではEVを最大化するのが最重要。
- しかし **EVは暗算できない**。難点は「相手の戦略が分からないから」ではなく、**相手の戦略がGTOと完全に同じでもEV計算が複雑すぎる**から。
- ではcall/fold/raiseをどう決めるか → **EQとOddsを使う**。

### 大原則とEQ・Oddsの式

> 役の強さ自体に価値はなく、**相手より強い役を完成させていることだけ**がpotを取れるかに関与する。

- **EQ（Equity／エクイティ）** = チョップ（引分）まで考慮した勝率。

$$EQ = 勝利確率 + \frac{チョップ確率}{2}$$

- **Odds（オッズ）** = 勝ったときの見返りを数で表したもの。

$$Odds = \frac{勝利時に得るチップ量}{新たに危険に晒すチップ量}$$

- **必要勝率（callに必要なEQ）**:

$$必要勝率 = \frac{1}{Odds}$$

- **判定基準**:

$$EQ > \frac{1}{Odds} \;\Rightarrow\; call が正当化される$$

### 具体例A: リバーのAトリップス vs potサイズオールイン

- 自分: Aのトリップス完成。相手レンジ: フルハウス50% / Aのトリップス20%（キッカー負けなくチョップ）/ ゴミ手30%。相手から pot ピッタリの 50bb オールイン。
- **EQ** = 30%（ゴミ手に完勝）+ ½×20%（トリップスはチョップ）= **40%**。
- **Odds** = 得られる (pot50 + bet50 + call50 = 150) ÷ 危険 (50) = **3**。必要勝率 = 1/3 = **33%**。
- 判定: EQ 40% > 33% → **callすべき**。EQが50%なくてもcallは正当化される（40%なら6割負けるがそれでよい）。
- 要点: **Oddsは常に計算できる。EQさえ分かればcall/foldを大きく誤らない**。

### EQ実現率（Equity Realization, EQR）

問い: EQが必要勝率以上なら必ずcallすべきか？ → 複雑。鍵は **EQ実現率**。生のEQと**正味EQ（EQRを加味）**は異なる。

**具体例B: A♥5♥（ナッツフラッシュドロー）**

- BTNからBBの3betにcall。フロップ **K♥J♥8♠** でナッツFD完成。pot 22.5bb に 20.25bb bet。
- GTOでのA5sのEQ = **46.8%**。Odds = (20.25×2 + 22.5)/20.25 = **3.11**（≈3pot/pot=3）、必要勝率 = **32.2%**。EQ 46.8% > 32.2% → **flopはcall**。
- **しかしターンで状況が変わる**: call後pot 63bb、残スタック 68.75bb。ターン 9♣（ドロー完成せず）、相手がpot超えオールイン。このオールインへのA5sのEQ = **23.5%**。Odds = (68.75×2 + 63)/68.75 = **2.92** → 必要勝率 **34.2%**。EQ 23.5% < 34.2% → **fold**。このとき23.5%のEQを放棄する。
- **核心**: flop時点で見込んだEQの一部をturnで放棄している。**現状のEQを全て実現できるのは、直ちにAll-inを選択した場合のみ**。
- **インプライドオッズ**: 逆に、ターンで♥が落ちればナッツ完成で相手から追加チップを取れる → flop時点のOddsは実際より良くなる。この将来的に予測されるOddsのこと。
- 結論: 実戦でEQとOddsだけでcall判断するのは困難で、EQ実現率やインプライドオッズを考慮する必要がある。**ただしAll-in勝負では必ず全EQが保証される**。

### EQを算出すべき3つの場面

1. **リバー**: 内部的に勝敗確定済み。相手のAll-inレンジに対しEQが必要勝率以上かだけが重要。EQ計算力より**相手のAll-inレンジを正しく見積もる力**（＝GTO学習）に比重。
2. **プリフロップ**: 相手のGTOレンジを覚えるのが他より易しい。各ハンドが相手のハンド/レンジにどれくらい勝率を持つか知ると有益（知らないと「Oddsに合うのにfold」して大損）。ツール例: iOSアプリ「Odds Calculator」。
3. **ナッツ級ドロー**: 引ければほぼ勝ち確定。「何%で完成？」を2倍4倍の法則で求める。

### 2倍4倍の法則

- **アウツ**: 相手をまくるのに必要なカード（枚数）。実戦ではフラッシュドローのアウツ＝同スートの枚数を指すことが多い。

$$1枚が開かれる時、それがアウツの確率 = アウツ枚数 \times 2\%$$
$$2枚が開かれる時、1枚以上アウツの確率 = アウツ枚数 \times 4\%$$

- 検証（A♥5♥、K♥J♥8♠、アウツ12枚: 同色8枚 + A 3枚 + …）:
  - Flop All-in時EQ: 12×4 = **48%程度**（GTO実値46.8%）。
  - Turn All-in時EQ: 12×2 = **24%程度**（GTO実値23.5%）。

**総合問題**: BTNの4betポット vs SB、K♠6♠、フロップ A♠T♠3♦、pot 50bb・自分スタック40bb、相手が突然All-in。
- Odds = (50 + 40×2)/40 = 130/40 = **3.25**（3倍より良い）。
- アウツ = 9枚（スペードのみ。K♠はAに負けるので除外）。EQ = 4%×9 = **36%**。
- 判定: EQ 36% > 必要勝率 1/3.25 ≈ 30.8% → **foldはあり得ない（callすべき）**。

## ハンドとレンジ：レンジ思考の4段階

（記事: 「ハンドとレンジ」。著者の代表作の一つ）

「レンジで考える」とよく言われるが、多くの人の思考は「ハンド vs レンジ」に留まり、真の「レンジ vs レンジ」に達していない。核心は、自分の"手札"ではなく **自分の"レンジ"に基づいてベットする能力**。理解を4段階に分けて解説する。

| Lv | 思考 | 評価 |
|----|------|------|
| Lv1 | 相手の特定ハンドを推測して判断 | 誤り |
| Lv2 | 相手のレンジを考える（自分のレンジは未構築） | 中級 |
| Lv3 | 自分のレンジ全体をバランスさせて構築 | 上級 |
| Lv4 | 相手の思考レベルを認識してエクスプロイト | 最上級 |

### Lv1. ハンド vs ハンド（誤り）

- 局面: BTN Qh2h open → BB call、フロップ JJ2 レインボー、33%CB → 相手50%レイズ。
- 誤った考え: 「相手はJを持っている可能性が高い。2でコールしても勝てない。**フォールドが正解**」。
- 問題点: 相手のハンドを1種類（Jのみ）に絞り込んでいる。バランスの取れたプレーヤーが「あるアクションを1種類のハンドだけで取る」ことはほぼない。
- 実際: GTO Wizard は**コール推奨（EV +1.11bb）**。フォールドすると1.11bb損失。相手のレイズレンジ内訳例: Jヒット以上 約25% / キングハイ・ノーペア 約45% / ツーペア 約3.7%。
- 原則: 各アクションは**そのアクションを取りうるレンジ全体**を想定する。ショーダウンでこそ「ハンド vs ハンド」だが、**各アクションはレンジに基づいて行われる**。

### Lv2. ハンド vs レンジ（中級）

- 相手のレンジは考えるが、**自分のレンジ構築を考えていない**（自分は1ハンド視点）。
- 限界の露呈例: ボード AK4 レインボー、自分 Kd6d、GTO推奨はポットオーバーベット（125%）。「K6で打っても降ろせずAにcallされる」と誤解し打たないが、実解では**このハンドは高頻度でベット**。
- ポイント: 自分の1ハンドの強弱だけで判断すると、レンジ全体設計から見た最適アクションを取りこぼす。

### Lv3. レンジ vs レンジ（上級）

戦略構築のプロセス（核心）:
1. **ハンドを見る前に、まず自分にレンジが配られていると考える**。
2. ボードとレンジから戦略（どのハンドをどの頻度でベット/チェックするか）を構築する。
3. **最後に自分のハンドを見て、その戦略に従いアクションを決める**。

- 具体例（AK4ボード）: Kの一部をベットに回す／4ヒットを「2ペアへの昇格」に賭けてベット／Aを頻度でベットし相手のAを過度に強くさせない／AAのような強すぎる手はスロープレー／フラッシュになりうる手も頻度でベット。
- なぜ必要か: Kを2ペアやKKでしかベットしないと、ターンでKが落ちた時、相手はKを多く残しているのに自分のレンジにKがなく、大きなポットで一方的にいじめられる（カバレッジの穴）。

### Lv4.「ハンド vs レンジで考える」相手をエクスプロイト（最上級）

- 理論的発見: **相手の戦略が固定なら、自分の各ハンドのEVは"相手のアクション"だけで決まり、自分の残りレンジには依存しない**。よって相手が気づかない限り、Lv2でもLv3でも（そのハンド単体の）EVは同じ。
- ではなぜLv3が必要か: **Lv2の相手を"倒す"にはLv3の習得が必要**。相手がLv2だと見抜いたら、Lv2視点とLv3視点で相手戦略を分析し、**その2つの乖離が相手のリーク**になる。そこへアジャストしてエクスプロイトする。
- 到達点: **「ハンド vs レンジで考える」相手に対し、自分は「レンジ vs レンジ」で考える**。**エクスプロイトとは相手の思考に対して行うもの**。そのためにGTOを理解・模倣できる土台が必要。

## レンジ構造とベットサイズ理論

この章は、ベットサイズと「良いレンジ」に関する複数記事（bet sizeの第一歩／ポラライズ／Geometric Betsize／bluffとshift／Rangeにおけるanchor／Robust Equity）を統合したものです。共通する核心命題は **「EQが高いこととEVが高いことは別」「レンジ全体で戦略を設計する」**。

### 1. ベットサイズの基礎（bet sizeの第一歩）

核心は **「打ってはいけないサイズが存在するので、それを避けてbetに意味を持たせる」**。

**pot% で考える**
- betの割に合うかは**絶対金額ではなく pot%（potに対する比率）**で決まる。相手から見れば pot% によって call に必要なEQが決まる。
  - **Case1**: pot 1000 に 500 bet → 500賭けて2000勝負＝4倍、pot% = 50%。
  - **Case2**: pot 10000 に 500 bet → 500賭けて11000勝負＝22倍、pot% = 5%（同じ金額でも割がいい）。
  - **Case3**: pot 10000 に 5000 bet → 4倍、pot% = 50%（Case1と同じオッズ）。
- **代表的サイズ**: 33% / 75% / 100% / 150% / All-in。中間が欲しければ50%等。このサイズ選定がスキル。
- リーク: 「大サイズ＝ブラフ、小サイズ＝バリュー」と決めつけ、大サイズに沢山callし小サイズに降りすぎるのは、Exploitにはなり得ても**均衡的には誤り**。

**Value bet は callレンジに勝って初めて成立**
- **Value bet の可否は「自分のハンドの強さ」ではなく「相手のcallレンジに勝っているか」で判断する**。自分が強いことは十分条件ではない。
- 教訓ハンド: BB の Qc9c（2ペア）が Turn 125% / River 150% と打ちすぎ、相手 T7 の上の2ペアに即callされ負け。Turn時点でQ9のEQは70%あったが、**50%以上のEQ＝Value betすべき、ではない**。打つと相手は弱い手を捨て、残るcallレンジが強化される。その強化レンジに勝てなければValueにならない。

**Elasticity（弾力性）**
- **bet size によって相手のcallレンジは弾力的に変化し、サイズが大きいほど残るcallレンジは強くなる**。均衡での目安（相手が弱い手を捨てる頻度）:
  - **50% bet → 40% 降ろす** / **75% bet → 50% 降ろす** / **125% bet → 60% 降ろす**。
- **禁忌級のミス**: ある程度強いハンドを、打つことでValueでなくなる大きすぎるサイズで打つこと。

**Small bet と Protection**
- **33%以下**を small と呼ぶことが多い（実戦は 10/20/25/33%）。初心者はまず「small = 33%」でよい。
- small bet は相手の降り頻度がそこまで高くならず、レンジが極端に強化されない → **「打ってはいけないサイズ」になりにくい**。
- **Flop/Turn の 33% は、あたかもチェックするかのようにどんなハンドで打ってもよい**。弱い相手を安く降ろすこと自体に **Protection（プロテクション）** の価値がある（降ろした相手には捲り目があった）。
- **River には Protection がない**ため、Value か Bluff かを厳密に判断する。

**レンジ全体でサイズを設計する**
- River のハンドランクと打てるサイズの目安: A（上位20%）=125%含む自由 / B（20〜40%）=50%や75%まで / C（40〜60%）=50%や33% / D（60〜80%）=betできない / E（下位20%）=bluff bet。
- リーク: 「33%を打ったらCランクしか出てこない」構築。相手はBランク以上でNuts級扱いになり搾取される。
- 正しい構築: **すべてのbetサイズに「より大きなサイズも打てる強いハンド」と「bluffハンド」の両方を用意する**。
- **最重要**: 自分のハンドを見る前に、そのスポットで打ちうる**全betサイズの集合を意識し、レンジ全体で戦略を決める**。

### 2. ポラライズ（レンジの類別）

（記事: 「ポラライズ -レンジの類別-」。目的は「EQが同等でもEVに一方的な差が生まれること」の確認）

**核心命題: EQが高いからといってEVが高いとは限らない**。したがって「良いレンジ」とはEQの高いレンジではなく **EVの高いレンジ**であるべき。

**レンジの三類別**
1. **リニアレンジ (linear)**: 強い手から順に集めたレンジ。強さが一方向に連続。オリジナルレイザーの典型。
2. **キャップドレンジ (capped)**: 強さに上限（キャップ）があるレンジ。最強級を早いアクション（例: 3bet）で分離済みのため、残ったコールレンジに上限が生じる。コーラー側の特性。
3. **ポラライズドレンジ (polarized)**: ナッツとエアーの両極端で構成、ミドルを含まない。例: ナッツとエアーのみのオールインレンジ。

**千里眼ゲーム（Clairvoyance Game）** — 理論の骨格を示す最小モデル
- 設定: リバー、各スタック100bb・pot 100bb、Hero = AA or QQ（50/50）、Villain = KK、ボード 33322、Hero=OOP・Villain=IP、アクションはオールインのみ。
- 全ハンドがフルハウスで強度 **AA > KK > QQ**。Hero = ポラライズド（AA=ナッツ/QQ=エアー）、Villain = キャップド。
- **EQは互いに50%**（HeroはAAで勝ちQQで負け、等確率）。

**被支配戦略（Dominated Strategy）**: 相手戦略によらず確実により利得の高い別戦略が存在する戦略。
- AAでフォールド（確実に勝てるのに降りる）/ QQでコール（確実に負けるのにcall）/ KKでベット（QQは降ろしAAにcallされ、バリューにもブラフにもならない）→ すべて被支配。
- 結論: **このゲームでアグレッション（自発ベット）を持てるのはHeroだけ**。一般化: 完全にポラライズされた側だけがアグレッションを持ち、キャップされた側は「適当な頻度でブラフキャッチ」しかできない。

**無差別の原理（Principle of Indifference）**: もしVillainにとってcall/foldどちらかが一方的に有利なら、Villainは全レンジをそちらに振ってHeroをexploitできる。よってHeroの適切なブラフ頻度とは、**Villainをcallでもfoldでも無差別にする**頻度。

**α（アルファ）とMDF** — 導出（b=ベット額、p=ポット、x=ベット時にバリューである割合）:

```
EVcall = x(b+p) - (1-x)b        EVfold = 0
x(b+p) - (1-x)b = 0  →  (2b+p)x = b  →  x = b/(2b+p)
```
- バリュー : ブラフ = **(b+p) : b**、**α = b/(b+p)**（Heroのブラフ比率を決める値）。

Villainのコール頻度（m）についても、HeroがQQでブラフしてもチェックしても無差別になる条件から:
```
EVbluff = p(1-m) - bm        EVcheck = 0
p(1-m) - bm = 0  →  m = p/(b+p)
```
- **MDF（Minimum Defence Frequency, 最小防御頻度）= p/(b+p)**。Villainはこの頻度でcallするのが最適。

**b = p = 100 の具体例**
- α = 100/200 = **1/2**、MDF = 100/200 = **1/2**。
- Heroの戦略: AAは全ベット、QQはαに従い **1/2** の頻度でブラフベット。Villainの戦略: チェックにはチェックバック、ベットにはMDF **1/2** でcall。
- EV計算:
```
EV(Hero)   = (EV_AA + EV_QQ)/2 = { (1/2×100 + 1/2×200) + 0 } / 2 = 75
EV(Villain)= (1/2 + 1/2×1/2)×0 + 1/2×1/2×100 = 25
```
- **結論: EQは互いに50%で等しいのに、Heroの EV(75) は Villainの EV(25) の3倍**。ポラライズしたレンジは、EQが等しくても一方的に高いEVを持てる。

**複数ストリートの実例（CO vs UTG）**
- CO が UTG の 2.5bb open に 8bb 3bet、UTGのみcall。フロップ **KT2（レインボー）**、UTGはドンクせずチェック。
- Flop: COは **1/4 pot程度**の安く広いCB。この安いベットにVillainは強い所で**チェックレイズ**が必要。この時点でHeroは「軽くポラライズ」され、相手のコールレンジはキャップされる。**注意: ポラライズ＝オーバーベットを打つこと、ではない**。
- Turn: **ラグ（ボードと相関の低いカード）**が望ましい。ラグはポラライズの強い部分をさらに強く、弱い部分をさらに弱くする。Hero は**80%程度のダブルバレル**（ブラフ多め）でポラライズを助長。
- River: 新たなラグ（例 2♠）が理想（「お互いのレンジに2はもう無い」）。Villainのチェックにオールイン。最終EQグラフは綺麗なポラライズになり、コーラー側は「ブラフキャッチくらいしかない」。
- 有料部分（末尾）の予告: OOP/IP入替、可変ベットサイズ、ジオメトリックサイジング、ストリートありのMDF、ナッツ/エアー以外のMDF、混合比を誤った場合の影響。

### 3. Geometric Betsize（幾何級数的bet）

（記事: 「Geometric Betsize」。概念は無料、数学的導出は有料）

**問題意識**: バランスの取れた（均衡）相手には、自分のハンド対相手レンジではなく「**相互のレンジ**」を考慮したベットサイズが必要になる。

**1ストリート分析**（pot=p、bet=b）
- **MDF = p/(p+b)**。ナッツ(AA)のEV:
```
AA EV = (p+b)×MDF + p×(1−MDF) = p + pb/(p+b) = p(p+2b)/(p+b)
ポラー側EV = (1−x)×(QQのEV) + x×(AAのEV) = x × p(p+2b)/(p+b)   （x=バリュー比率）
```
- 示唆: bが大きいほどEVは上昇するが**増加率は逓減**。EVはx（バリュー比率＝ブラフを多く含められる度合い）に比例。**結論（1ストリート）: なるべく大きく、つまりオールインが最適**。

**マルチストリート化**（pot=100、スタック=400、Hero=A or Q、Villain=K、ボードなし、ベット2回可）
- ポット成長率 r1, r2 で考える。オールイン到達条件: **r1 × r2 = 9**（最終pot 900 / 初期100）。
- ブラフ搭載可能数を分析すると、**r1 = 3, r2 = 3（等倍）で最大化**。
- **結論: 同じサイズを2度重ねてオールインまで入れきるベットが、ポラライズのEVを最大化する**。

**Geometric Betsize の定義**: 各ストリートで**同じ倍率**のベットを繰り返し、最終的にスタックを**ちょうど使い切る（オールイン）**サイジング。
- 適用条件: 完全ポラライズ（EQが100%か0%）で、ターン・リバーのカードでEQが変化しない状況。
- 位置づけ: **「ポラライズの基本＝Geometric」**。
- **表記 "ne"**: n回のベットでオールインに入れきるGeometricサイズを「ne size」と呼ぶ（3回＝3e、2回＝2e）。「2e size にあやかって250円」が価格の由来。

**SPR別のGeometricサイズ（記事の数値）**
- **SPR 17.7**: 3e ≈ 各115%×3回（記事内では「Flopから約125%を3回」とも）。2eなら ≈ 250%。
- **SPR 5.6**: 3e ≈ 65%弱。
- 具体例: ①AK6r/AK2ペア → 約125%をGeometricで継続。②Flopチェック→Delay-CBでセット完成 → **250%（2e）**。③BTN vs UTG 3betポット（SPR 5.6）→ Geometric ≈ 65%弱だがWizardに65%が無いため実装上**75%**採用（125%は使われない。GTOソフトの選択にもGeometricが反映）。
- キーテイクアウト: (1) ポラライズの基本はGeometric、(2)「大きいサイズ＝ポットオーバーで損」は誤り、(3)「リバーでSPR=1にすべき」は限定的・不完全。
- 有料部分（数学的導出）: 「Two street Static Clairvoyant Game」で r1=r2 が最大になることの厳密証明。

### 4. bluffとshift

（記事: 「bluffとshift」。初級→中級。GTO Wizard 6max 100bb 50nl GTO-GTO）

**Riverのbluff：核心原則**
- spot例: BTN vs BB SRP、Flop Q84 → x/c, 75%CB → Turn 2 → x,x → River 9。均衡では **Khi以下をbluff**、Ahi〜3rd pairは基本bluffに選ばれない。
- **原則: bluffは基本的に弱いハンドで行った方が利益的**。
- 反直感的な数値例:
  - K5s: 51%betのEV = **1.01** → それでもbluffする。
  - 74s（4hit）: 51%betのEV = **2.57**（K5sより高い）→ それでも**pure check**。
- なぜ？ 均衡が避けるのは「**同一ハンドの他アクション（特にcheck）と比較して低いEVのアクション**」。K5sがbluffするのはK5s自身のcheckよりbet EVが高いから。74sがbetしないのは74s自身のbetよりcheck EVが高いから。
- **判定式**:
```
check EV > bluff EV → check
check EV < bluff EV → bluff
```
- blocker・valueに見えることは直接の理由ではない: blockerが良い→foldが多く取れる→bluff EVが上がる→check EV < bluff EV が成立しやすい、という間接的な経路。
- **法則: check EVが低いほどbluffに選ばれやすい**。弱い手はcheck EVが低いのでbluffの筆頭候補。Manhattanグラフでは betハンドは左（弱い側）に集中し、真ん中は打たない。
- まとめ: Riverでbluffを打つ作業の大半は「**自レンジで弱い順にハンドを探す**」こと。

**pure bluff と id bluff**
- KJsは check EV = 1.22、bluff EV = 1.21（solver誤差とみなし無差別）→ 混合戦略でbet（頻度構築）。
- なぜ頻度でbluffが要るか（AKQゲームの発想）: valueを最大化するため。bluffが足りないbetは相手のブラフキャッチからcallをもらえずvalueが伸びない。
- bluff handは2種類: **pure bluff**（単にbluff EVが高い）/ **id bluff（indifferent bluff）**（bluffとcheckが無差別で、頻度のためにbetしている）。
- 用語批判: 「この辺までbluffしないと足りない」という主張は、対象がpure bluffなら単にEVのためのbetなので不適切。「足りない」は頻度の話＝**id bluffに関する言及であるべき**。

**Flop/Turnのbluff：draw良型から選ぶ**
- まだランナウトがある＝**semi-bluff**が存在。Flush draw / straight draw は **EQがrobust**（potが膨らんでもEQが毀損しにくい）→ bluff EVが十分大きくbluffに選ばれやすい。
- 厄介: これらのdrawはそもそもEQが低くない → **EQ最低の手ではなく、draw良型の"中EQ"ハンドがbluffに回る**（AK4ボードのManhattanグラフはlow EQに寄らず広く分布、over betを打つ）。Early streetほどdraw良型からbluff。

**shift（本記事の中心概念）**
- 定義的イメージ: ボード進展に伴うレンジの相対強度のシフト。
- spot例: UTG vs BB SRP、Flop Q74 → x/c, 50%bet → Turn 6 → x,x → River A。均衡はざっくり **low pairをbluff**（6hitや4hitでbluff）。
- 手順①: nodeに持ち込んだレンジを適切に考える。レンジが大きく変動したのは **Flopのcall** → 「Flop callしたレンジの中でRiver時点で弱いもの」をbluffに選ぶ。
- 手順②: ただし「Flop callで最も弱い所」をそのままbluffするわけではない。後のカードでEQが変動し、弱い手が強くなることがある → **EQがどうshiftしたか**を考える。
- このspotの追跡: Flop下限=KJhi or draw → Turn 6でSDが6hit/straightに昇格 → River Flush完成+A も進展 → **2度の激しいshift**。結果RiverではKJhi 1種を除き **4hit・6hitがレンジ下限**。hitが下限になったため、**hitがbluff候補として有力**になる。
- **心構え（最重要）: ある程度強いハンドを持っているとき、下限を疑う**。shiftの激しいボードでbluffが難しいのは、hitでFlop callしたのにRiverで下限であることを疑わねばならないから。
- **一般則: bluffするハンドの役が強いシチュエーションはbluff過少になりやすい**（解説で「ここはbluffが少なそう」と言われる多くはこれ）。
- 基本姿勢: 「全spot全situationで、自身のレンジ下限・相手のレンジ下限は何かを考えながらpokerをする」。役があると SDV（ショーダウンバリュー）がありそうに見える誤謬を破壊する。

**bluff過少になるspot（基本方針の裏返し）**: River＝自レンジ下限が分かりづらいと困難 / Flop・Turn＝draw良型が存在しないと困難。

### 5. Rangeにおけるanchor

（記事: 「Rangeにおけるanchor」）

- **定義**: call優先で守りたいハンド帯（多くはレンジのミドル帯）が、トップレンジ（強ハンド）に対し「碇（anchor）」のように作用し、そのraiseを妨げる現象。このpassive actionに拘束されたレンジ帯を anchor と呼ぶ。
- **成立ロジック**: AToのようなミドル帯はEQが惜しく切り捨てられない→callで守りたい。それらを大量にcallしつつQQをraiseすると、callレンジがハイカードだらけになり構造的に歪む。よって「QQはcallレンジ（ミドル帯）を守るためにcallする」。視点を変えれば「ミドル帯が"守ってくれ"と働きかけ、トップレンジのraiseが制限される」。
- **具体例1（UTG vs BB、BBのdonkを受けたQQ）**: pair boardでもGTOは約25%でdonk。QQは7には負けるがdonkレンジの大半に勝つ。GTOはraise頻度ほぼ無く、AA/KK/QQすらcallで抵抗。理由＝AToなどミドル帯を守るため（anchorがQQのraiseを妨げる）。
- **anchorは切り捨てられるか**: 理論上はnode lockでハイカードのid帯をfoldに拘束すれば検証できる。solverは残りをアグレッシブにplayするが、**EVは低下**する:
  - GTO戦略 UTG EV: **1.57** / Nodelock戦略 UTG EV: **1.44**（いずれもdonkを受けた後）。
- **具体例2（BTN vs HJ 3betポット、AJ9ボード、HJがJcTc）**: BTNが20%CB。GTOではJTsはpureにXR（bluff raise）、HJ全体もraise or foldに近い。ここでのanchorは pocket pair だが、EQが非常に小さいため**anchorを切り離して残りをアグレッシブにplay**する。A64のように2枚目が低いボードではpocket pairを耐える価値が高く、このアグレッションは見られない（**ボード依存**）。
- **総括**: ミドル帯は基本アグレッシブを好まない。ミドル帯のEQが大切・大量なら anchor として働き、残りレンジをpassiveにする。逆にミドル帯を捨ててよいなら切り捨ててアグレッシブに動く。**相手にanchorが多い場合、raiseを恐れずbetできる**。

### 6. Robust Equity（EQの堅牢性）

（記事: 「Robust Equity -EQの堅牢性-」。従来のバリュー/ブラフ二元論では説明できないGTOアクションを理解する枠組み）

**ハンドの強さの定義**
- **バリューハンドの定義: 「相手のレンジ全体に対するEQが50%を超えていること」**（「相手のレンジ全体に対する」が重要）。
- 3betレンジの歪さの例: HJ open range（全体の約20%）に対し、SBの3betレンジ（vs HJ）全体のEQは **57.33%** → レンジ全体で見ればバリュー。しかし個別で見るとばらつく（AQo=バリュー✓、77=心許ないがバリュー✓、KQs=厳しい、KJs=EQ50%割れ✗、A5s=ブラフ向け）。
- HJ側のオッズ計算（3betに直面）: pot = 1 + 2.5 + 11.25 = 14.75bb、Odds = (8.75+14.75)/8.75 ≈ 2.69、**必要勝率 ≈ 37%**。ATsはHJ openレンジには約53%だが、3betしてcallされるとEQが50%割れ → 「弱い手を降ろし強い手にcallされる」非効率なベット。GTOにはこうした「バリューにもブラフにもならないベット」が頻出する。

**EQ Robustness（本題）**
- All-in以外では現状EQがそのまま実現するとは限らない（EQR）。
- 事例（ボード Kc Td 4s、UTG が30%CB → BTNレイズ）: 88 と QJs はフロップEQほぼ同じ（44–45%）。レイズ直面後、88→**38.7%**、QJs→**35.7%**。だが**GTOは88フォールド、QJsコール**。EQの大小だけではハンドの価値を評価できない。QJsの方がEQ実現率が高い。
- **Robust Equity（堅牢なEQ）**: ベット・レイズに対して降ろされにくい／減少しにくいEQ。**ナッツ級を構築できるEQ**（ナッツならレンジが強化されても関係ない）。例: ナッツFD、ストレートドロー（QJs）、セット。
- **Vulnerable Equity（脆弱なEQ）**: 相手のアクションで失われやすいEQ。例: A以外のワンペア、Aハイカード。

**EQ Component（EQの構成要素）** — 1つのハンドに複数のEQが同居する
- 事例: 7h8h on Jh Tc 5h（合計約68%）: フラッシュドロー約17%（Robust）+ バックドアSD約4%（Robust）+ 7のワンペア約47%（Vulnerable）。
- 戦略的分類での再分解: ドロー系のロバストEQ約21% / ワンペア昇格による弱ロバストEQ約20% / ワンペアのバルネラブルEQ約27%。
- **注意**: アクションが激しくなるほどバルネラブルEQは厳しく晒される。このハンドで過剰にレイズすると27%のバルネラブルEQを自ら放棄し、そのレイズはもはやバリューレイズと呼べない。

**bet と robustness（4象限の戦略指針）**

| EQの種類 | 推奨戦略 |
|---|---|
| **Robust かつ 大きいEQ** | 焚いたpotで相手の強い手とショーダウンしたい → 大きいベット推奨。RobustなのでEQは実現できる。 |
| **Robust だが 小さいEQ** | 相手の大きいEQをフォールドさせて利益を得る → 大きいベットで降ろすのが正当化される（potを取る時はロバストEQで取るため）。 |
| **Vulnerable だが 大きいEQ** | 相手の小さいEQ（ワンオーバー等）を放棄させ捲られを減らす。ただしアグレッシブ過ぎると自分のバルネラブルEQを失うので注意。 |
| **Vulnerable かつ 小さいEQ** | アグレッシブにすべきでない。相手のロバストEQにEQを放棄させられるリスクが高い → チェックレンジを守る。 |

- 総括: **「バリュー/ブラフ二元論」は、実はこのRobustnessの考え方を分かりやすく簡略化したものだった**。
- 参考文献: 『No Limit Hold'em for Advanced Players』。

## プリフロップ戦略

（記事: 「プリフロップレンジの覚え方」＋「"超"初心者講習」。出典ソリューションは GTO Wizard 6max 100bb 50nl GTO-GTO、想定Rake 5%・cap 4bb程度）

> 注意: Anteの有無で最適レンジは大きく変わる。RakeやテーブルのタイトさによってGTO値からの調整が必要。

### A. プリフロップレンジの覚え方（GTO精密版）

**Bet Sizing（サイズ）**
- Open（ポジション別）: UTG/HJ = 2bb / CO = 2.3bb / BTN = 2.5bb / SB = 3bb。
- 3bet: IP = openの約3倍 / SB = openの約4〜5倍 / BB = openの約5〜6倍（例: HJ 2bb open に BB 約12.3bb 3bet）。
- 4bet: IP = 元3betの2〜2.2倍 / OOP = 2.5〜2.8倍。
- 5bet: 基本 All-in 一択（例外的にAA等でミニ5betあり）。
- Squeeze: 本来のレイズ額 + Cold Callで増えたBB数を上乗せ（例: UTG 2bb open → BTN call → BB 約13.5bb squeeze）。

**Open Range**
- 基本原則: AXs（Aと同色）はどのポジションからもopen可。Pocketもどこからもopen可だが55以下はEPで頻度が下がる。
- **Key Pocket 理論**（暗記の核）: 「**後ろに残っている人数 + 5** = そのポジションのKey Pocketの数字」。例: UTG（後ろ5人）→ 5+5=10 → **TT がKey Pocket**。
  - 覚え方: レンジ表でKey pocketから左に「山（斜線）」を描き、1つ右にずれて「縦線」を引く。山より上側と縦線を含む左側が参加ハンド。
- ポジション別の下限目安: UTG（最狭）= AXs全て/88+/K5s+ ／ HJ = AXs全て/77+/Q5s付近 ／ CO = AXs全て/66+/K2s全KXs/Q5s〜/A8o+ ＋A5o ／ BTN = AXs全て/55+/K2s全KXs/Q4s〜/J4s〜/A3o+ ／ SB ≈ BTNと同程度。

**Cold Call（vs Open）**
- 基本: **BTN以外はCCしない**。
- BTNのCCは「raiseできない弱い手」ではなく「raiseするには十分強いが4betを食らうと勿体ないレベル」をCCする。例: XTs、XJs、QQ以下pocket、スーコネ（45sまで）。AXsは全て頻度でCCに追加。オフスートは基本CCしない（例外的にAQo/AKoのみ低頻度）。
- New York Back Raise 対策: 最強格の一部（QQ/AKo）を低頻度でcallに残しバランス。

**3bet（vs Open）**: 構造は **Polar 3bet**（強いValue + 弱いBluff）。
- 3betして適正: Q以上2枚のオフスート / T以上2枚のスーテッド / 88以上pocket。
- 3betになり得る（Bluff寄り含む）: AXs全て / X9s / AJo・ATo・KJo / 88以下pocket。Bluff 3betは相手openレンジ下限のスーテッドを採用。

**BB Defence（vs Open）**: BBは既に1bb出しているので広くcallして守り、call以上のうち約1回はraiseで対抗（上級と中級で最も差がつく領域）。
- 3bet構築ロジック: 強い手を片っ端から3betするとcallレンジが弱くなりすぎる → (1)3betできるレベルまでcallに回す →(2)本当に3betしないと勿体ない手のみValue3bet →(3)頻度が低いのでBluffを足してPolar化。
- Over Call（Odds Call）: 相手openが安い（2bb）とフロップ3枚見るだけで利益になる手を下限外でもcall。2.5bbになると激減。

**Cold 4bet**: 前でopen→3betまで入った状況での再々レイズ。激強レンジ（QQ+ / AKo / Q以上2枚のスーテッド）。AQoは降りた方が良いことが多い。

**vs 3bet（自分のopenに3bet）**: callもあり、4betもPolar。Value4bet=QQ+基本4bet以上、JJ〜88はcall/4betマージナル、AKoは4bet以上多め（QQ・AKは4bet jamが選ばれやすい）。Bluff4bet代表= ATs・AJs・KTs・KJs。頻度の逆転現象: 低頻度open（弱いポケット等）は3betに高頻度call、高頻度openは低めにcall。

**vs 4bet（自分の3betに4bet）**: 「感覚でもそこまで間違えない」。QQ+をAll-in、AKはほぼpure、Bluffは A5s・A4s 程度、callはかなり広い。

**Squeeze**: CCが入った後の再レイズ。レンジ表の「左上の長方形（Value）」がベース。SBならpocket追加、BBならスーコネ追加。長方形部分を持つ時はかなり高頻度でsqueeze。

> 参考: GTO Wizard（プリフロップは無料閲覧可）、ヒロユキポーカーチャンネル、glassさん/ちゅうぴかさんのnote。

### B. "超"初心者講習の10ポイント（簡略・断定版）

100bb持ちキャッシュ想定。初心者が迷わず再現性高く・舐められずプレーできるよう、あえて断定的な指針（例外は多い）を提示。**上記GTO版よりサイズは丸められています**（open 2.5〜3倍、3bet OOP 4倍/IP 3倍など。詳細より再現性を優先）。

1. **BB・BTN以外はレイズで参加**。参加人数が増えるほど勝率が下がる（AAでも5人で約50%）。
2. **BTN・BBはopenに対してコールOK**（BTNは位置的優位、BBはブラインドを払いclose済み）。
3. **リンプをしない**。相手がリンプしたら、リンパー人数分の額を通常open額に上乗せしてopen（BB=10でリンパー2人 → 通常30+20 = 50でopen）。
4. **3betに横から（コールドコール）参加しない**。
5. **レイズ額は基本3倍**（Open: SBから3倍・他2.5倍、3bet: OOP4倍/IP3倍、4bet: 2〜2.5倍。例 SB5-BB10: open=30、3bet=90）。
6. **フロップ以降のbetは {33%（必須）, 75%, 100%, 150%, All-in} から選ぶ**。「かなり強い/弱い→大きく」「ちょっと強い/弱い→小さく」（ポラライズの発想）。
7. **openレンジ表に従う**（赤=常にopen/緑=条件付き/青=常に降りる。UTGでは緑は全て降りてよい）。
8. **3bet関連レンジに従う**（赤=All-inまで継続可/緑=3bet or 3betにcall/青=降りる）。
9. **オリジナルまでcheckで回し、ドンクベットをしない。CBは高頻度（50〜100%）で打つ**。
10. **「ナッツから考える」信念を持ち、betはボードに対して行う**。

- ポジション用語: UTG=SB/BBの次で最初にアクション、CO=BTNの前、BTN=SBの前でフロップ以降必ず最後。
- オリジナルレイザー: 前ストリートで最後にレイズした人＝最強ハンドの可能性を主張した人。アクション順はOOPが先・IPが後。
- ドンクベット（オリジナルがアクションする前にOOP側から先打ち）は**しない**。CB（継続ベット）は非常に強力で50〜100%で打ってよい。
- **ナッツから考える**: ①ボードの最強ハンド（ナッツ）→②セカンドナッツ→…と順序付け→③自分が上から何番目か判定。betはハンド単体でなくボードに対して行う（7c8c9cのAAはK84rのAAより価値が低い）。
- **EVpoker（推奨）vs 快楽poker**: EVpokerは期待値追求・運を排除（負けるコールで相手に利益を与えない）。快楽pokerは楽しさ優先で結果が運依存。
- 使用ツール: Range Painter（ぱいにゃんさん開発）。参考サイト「ポーカー道」。

## ポストフロップとRiver

### A. Flop CBの基礎（教科書シリーズの位置づけ）

（記事: 「Flop CBの基礎」3部作。**本編は有料**。ここでは無料導入部の枠組みのみ）

- テーマ: GTO理論に基づく Flop コンティニュエーションベット（CB）戦略の基礎。3部作は BTN vs BB（SRP）→ linear 3bp → BB 3bp。
- 位置づけ: **Exploit戦略ではなく「Exploitを理解するための前提知識」**。GTO Wizard（100bb General GTO-GTO）のソリューションを全Flopで再現できるようにするのがゴール。「Flop CBで大きなミスを生まない」精度。
- **学習アプローチ（2ステップ）**:
  - **Step1: ボード分類と戦略提示** — 使えるベットサイズ候補の抽出 → サイズ別の使用頻度決定 → ハンドごとの打ち手選択基準。
  - **Step2: ハンド振り分け** — 各戦略に個別ハンドをどう配置するか。
- linear 3bp の定義（無料部分で明示）: BB以外のプレイヤーが3betを行い、オリジナルレイザーがコールしたシチュエーション。BB 3bp は BBが3betしオリジナルがコールしたシチュエーション。
- 3betポットでは「レンジ対レンジでバランスに注目」「ベット目的を明確にする」意識が強調される。

### B. EQの切り離しと押し上げ（River model その1）

（記事: 「EQの切り離しと押し上げ」。完全無料。GTO Wizard 6max 100bb 50nl 均衡を題材にしたRiver理論）

中心メッセージ: **「River でレンジEQがあるだけでは戦略は決まらない。切り離しと押し上げという補正を経て初めて均衡が理解できる」**。

**メインケースの設定**
- PF: BTN open、BB call。フロップ Q-9-5: BTN 50%CB → BB call。ターン Q（ペアボード化）: BTN 50%ダブルバレル → BB XR。リバー 8c: BB はどのレンジをどのサイズでベットすべきか？
- BBのブラフ素材だったFD/SDがリバーで全て完成し、BBはほぼ全ハンドが **Trips+（Qのトリップス以上）** に強化。
- 多くの人は「レンジEQがあるからレンジベット」と考えるが、**実際の解は低頻度・極小ベット、ほとんどがチェック**。

**なぜ River は特殊か**
- フロップ・ターンは**ボードが未完成で相手のトラッシュも一定のEQを持つ**ため、ベットでそのEQを放棄（フォールド）させる価値があり、レンジベットが機能する（K-K-5でUTGのレンジEQが63%超なら全レンジ33%ベット）。
- **River はEQが確定し、トラッシュのEQがほぼ0**。降ろさせる価値がなく、EQを根拠にしたレンジベットは無意味になる。

**EQの切り離し（セパレーション）**
- River で相手は真0に近いトラッシュ帯を**無抵抗で捨てる**。したがって相手レンジからトラッシュを除外し、実際に抵抗してくる「**拮抗レンジ**」だけを相手と想定し直す。これで相手レンジのEQ下限が引き上がる（記事の **Figure1**）。

**EQの押し上げ（レンジ強化の補正）**
- 自分のレンジEQを「相手の全レンジ」基準で見ると、相手トラッシュ帯が**見かけEQを不当に高く押し上げている**。トラッシュはRiverで降りるので、拮抗レンジ基準で測り直すと**自EQグラフはこの押し上げ分だけ下降する**（**Figure2**）。
- 例: 見かけEQ60%超のAhitがブロックベットしないのは、「相手の拮抗レンジに対してはそこまでのEQがない」から。

**帰着する構造**
- 補正後はしばしば **01（ゼロワン）ゲーム**（0〜1の乱数でハンド強度を表すトイゲーム。EQの高さがベットサイズに単調対応し、最上位はトラップ、最下位はブラフ、中間はチェックまたは固定サイズ）に帰着。
- トラッシュ消滅でレンジがTrips+に強化されるケースは、片方が**ポーラ（バリューとブラフの二極）レンジ**を持つ **AKQゲーム**構造になる。**誰がポーラ側かでベット主体か否かが決まり**、同じ「レンジEQあり」でも戦略が対照的になり得る。

| ケース | 発生要件 | 補正後モデル |
|---|---|---|
| Case3 | ターン時点のレンジEQをリバーへ持ち込み | 01 ゲーム |
| Case4（亜形ドンクジャム） | リバーでドローが完成しトラッシュが消滅 | OOP ポーラ AKQ ゲーム |
| Main Case | リバーでドローが完成しトラッシュが消滅 | IP ポーラ AKQ ゲーム |

> 「補正後モデル」欄の OOP／IP は、補正後にポーラ（バリュー＋ブラフの二極）レンジを持ってベット主体になる側。Main Case では BB(OOP) のレンジが Trips+ に凝縮して均一化するため、ポーラ側は相対的に弱い手まで残る BTN(IP) になる。Case4 は逆にOOPがポーラ側で、そのOOPがドンクジャムを実行する。
> 余談: ターンでレンジEQを持ち込むこと自体はGTO均衡では稀。ターンにレンジEQがあれば通常はレンジベットを採用する。

### C. Wpolarとindifferent（River model その2）

（記事: 「【River model】Wpolarとindifferent」。advanced player向け、piosolverトイモデル）

前提: Geometric betsize の note で indifferent の作り方を理解できている程度。記事の3目標＝①Wpolar-gameというmodelの理解、②toygame（トイモデル）の有用性の理解、③indifferentと頻度構築の関係の理解。

**導入例（問題提起）**
- stars 50nl、BTN open に BB で **A7s**、Board **K64tt**（ツートーン Kハイ）。BTN 33%c-bet → BB 50%raise → BTN call。Turn **Td**（完全なラグ）→ OOP が pot over c-bet。River **Js** → ナッツフラッシュ完成。
- 直感: 「Turn-RiverのgeometricラインだからRiverはAll inできる手」。**しかしこれはレンジ戦略の理解不足**。
  - GTOWizardの解では、Riverでレンジ全体のうち **All inしている手は1.3%しかない**。ほとんどが安ベット、**A7sに至ってはピュア安ベット**。
- 結論: **「Turnまでpolarizeしていたが、Riverは止まってレンジ全体で安ベットをしろ」**。
- 重要命題: **「同じレンジであっても戦略の構築によってEVが変化する」**（＝pokerが絵合わせゲームではない要因）。導入例でAll in戦略のみに限定すると、安ベット戦略に比べ**100点以上（1bb以上）のチップを捨てる**。

**Wpolar-game の定義（レンジの4群モデル）**

| 群 | 呼称 | 所属 | 中身（例） |
|---|---|---|---|
| 1群 | 弱Air | OOP | ブラフしていたハンド（FD以外） |
| 3群 | 弱Nuts | OOP | バリューを打っていたハンド（44のセット等） |
| 2群 | 強Air | IP | ブラフキャッチしていたハンド（Khit等） |
| 4群 | 強Nuts | IP | FDでコールしてきたハンド（QTsなどのhitドローが完成） |

- 「Wpolar-game」= OOP が「1群 and 3群」の polar レンジ、IP が「2群 and 4群」の polar レンジという構成（OOP側が"弱い側のポラー"を持つ形）。
- 戦略の読み方: OOP は「1群・3群のpolarで相手の2群（強Air）をpolarに苛める」。IP は「2群でブラフキャッチしつつ、4群でOOPの3群（弱Nuts）を苛める」。
- **bet sizeが小さくなる理由**: IPの強polarレンジ（4群）を恐れながら、OOPの弱polarレンジを活かしてEVを高めるため。
- 実戦への落とし込み: Riverでレンジ全体がWpolar-game的なとき、「奇跡のNutsを弱Nutsとして処理し、レンジ全体で相手の（Turnまでの）ブラフキャッチ＝強Airを苛める」。
- 学習ポイント: **「Riverのmodelをあらかじめ複数持っておき、現在の状況がどのmodelに近いかを考えると、Riverの解像度を上げて戦略構築ができる」**。

**Indifferentと頻度構築（OOP強polar model）**
- レンジを入れ替え、OOPが強polar・IPが弱polarのケース。4つのノード: Node1（OOP: check/bet）、Node2（IP: OOP checkへの応答）、Node3（OOP: IP All inへのcall/fold）、Node4（IP: OOP All inへのブラフキャッチ/fold）。
- **Indifferentの核心**: OOPがAll inしIPがブラフキャッチする局面で、OOPは **IPの弱Nutsをindifferentにするようにbetする**（IPの弱Airは完全なゴミ）。IP側から見れば、OOPのバリューブラフ比率が偏れば全fold/全callでexploitできる。
- 根本原理: **「何らかの群が適切にindifferentになっていないなら、それはExploit可能な頻度構築」**。頻度構築の定義: **「相手の特定の群をindifferentにすることを目標として構築するもの」**。
- 相互構造: OOPの（強Nutsのbet頻度に対する）強Airのbet頻度 → IPの弱Nutsのcall/foldをindifferentに。OOPの強Nutsのbet頻度 → IPの弱Nutsのcheck/betをindifferentに。
- 検証実験: OOPの強Nutsのbet頻度を上げてNode1をlockするとNode4でindifferent群ができ、同時にNode2で**弱Nutsがピュアにbetを始める**（indifferentだった群がピュア戦略に変わってExploitしている実例）。

**Exploitの理論的基礎（この記事の要）**
- IPで弱Nutsを持ちOOPにcheckされた場面: あなたの手はcheck/betについて **indifferent**。ただし「indifferent = どっちでもよい」ではない。
- 実践的な搾取則:
  - **OOPの強Nuts打ち出し頻度がGTOより過多 → betでExploit**。
  - **OOPの強Nuts打ち出し頻度がGTOより過少 → checkでExploit**。
- GTOの本質: GTOは緻密にindifferent群を作りExploitされない戦略を組むが、人間には不可能で必ず綻びが生じる。**その綻びは「こちらの特定の手をindifferentにしなくなる」形で現れ、そこが隙。ここを突くのが理論に裏打ちされたExploit**。「相手のどの頻度が、こちらのどのEVに、どう影響するか」を理解して戦略を考える。

### D. deepdive into AK-hi-board（先行版、上級）

（記事: 「deepdive into AK-hi-board 先行版」。¥50000だが先行公開で大半が読め、著者は**購入非推奨**。100bb-cash・1on1・4betまで、GTO Wizard general版）

- ポジション別の要点（無料本文に展開）:

## GTO Wizard の使い方

（記事: 「GTOWizardについて」。完全無料）

### GTOツールとは（Pio vs GTO Wizard）

ポーカーのGTO学習は事実上「GTOツール」に依存します。主要ツールは2種類。

**Pio Solver（計算機タイプ）**
- **買い切り型**のPCインストール型ソフト。自分でレンジ・ベットサイズを指定するとGTO近似解を「計算してくれる」＝本質は計算機。
- 費用感: Proプラン **$475**（約5万円）＋高性能PC（約20万円）で初期費用30万円程度。スマホ不可。
- 計算に最低10分以上かかり、あらかじめ計算して後日参照する方式。
- **Node Lock機能**: 相手が非GTOのとき、どう対応（エクスプロイト）すべきかを計算できる。toy game 作成も可能で勉強に欠かせないが**使いこなしが難しい**。
- 補足（Wpolar記事より）: piosolverは設定（レンジ・スタック・ボード/betサイズ候補/rake/計算精度）を与えるとGTOを生み出す機械。GTO Wizardはpioの結果を見やすくしたもので、Wizardは計算精度が低い傾向があり、細かいスポットはpioで精度を上げると正しい結果が得られる。

**GTO Wizard（図書館タイプ）**
- **サブスク型**のブラウザ型サービス。用意されたレンジ・ベットサイズの「計算済み結果を閲覧」できる＝本質は計算結果の図書館。
- 料金区分: Cash / MTT / Spin / Str+Ante の4つ。各にStarter・Premium・Eliteがあり **Premium以上推奨**。年間契約で月約$62（約8,000円）、Eliteは月$134。
- PC・スマホ両対応、追加初期費用なし。ボタン押下後1秒以下で結果表示。
- 2023年に solver「RuseAI」を買収し「WizardAI」として統合。solver機能も拡張中（現状Eliteで制限付き利用可）。

**使い分けの推奨**
- 初心者・大半のプレーヤーは **GTO Wizard を選ぶ**。Pioは持て余しやすくNode Lockを有効に使うのは難しい。
- **Wizardをベースに使い、疑問が残るスポットだけPioで計算し直す**のが理想（Range CopyでレンジをそのままPioに移せる）。
- ソリューション精度は代表的なもので0.1〜0.3%、Simplified系も高精度で標準的スポットでは実用上問題なし。

### GTO Wizard の主要機能

- **Study — ハンドレビュー**: ソリューションを選び、レンジ表にカーソルを合わせるとコンボごとのアクション／**EV / EQ / EQR** を参照できる。表示モードは Strategy+EV（基本）/ Strategy / Strategy+EQ / EQR。**選択頻度が極端に低いアクションは計算精度が不十分なことが多く、深追いしない**。
- **Study — EQグラフ（Rangesタブ）**: 縦軸＝そのハンドの相手レンジに対するEQ、横軸＝自分レンジ内でのEQ順位置。**両者のグラフが離れるほど一方のレンジが全体的に強く、CBが正当化されやすい**。アグレッサー（オリジナル）のグラフが上に来やすい。
- **Study — 集合分析（Report機能、キー「4」）**: 全フロップ（ターンまで対応、**Riverは非対応**）を横に並べ、各ボードのレンジ全体のアクション頻度やEVを棒グラフで俯瞰。Filterで条件（例: モノトーン以外）を絞ると加重平均頻度が見える。**bet頻度の高いボード＝IPのEVが高い**を視覚化できる。
- **Practice — Trainer（GTOと対戦）**: 実戦形式の練習。**Show hints は必ずOFF**（でないと答えが常に表示される）。RNG mode の Low はサイコロで頻度通りのアクションを要求し難易度が上がる。採点は **Best / Correct / Inaccuracy / Wrong / Blunder** の5段階。
- **Practice — Range Builder（塗り絵）**: レンジ表に自分でアクションを塗り、実解と比較して適合率で採点。openレンジやBB defenceの暗記に有効。著者は25%刻みで塗り100%適合を目指して繰り返す。
- **小技**: モバイル版が重い場合は**言語設定を英語にすると大幅に高速化**する。
- **登録の注意**: アフィリエイトURL（`gtowizard.com/p/名前`）を踏むと初回10%割引。アフィリエイト先は**登録時に確定**し、後から変更できない。

## 学習法：思考をハンドレビューする

（記事: 「思考をハンドレビューする」。座学志向者向け、実質全文無料）

> 📝 **本ノートの理論を使ったハンドレビュー例**: [BTN 88 vs CO — J♠9♠5♥ Q K を「切り離し・押し上げ」で読む](./hand-review-88-btn-vs-co-J95QK.md)（GTO Wizard 画面つき解説）

### 核となる主張

- ハンドレビューは「結果（そのプレーラインが正しかったか）」ではなく **「思考プロセス（どう戦略を組み立てたか）」をレビュー**すべき。
- 「QQはフロップでベット、チェックは間違い」という結論だけでは断片的な「tipsの知識」で終わり、均衡の理解は深まらない。

### Step0. 自身のレベルの設定

- 前提認識: 「GTOをある程度把握していない人がNLHで十分な実力を出すのは不可能」。
- 自分のプレーを振り返る際、次を明確に分ける: ①GTO的な戦略構築はどうなっているか、②自身のプレーは利益的（Exploit的に正しい）だったか。
- 例: UTG QdQc open → BBコール → フロップ AK8。GTO戦略＝大サイズ基調のレンジベット、実プレー＝チェック。GTO戦略を理解していない → Step1へ。概ね把握している → Step2へ。

### Step1. GTO戦略を学ぶ — 3種類のレビューの区別

精度の高い順:
- **ハンドレビュー（効果薄）**: そのハンドのプレーラインが正しかったかだけを確認 → tips知識のみ。
- **レンジレビュー（推奨）**: 均衡的なレンジ戦略が想定できていたかを確認 → 戦略構築の妥当性を検証。
- **戦略レビュー（最上級）**: 自分の思考過程をもとに戦略構築プロセス全体を辿り、問題を整理 → 実践的知識を習得。

レンジレビューの手順（AK8ボード例）: ①レンジアドバンテージ確認（EQグラフ。UTGレンジ勝率66.6%＝レンジ有利）→②ベットサイズごとのハンド構成分析（124%ベット時: ナッツ級=KK・88セット/強いバリュー=AK・AQ・AJ/ブラフ=Kの低キッカー・QQ以下ポケット・78s・89s・QJ・QT・JT）→③ポジション差の理解（UTG vs BB=レンジベット主体、BTN vs BB=ポーラーベット主体）。

誤解の原因分析: 「AKハイはポーラーベット（だからチェックもあり）」と誤解する原因は、BTN vs BB の戦略を UTG vs BB に流用したこと（**ポジションの取り違え**）。

戦略レビューの5ステップ: ①自身の均衡乖離を把握 →②問題点の原因を振り返る（なぜそう考えたか）→③誤った思考の源泉を特定（ポジション無視・状況の混同）→④改善知識を獲得（「ポジションによって戦略は異なる」）→⑤実践の意思決定に反映（AK8を見た瞬間に「レンジベット」が着想できるか）。

### Step2. EVの源泉を理解する

- **EVの議論とExploitabilityの議論を分離する**:
  - EVの議論: 「33%〜125%でEVは等価であり、checkのEVは低い」。
  - Exploitabilityの議論: 「そのような混合比（ミックス）を持っていること」自体の是非。
  - この2つは本質的に別問題。
- **Node Lock機能の誤用への警告**: 相手戦略をnode lockして「合っていたからOK」で終えるのは、初級ハンドレビューを高度化させただけ（思考プロセスのレビューにはならない）。
- EV源泉の追求（QQの125%ベット例）: ターン以降を確認するとEVは0〜1付近＝**フロップのブラフ成功に大きく依存**。最も大事な問いは「フロップでのブラフ成功がEVを上げるか」。Node Lockで相手応答をシミュレーション（A＋グッドキッカーの降り率が下がる→ブラフEV減少、FDのコール率が上がる→ブラフEVは特に低下しない）。
- Exploitabilityのケア: 自身の戦略をロックして相手のカウンターを調べる。チェック範囲が濃くなると相手は「効果的なナッツ」でプローブベットしてくる。対策＝チェック範囲にも強い手を混ぜる／プローブへの応答を用意。
- 結論: 実践的に最適なExploitは複合的な理由を考慮して得られる。単なるnode lock検証でなく、EV源泉の理解・Exploitabilityへの配慮・多要因を統合して選択肢を評価する。
- ツール活用: GTO Wizard＝座学で高速に多数のスポットを確認・膨大な均衡アーカイブ。PioSOLVER＝検証時の精度（アキュラシー）変更が可能で詳細な精度調整に優れる。

## 用語集

- **GTO（Game Theory Optimal）**: exploitされない、相手のどんな戦略にも0以上のEVを保証する均衡戦略。2人ゼロサムでのEVは0。
- **非協力型ゼロサム不完全情報ゲーム**: ポーカー（およびじゃんけん）のゲーム理論的分類。
- **Exploit（エクスプロイト）/ adjust（適応）**: 相手の偏り（非均衡戦略）につけ込み、GTO以上のEVを狙う考え方。相手の戦略を知っている必要がある。
- **MES（Maximally / Maximum Exploitative Strategy、最大搾取戦略）**: exploit戦略のうち最もEVが高いもの＝相手戦略へのベストレスポンス。命題「GTOに対するMESはGTO」。
- **メタゲーム**: exploitとexploit返しの読み合いの層。
- **EV（期待値）**: 平均的に得られるはずのチップ量。+EV / -EV。
- **EQ（エクイティ）**: チョップまで考慮した勝率的取り分。EQ = 勝率 + チョップ確率/2。
- **Odds（オッズ）**: 勝ったときの見返り＝獲得チップ/危険に晒すチップ。必要勝率 = 1/Odds。判定は EQ > 1/Odds。
- **EQR（Equity Realization、エクイティ実現率）**: 現状EQをどれだけ利益化できるか。全EQを実現できるのは即All-in時のみ。生EQと正味EQは異なる。
- **インプライドオッズ**: ドロー完成時に将来得られる追加チップを織り込んだ実効オッズ。
- **2倍4倍の法則**: 残り1枚でアウツ×2%、残り2枚でアウツ×4%が、そのカードを引く概算確率。
- **アウツ**: 相手をまくるのに必要なカード（枚数）。
- **純粋戦略 / 混合戦略**: 純粋＝1アクションを100%。混合＝2つ以上を確率で選ぶ。混合される各アクションのEVは等しい（インディファレント）。
- **Nash均衡**: 各プレーヤーが自分の戦略だけを変えてもEVが向上しない戦略の組。混合戦略により存在が担保される。GTOはNash均衡から来る。
- **インディファレンス（無差別）/ 無差別の原理**: 複数アクションのEVが等しい状態。均衡のブラフ頻度は相手をcall/foldで無差別にするよう決まる。
- **千里眼ゲーム（Clairvoyance Game / AKQゲーム）**: ポラー vs キャップの最小トイモデル。EQ等でもEVに一方的差が出ることを示す。
- **linear / capped / polarized**: レンジの三類別。linear＝強い順、capped＝上限あり、polarized＝ナッツとエアーの二極（ミドルなし）。
- **被支配戦略（Dominated Strategy）**: 相手戦略によらず、確実により利得の高い別戦略が存在する戦略。
- **α（アルファ）**: ポラー側のブラフ比率を決める値。α = b/(b+p)。バリュー:ブラフ = (b+p):b。
- **MDF（最小防御頻度）**: コーラー側が守るべき最小のcall頻度。MDF = p/(b+p)（＝p/(p+b)）。
- **Geometric Betsize（幾何級数的bet）**: 各ストリート同倍率でベットを重ね、最終的にスタックを使い切る（オールイン）サイジング。ポラライズの基本。
- **ne size**: n回のベットでオールインに入れきるGeometricサイズ（3e、2e等）。
- **SPR / SRP**: SPR=スタックポットレシオ、SRP=シングルレイズドポット。
- **Robust Equity（堅牢なEQ）/ Vulnerable Equity（脆弱なEQ）**: 相手のアクションで減少しにくいEQ（ナッツ級を構築できる）／減少しやすいEQ（A以外のワンペア等）。
- **EQ Component（EQの構成要素）**: 1つのハンドに同居する複数のEQ（ドロー分・昇格分・現状ワンペア分など）。ロバスト性はグラデーション。
- **anchor（アンカー）**: call優先で守りたいミドル帯が、碇のようにトップレンジのraiseを妨げる現象。
- **shift**: ボード進展に伴うレンジ相対強度の変化。River bluffの下限を見極める鍵。
- **pure bluff / id bluff（indifferent bluff）**: 単にbluff EVが高いbet／checkと無差別で頻度のために打つbet。
- **check EV / bluff EV**: River bluff判定は同一ハンドのこの2つの大小で決まる（check EV < bluff EV → bluff）。
- **Wpolar-game**: Riverの4群モデル（1群=弱Air/3群=弱Nuts=OOP、2群=強Air/4群=強Nuts=IP）。OOPが弱側ポラーを持つ構図。
- **頻度構築**: 相手の特定の群をindifferentにすることを目標としてアクション頻度を組むこと。綻び＝Exploitの隙。
- **Key Pocket**: 「後ろの人数 + 5」で決まる、そのポジションのopen下限ポケットの数字（UTGはTT）。
- **Polar 3bet / Value 3bet / Bluff 3bet / Merged Range**: 3betの構成。強Value＋弱Bluffの二極、純Value、下限ブラフ、その間を補完するレンジ。
- **Cold Call / Over Call（Odds Call）/ Cold 4bet / Squeeze**: それぞれ、openへの横コール／安いopenに対しフロップを見に行くコール／open→3bet後の再々レイズ／CC後の再レイズ。
- **Value bet / bluff bet**: callレンジに勝って初めて成立するbet／相手を即座に降ろすためのbet。
- **Elasticity（弾力性）**: bet sizeで相手の抵抗レンジの強さが弾力的に変わる性質（50%→40%降り、75%→50%、125%→60%）。
- **Protection（プロテクション）**: Flop/Turnで捲り目のある相手を安く降ろすこと自体の価値。Riverには存在しない。
- **CB（継続ベット）/ DB（ダブルバレル）/ XR（チェックレイズ）/ ドンクベット / ドンクジャム**: PFアグレッサーの継続ベット／ターンの2発目／チェック後に相手のベットへレイズ／オリジナル前にOOPが先打ち（初心者は禁止）／ドンクのオールイン版。
- **01（ゼロワン）ゲーム**: 0〜1の乱数でハンド強度を表すトイゲーム。EQとベットサイズが単調対応する均衡モデル。
- **拮抗レンジ / EQの切り離し / EQの押し上げ**: Riverで抵抗してくるトラッシュ除外後の相手レンジ／トラッシュを相手レンジから除く補正（Figure1）／見かけEQを拮抗レンジ基準で下方修正する補正（Figure2）。
- **ナッツ / トラップ**: そのボードの現状最強ハンド／01ゲームで最上位を各ベットサイズに混ぜて残すこと。
- **Manhattanグラフ**: ハンドをEQ順に並べて戦略頻度を可視化したグラフ。
- **リンプ（Limp）**: PFで最低額をコールして参加すること。本記事群では原則禁止（ライブ環境の項は例外的に言及）。
- **オリジナル（オリジナルレイザー）/ OOP / IP**: 前ストリートで最後にレイズした人／先にアクションする不利な位置／後にアクションする有利な位置。
- **Ante**: MTT等で全員が事前に払う強制ベット。あるとレンジが全く異なり、Cashとは別ソリューション（別課金）。
- **Node / Node Lock**: ゲームツリー上の意思決定地点／相手が非均衡のとき自分の対応を計算する機能（誤用注意）。
- **RNG mode / Blunder / Inaccuracy / Simplified**: Trainerで頻度通りを求めるモード／採点区分（EVloss特大／Wizard上3.5%以下の軽微なズレ）／ベットサイズ等を簡略化した高精度解。
- **EVpoker / 快楽poker**: 期待値を追求し運を排除するプレー／楽しさ優先で運に依存するプレー。
- **solver+**: piosolverの代表的計算結果を保存した、ライブ中にスマホで参照できるアプリ（ノードロック不可等の制約）。

## 実戦チェックリスト

### 概念・思考
- [ ] 相手不明ならGTO寄せで搾取されない土台を作り、逸脱が明確に見えた所だけexploitへ振る。「GTOに対するMESはGTO」。
- [ ] 各アクションはレンジに基づいて行う。ハンドを見る前にレンジから戦略を組み、最後に自分のハンドを見る（Lv3）。
- [ ] 混合される各アクションのEVは等しい。混合比率を守ることが被Exploit耐性。頻度を守るなら乱数化する。
- [ ] 「EQが高い＝EVが高い」ではない。良いレンジはEQでなくEVの高いレンジ。

### プリフロップ
- [ ] 参加するならレイズで入る（BB・BTN以外はコール参加・リンプをしない）。相手がリンプしたら人数分を上乗せしてopen。
- [ ] サイズ: Open（UTG/HJ 2bb・CO 2.3bb・BTN 2.5bb・SB 3bb／初心者簡略版は2.5〜3倍）。3bet IP約3倍・SB約4〜5倍・BB約5〜6倍。4bet IP2〜2.2倍/OOP2.5〜2.8倍。5betはAll-in。
- [ ] 3betに横からコールしない（CCはBTNのみ）。Key Pocket（後ろの人数+5）でopen下限ポケットを思い出す。
- [ ] BB defenceは広くcall＋約1回に1回はraise。強い手を片っ端から3betせず、3betできるレベルまでcallに回してからValue3bet→Bluffを足しPolar化。

### ポストフロップ（Flop/Turn）
- [ ] OOPはオリジナルまでcheckで回し、ドンクベットを打たない。オリジナルはCBを高頻度（50〜100%）で打つ。
- [ ] betは絶対金額でなくpot%で決める。Value betの可否は「相手のcallレンジに勝っているか」で判断する。
- [ ] ある程度強い手を、打つことでValueでなくなる大きすぎるサイズで打たない（禁忌級のミス）。
- [ ] サイズ目安: 50%で相手は弱い手40%、75%で50%、125%で60%を捨てる。33%small betはProtection効果があり、強弱どんな手でもチェックのように打ってよい。
- [ ] 自分の手を見る前に、打ちうる全betサイズを想定し、各サイズに「より大きく打てる強い手」と「bluff」の両方を配置する。
- [ ] bluffはdraw良型の"中EQ"ハンドから選ぶ（semi-bluff）。EQ最低の手ではない。
- [ ] ミドル帯（anchor）が自レンジにどれだけいるか意識する。多いとraiseを控え、EQが小さく切り捨ててよいなら切り離してアグレッシブに。
- [ ] ポラライズの基本はGeometric（同倍率を重ねてオールインへ）。「大サイズ＝損」は誤り。

### River
- [ ] Protectionが無いので、Value/Bluffを厳密に判断する。
- [ ] RiverでレンジEQが高くても即ベットと考えない。多くの解は低頻度・極小ベットかチェック主体。
- [ ] 相手のトラッシュは無抵抗で降りると想定し、切り離して「拮抗レンジ」に対しEVを測る。見かけEQは押し上げられているので下方修正する。
- [ ] Riverのbluffは check EV と bluff EV の大小で決める（check EV < bluff EV → bluff）。自レンジで弱い順に探す。
- [ ] 役がある程度強いspotはbluff過少になりやすい。「ある程度強い手を持つとき下限を疑う」。shiftを追跡する。
- [ ] Riverモデルを複数持ち、現在の状況が 01ゲーム / AKQ（ポーラ）/ Wpolar のどれに近いか当てはめる。誰がポーラ側かで戦略は真逆。

### 学習・ツール運用
- [ ] 初心者・大半はPioよりGTO Wizard。プランはPremium以上。CashとMTT（Ante）は別課金。
- [ ] 登録時にアフィリエイトURL（gtowizard.com/p/名前）で初回10%割引（登録時に確定、後から変更不可）。
- [ ] Study/集合分析（キー4）＋FilterでボードごとのEV・頻度傾向を俯瞰。TrainerはShow hints必ずOFF、RNG mode Lowで頻度まで練習。Range Builderで25%刻みに塗り100%適合を目指す。
- [ ] Wizardをベースに、疑問が残る細かいスポットだけPioで精度を上げて計算し直す（Range Copy）。スマホが重ければ言語を英語に。
- [ ] レビューは結果でなく思考プロセスをレビューする。ハンド<レンジ<戦略レビュー。EV議論とExploitability議論を分離。node lockで「合っていたからOK」で終えない。

## ライブ実戦メモ：Macau地下労働日記

（記事: 「Macau地下労働日記」。完全無料。2023-2024年末年始、マカオで100/200香港ドル NLHE・10max中心、約30時間プレイの体験記）

### 客層・ゲーム観察（核心）
- 10maxで半数以上がlimper。エニハンリンパーが約10%出現し、K2o/Q4o/34o/73s級の弱ハンドが頻出。
- 3betはプレミア級のみ（ATを見たのは1度程度）。limp potは3〜5way、iso potは2〜4wayが標準。
- ポストフロップは素直＝当たっていなければベットしない。raiseはtopヒット以上を約束。ブラフは発作的でほぼアンダーブラフ。

### レンジ運用（マルチウェイ・ライブ特化）
- 後ろの人数が多いと必ずlimperが入る前提で**マルチウェイ想定のオープン**を組む。KJoのようなスチール依存ハンドは削り、ポケットペアはピュアにオープン。
- vs limp: スチールとしてのisoは通じない。limpレンジは「弱い」のではなく弱ハンドの含有量が多いだけでAKまで混じる → **バリューレイズ主体**。ローポケットはover limp、スーコネ(T9s付近)はover limpとisoがindifferent。
- vs open: 相手のlimp頻度で調整。通常型には標準レンジで3bet、高limpレート相手は少しタイトに。3betでほぼHU化し、4betは超プレミア（QQまでsnap fold可）。
- vs 3bet: JJまで基本fold検討（相手依存）。AKの4betは非利益的で以降fold寄りへ。vs 4bet: 全てsnap fold（AA級のみ継続）。

### 収支・分散・資金管理（生計/バンクロール視点）
- 収支の実感: 「耐えて耐えて-3bb下山→10bb増、たまにご褒美ジャンプ」。全potが10bb以上で強ハンド1枚が10bbを確約、HU化で100bbチャンス。**分散が非常に低いゲーム性**。
- 資金管理: 「5BI下ブレたら発狂と言われ200万持参 → 正しかった」。**低分散でも下ブレは起きる前提**で、レートに余裕あるバンクロールを用意する。
- 実績: 開始直後-200bb → 回収して最終+75bb（約30時間）。

### 学びの要点
- 弱者の多いパッシブなライブ環境では「ブラフでの奪取」より **「バリュー最大化」と「マルチウェイ前提のハンド選択」** が効く。EPが5〜6人降りてくる局面が大チャンス。
- 実例: BTN rec 3bbオープン → SB(Amu) T9o 3bet 10bb → BTN call → Flop A34tt x/x → Turn 8 で50%/call → River 9 で50%→allin/callされバリュー獲得。
- 言語・交渉・席取りなどEV以前のライブ環境適応（メタスキル）が実収益に効く（中国語の数字は必須級、Google翻訳表示での交渉が有効）。

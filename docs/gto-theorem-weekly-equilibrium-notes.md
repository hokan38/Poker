## poker学習のロードマップ（Level1〜5）

著者が示す学習の全体観。上達を5段階に分け、飛ばさず順に埋めることを説く。**週刊均衡シリーズ本体は Level3（均衡思考）を主対象**とする。

| Level | テーマ | 中身 | 期間目安 |
|---|---|---|---|
| **L1** | blunderの回避 | 明確な悪手（禁忌）を犯さない | 1〜2ヶ月 |
| **L2** | PFの精緻な暗記 | プリフロップを細部まで完璧に | 2〜3ヶ月 |
| **L3** | 均衡思考の習得 | レンジ vs レンジの思考（本シリーズの主対象） | 1年以上 |
| **L4** | お気持ちExploit | 均衡を土台に感覚的な搾取のまねごと | 3〜6ヶ月 |
| **L5** | Exploitの習得 | 相手の「戦略」全体への最適反応 | （明記なし） |

- **L1 禁忌の例**: limp donk / 3bet横コール(3cc) / IPのRiver小ベット / キャッシュOOPで3倍以下の3bet。信頼できる人に「禁忌だけ」指摘してもらう。
- **L2**: 「プレイの質問の5〜7割は"そもプリ案件"（プリフロップ自体が誤り）」。**PFを精緻に覚える価値を低く見る人は弱い**。覚える例＝SB CC vs UTG / BB over call / BB 3bet vs UTG / BTN vs SB 4bet / SB vs BTN 5bet Jam / SBスクイーズ。solutionは **nl50 general GTO-GTO 100bb** を1つ固定して詰める。
- **L3（核心）**: 均衡思考＝**バランスの取れた戦略構築**。要素＝「全spotでbluffを用意／降りすぎない／callしすぎない／bet sizeをレンジから決める」。本質は**レンジ vs レンジ**。このLevelでは**相手へのExploitは一切考えない**。目標は「**均衡がなぜそうなるかを人に説明できる**」こと。
- **L4**: （特にターン以降で）**乱数を捨て**、相手のvalue過多/bluff過多を判断してpureにアクション。危険サイン＝「Exploitが得意だと思う／GTOをあまり勉強していないが強いと思う」→ **L3欠落**の疑い。
- **L5**: 「ハンドvs戦略」「戦略vs戦略」で考える。お気持ちExploitは行き当たりばったりにすぎない。正しいExploit＝**常に相手の戦略全体に思いを馳せて自分の戦略を組む**。
- 進め方: 各Levelを**95%の自信**まで詰めてから次へ。記事は GTO Wizard **premium plan以上**推奨、基本 nl50 general GTO-GTO を使用。記事構成は「①例題 →②解説 →③応用/練習」。

## Stage1-1：Call判定均衡思考の型

唯一フルに読めた理論記事。**フロップで相手のベットに直面したときのCall/Fold判定**を、感覚でなくレンジ思考で行う「型」を教える。

### 核心：Call/Fold判定の3ステップ
1. **サイズ→降り頻度**: 相手のベットサイズから、自レンジ全体で理論上どれだけ降りるべきか（fold頻度）を出す。
2. **レンジを弱い順に切る**: 自分の保有レンジを強度順に並べ、**弱いハンドから順に「降り群」**を選ぶ。
3. **自ハンドの位置判定**: 自分の実ハンドがその降り群に入るかを見て Call/Fold を決める。

> 要点：「**このハンド単体で守れるか**」ではなく「**レンジ全体でどれだけ守るべきか → その中で自分は降り群か**」の順で考える（ハンド単位でなくレンジ単位）。「Ahiだから」「トップペアだから」という**絶対的ハンド強度での判断を排す**のが均衡思考の第一歩。

### 例題（無料公開部分）
- 状況: **BTN vs BB**、フロップで BTN の **33% CB** に BB が直面。
- 境界付近のハンド例: **Ad4d / QJ / Ahi**。
- 誤り例: 「エースハイだからコール」という単体・直感判断 →**均衡思考ではない**と否定。
- 型: 33%から必要な降り頻度を逆算 → BBの全レンジを強度順に把握 → **降り群／継続群の境界線**を引く → 自ハンドがどちら側かで決める。
- ※MDF/αの明示的計算は **Stage1-2（メンバー限定）** で扱う、と目録に記載。1-1は「サイズ→降り頻度→弱い順に切る→位置判定」という**手順の型**まで。
- 練習: GTO Wizardで BTN vs BB の Flop CB に対する BB の Call/Fold を**多数のボード**で反復。

## このシリーズの学び方（読めた範囲から）

- **均衡思考＝レンジ vs レンジ**。個々のハンドの強さでなく、**自レンジ全体でどう振る舞うべきか**から各アクションを決める。
- 判定の共通の型：**①サイズ／状況から頻度（fold頻度・bluff頻度）を出す →②レンジを強弱で並べる →③自ハンドの位置で行動を決める**。Call判定・Bet判定・Bluff判定はいずれもこの型の応用。
- **Exploitは最後**。L3（均衡）を「説明できる」まで固めるまで、相手の搾取は考えない。順番を飛ばした自称Exploit巧者はL3が抜けている、というのが著者の一貫した警告。
- ツールは **GTO Wizard（premium以上）**、**nl50 general GTO-GTO 100bb** を基準solutionに固定して詰める。

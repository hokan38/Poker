## マルチウェイポットでの10のヒント

- **出典**: https://japan.gtowizard.com/blog/10-tips-multiway-pots-in-poker/
- **概要**: 3人以上のポットではナッシュ均衡がEVを保証せず、ヘッズアップの原則がそのまま通用しない。防御分担・ナッツ級ポテンシャル・エクイティ保持力を軸に、マルチウェイ特有の10の調整指針を示す記事。

**要点**:
- マルチウェイでは「搾取されない戦略」が存在せず、GTO的な均衡戦略でもEVは保証されない。相互エクスプロイトの余地が常に残る。
- **防御責任は複数人で掛け算的に分担**される。全体フォールド率 = 各プレイヤーのフォールド率の積。1人あたりのMDF目安はαのn乗根（α = s/(s+1)、s = ベット/ポット比、n = 相手人数）。
- 例: 10%ポットベットに対し、ヘッズアップならレンジの約91%を防御すべきだが、8人ならひとり約26%でよい。1%ポットベットでもHUで約99%に対し9人なら約44%。→ **エアの純粋ブラフはリスクリワードが極端に悪化**（バリューのポットオッズは不変）。
- **レンジベット（全レンジ小サイズCB）は放棄**する。相手が広く防御する必要がないため、HUで得ていた追加フォールドエクイティが消える。ミドル級はチェックに回し、バリューラインを絞り、チェックフォールドを増やす。
- ハンド評価の軸は「生の強さ」より**ナッツ級ポテンシャル**。例: A♠Q♠8♥ で 6♠4♠（弱フラッシュドロー）は価値が低く、K♠7♠（ナッツFD）は高い。完成時にナッツになれないドローでのセミブラフは控える。
- **エクイティ保持力（コールされたとき残るエクイティ）が急落**する。例: A♣T♣2♠（NL500）でオーバーベットすると、3ウェイでは A2（ツーペア）や AK でさえ防御側上位25%レンジに対しエクイティ50%を割る。→ HUでは適正なオーバーベットがマルチウェイではオーバープレイになる。
- インプライドオッズ／リバースインプライドオッズが両方増幅され、ディープスタックに似た力学になる。オールインのバリュー基準は厳しくなり、スーテッドコネクタやナッツフラッシュ系の「伸びしろのある」ハンドの価値が上がる。
- **ベットサイズは小さめが基本**。オーバーベットが許されるのは、ナッツアドバンテージを持ちナッツ級でスタックを狙える場合のみ。
- **ポジションの価値は人数とともに増幅**。例: 500NL 200bb、CO 2.5bbオープンに対し、BTNは約44%防御、SBは約36%防御（BTNが約8%広い）。前後に挟まれる「monkey in the middle」ポジションは特に不利。SBのコールドコール後、BBはオッズが良くてもタイトに守るべき。
- **ブロッカー効果も増幅**する。例: 500NL 6max 200bb UTGオープンで、AKは22よりブラインドスチール頻度が7.3%高い（AKは継続レンジをブロック、22はフォールドレンジをブロック）。ポストフロップでは「ナッツをブロックする」ことが重要で、「フォールドをブロックする」のは逆効果。
- キャップされたレンジはマルチウェイでは**搾取されにくい**（防御負担が分散するため）。スクイーズレンジは非常にリニアでトップヘビーになる（例: BB vs UTG vs SBコールドコールでは、HUよりプレミアム偏重でよい）。逆に、**マルチウェイでチェックが回り続けた後のレンジは非常に弱くキャップされる**ため、リバーでの積極的なブラフが推奨される。

**実戦への適用**:
- マルチウェイに入ったら、まず「純粋エアブラフ禁止・ミドルはチェック・バリューは絞る」を初期設定にする。
- ドローで打つ前に「完成したらナッツか？」を自問する。ノーならチェック寄り。
- サイズは小さく。ツーペア程度でのオーバーベット／スタックオフはHU感覚の典型的オーバープレイと心得る。
- 全員チェックで回ったリバーは相互にキャップ状態。ブラフとシンバリューの好機として攻める。

## 3ウェイポットで挟まれたときの戦い方

- **出典**: https://japan.gtowizard.com/blog/monkey-in-the-middle-3-way-pot-heuristics/
- **概要**: 3ウェイで小さいCBを受けたとき、後ろにもう1人残っている「中間ポジション」の応答はHUの直感と大きく異なる。フォールド増・小サイズレイズ増という反直感的な構造と、その理由（残存アクション・強いCBレンジ・第三者からのエクイティ奪取）を解説する記事。

**要点**:
- 比較例（T♠7♥4♠、25%ポットCBに対する応答）: **HUでは** フォールド約10%／コール約73%／レイズ約17%（約50%サイズのポーラーなレイズ）。**3ウェイ（CO-BTN-BB、BTNが中間）では** フォールド約31%／コール約39%／レイズ約30%（最小25%レイズ中心の非ポーラーな構成）。
- フォールドが増える理由①: **後ろにアクションが残っている**。BBがコールすれば2人に勝つ必要があり、レイズされれば投資を失う。小さいCBのポットオッズは見た目ほど良くない。
- 理由②: **CBレンジ自体が強い**。2人相手に打つCBはHUより強く、弱いペアの勝率も改善しにくく、ブラフも通りにくい。
- 理由③: レイズには**第三者（BB）からエクイティを奪う**追加価値がある。例: T♠7♥4♠ で JTo のエクイティは約47〜52%だが、BTNの25%レイズにBBがレンジの約85%をフォールドすると **60〜63%まで上昇**。レイズの標的はCOではなくBBの弱さ。
- 具体数値: 12.8bbポットへの3.2bbの小レイズがBBのフォールド頻度を40%押し上げる。ただしBBが一度コールした後はフォールド頻度は45%程度まで低下する。
- **コールドコーラーが中間の場合は別物**。HJ-CO-BTNのようにBTNがコールドコーラーだと、そのレンジはBBのオーバーコールよりずっと強く、フォールドしにくい（例: COはコール53%／レイズ7%）。単体OESDのような弱いドローはそもそもレンジにない。
- **ドライボードでは構造が変わる**。K72r ではBBにドローが乏しく、CO（中間）のレイズは約16%・コール約54%（T74tt のレイズ約30%・コール約39%と対照的）。BBのフォールドは約68% vs T74tt の約45%。ポーラー化が進むとレイズ頻度は下がる。
- **CBサイズが大きくなるほどレイズのEVは低下**。50%CBに対してはBBがガットや弱ペアの70%をフォールドし、CO側レンジのポーラー化も進むため、リスクリワードが悪化しコール／フォールドに寄る。

**実戦への適用**:
- 3ウェイの中間で小CBを受けたら「HUよりよく降り、レイズは小さく・広く（非ポーラーに）」を基本形にする。
- レイズする前に「これで後ろの第三者から奪えるエクイティはどれだけか」を評価する。ウェット＋後ろが弱レンジ（BBオーバーコール型）ほどレイズ価値が高い。
- 中間が自分でなく相手のとき、その相手がコールドコーラーならフォールドエクイティを過信しない。
- CBが大きい（50%以上）ときはレイズを絞り、コール／フォールド中心に切り替える。

## 3ウェイポットでのプローブベット戦略

- **出典**: https://japan.gtowizard.com/blog/probing-out-of-position-in-3-way-pots/
- **概要**: 3ウェイではフロップがチェックで回っても相手レンジがキャップされているとは限らない。BBのターンプローブは相手のチェック頻度ではなく「自分のナッツアドバンテージ」で決まる、という検証記事。

**要点**:
- HUのヒューリスティック「プリフロップレイザーがCBを飛ばしたらレンジはキャップ」は3ウェイでは成立しない。OOPのプレイヤーはマルチウェイでは強いハンドも広くチェックする。
- 検証で否定された仮説: 「プローブ頻度はCO/BTNのフロップチェック頻度と相関する」→ 様々なボードで明確な相関は観測されなかった。
- 実際の決定因子は**BB自身のナッツアドバンテージ**。プローブを決めるのはレンジの弱い部分ではなく、BBが相応の強コンボ（トリップス・ストレート等）を持てるかどうか。
- プローブ条件は二段構え: ①フロップ構造がBB寄り（例: K77r、765tt のようにBBがトリップスやストレートを作れる）、②ターンカードがBBのナッツ優位をさらに高める。
- 好例: K♠7♦6♣ + 5♦ ターン。ストレートやツーペアがほぼBB側にしかなく、プローブ頻度はほぼ100%・サイズは100%ポット一択。
- 同じ K76 でもターンが K なら頻度約100%のまま **100%ポットと67%ポットの50/50** に分かれ、ターン 2♣ ならツーペアを持っていてもプローブはごくわずか。「ナッツ優位が立ったか」が全て。
- ナッツ不利ボード（K76モノトーン気味、T98r など）では、フロップが全員チェックでもBBは強いハンドすらチェックを続ける。
- サイズの使い分け: **100%ポット（ポーラー）** = ナッツ優位が大きいときの標準。**67%（小さめ）** = 双方のエクイティが拮抗し、優位がレンジの弱い部分（ペア+ドローなどリニアなハンド）に集中しているとき。小サイズはレイズに弱いリニアハンドを含むため、レイズで得をするナッツ級を混ぜてバランスを取る必要がある。
- 例外例: T75r 系はブランクターンではほぼプローブせず、打つ場合も小さめ。6のターンで頻度は上がるが小サイズ中心（優位が「頑健だが脆いエクイティ」の弱い部分に集中しているため）。

**実戦への適用**:
- フロップチェック回りだけを根拠にターンで自動プローブしない。「相手が弱い」ではなく「自分がナッツ側か」で判断する。
- プローブ前チェックリスト: このフロップで最強級コンボは自分のレンジにあるか？ このターンでその優位は強まったか？ 両方Yesなら大きく打つ。
- ナッツ優位が明確なら100%ポットのポーラーサイズ、拮抗ならナッツを混ぜた67%程度の小サイズ、優位なしならチェック継続。

## 3wayポットでコーリングステーションをエクスプロイトする

- **出典**: https://japan.gtowizard.com/blog/3-way-how-to-exploit-a-calling-station/
- **概要**: 「BTNのレイズ益はBBのフォールドから来ているなら、降りないBB相手にはレイズを減らすべきでは？」という読者の疑問をノードロックで検証。結論は逆で、コーリングステーション相手にはレイズ頻度をむしろ上げるべきという記事。

**要点**:
- 前提となるGTO構造: CO-BTN-BB の T♠7♥4♠ 等で、BTNが小CBにレイズするとBBは最大40%程度フォールドし、OESD・非ナッツフラッシュ・多くのトップペアまで降りる。このフォールドがレイズのインセンティブ。
- 検証上の工夫: BBをステーション化するとCOのCB戦略まで変わってしまう（25/50%ミックス→ほぼ全て50%）ため、COのサイズを固定したカスタムソリューション＋ノードロックで、**トップペア・OESD・FDを絶対に降りない極端なBB**を作成。
- 結果: BTNのレイズ頻度は **13% → 19%（+6ポイント）と大幅増**。フォールドもわずかに増加（＝コールが減り、戦略が「降りるか上げるか」に二極化）。
- 副次的変化: COのベット頻度は 23% → 31% に増加。ただしレンジ構成比（強/中/弱）とエクイティはほぼ不変。
- ハンド別の変化: ステーション相手にBTNは 77・44 などのポケットペア、AT・KT・QT などの弱ブロードウェイでレイズを増やす。
- 反直感的な例外: **JTo のレイズはむしろ微減**。GTO相手には支配されたトップペアを降ろせる価値があったが、ステーション相手ではそのフォールドエクイティが消え、BBのより強いトップペアに支配されるリスクだけが残るため。
- 核心の考え方: 「相手が降りてくれると得だからといって、コールされたら損だとは限らない」。レイズの真の目的はBBが**エクイティを実現するためのコストを吊り上げる**こと。降りればエクイティを失い、コールすれば割高な料金を払う——どちらもBTNの得。
- 合理的な相手へのレイズは「正しく降りざるを得ない状況」を作る搾取、ルース相手へのレイズは「悪いオッズで払い続けるミス」から利益を得る搾取。動機が違うだけでレイズ自体は正当化される。

**実戦への適用**:
- 「降りない相手にはブラフレイズ無意味→レイズ全体を減らす」は誤り。**バリュー寄りのレイズを増やす**のが正解。
- ステーション相手に増やす候補: 中ポケット（77・44系）や弱トップペア級（AT/KT/QT系）のバリュー／プロテクションレイズ。
- ただし相手のコールレンジに支配されやすいハンド（JTo的なセカンド級トップペア）はレイズを控え、コールに回す。
- エクスプロイトの評価軸を「フォールド率」単体でなく「相手のエクイティ実現コストをどれだけ上げられるか」に置き換える。

## ヘッズアップの上達方法

- **出典**: https://japan.gtowizard.com/blog/how-to-improve-your-heads-up-game/
- **概要**: 場当たり的な学習ではなく、プリフロップ→フロップ→見逃されがちなスポット→フルハンドという4レベルの体系的ドリル（計46個）でHU（特に浅いスタック）を鍛える学習ロードマップ記事。

**要点**:
- **レベル1: プリフロップ習熟**が全ての土台。初心者は学習時間の大半をここに割き、上級者も悪癖防止のために継続的にドリルする。High RNGモードで混合頻度プレイに慣れる。
- スタック帯の区分: **1〜5bb（オールイン/フォールドのみ）、5.5〜10bb、10.5〜16bb、17〜30bb**。有効スタック（チップ数ではない）が戦略を決定し、1〜2bbの差でも最適プレイは実質的に変わる。
- **レベル2: フロップの基礎**。リンプポット・チェックバックポット・レイズポットの3類型を、スタック帯別に分けてドリルし、GTOベースラインの頻度を身につける（相手の逸脱への即応力の土台になる）。
- **レベル3: 見逃されがちなスポット（ディレイベット）**。相手がCBを飛ばした後のディレイベット、リンプポットのディレイベット、プローブベット（SBリンプ-チェック後のBBの主導権）など。多くのプレイヤーが取り逃がす「イージーEV」で、意識的に狙うだけで勝率が目に見えて上がる領域。ドリルは8bb・14bb・25bbのスタック別。
- **レベル4: フルハンドシーケンス**。プリフロップからリバーまで通しでプレイし、レベル1〜3を統合しつつターン・リバー感覚を養う。
- 最適プレイの多くは単一アクションでなく「**複数アクションの頻度ミックス**」（3択以上の混合も多い）。RNGを使った確率的意思決定への慣れが必須。
- エクスプロイトの視点: 多くの対戦相手はソルバー推奨よりCB過多。チェックバック系ポットに搾取可能なパターンが生まれやすい。
- ドリルは計**46個**（レベル×スタック帯×ポット類型で構成、全てHigh RNG設定）。リンプポットはSB/BB双方の5.5〜10 / 10.5〜16 / 17〜30bb、レイズポットはSBアグレッサー/BBコーラーの10.5〜16 / 17〜30bb など。
- 上達の最重要因子は**一貫性（毎日の小さな積み重ね）**。提供ドリル修了後は、頻出ボードのうち自信が最も低いものをカスタムドリル化する。PokerArenaでリスクなしに実戦適用できる。

**実戦への適用**:
- 学習順序を固定する: プリフロップ→フロップ類型別→ディレイベット/プローブ→通しプレイ。トピックのつまみ食いをやめる。
- 有効スタックを常に帯（〜5bb / 〜10bb / 〜16bb / 〜30bb）で認識し、帯ごとに戦略を切り替える癖をつける。
- 相手がCBを飛ばしたターンは「イージーEV」の筆頭。ディレイベット／プローブの頻度を意識的に確保する。
- 毎日短時間でもドリルを続け、プリフロップは上級になっても定期メンテナンスする。

## このカテゴリの横断まとめ

1. **HUの直感はマルチウェイに持ち込まない**。防御義務は人数で掛け算的に分散し（MDF ≈ α^(1/n)）、レンジベット・エアブラフ・大サイズの多くが機能しなくなる。
2. **人数が増えるほど「ナッツ級」への集中度を上げる**。ハンド評価の軸は生の強さからナッツ級ポテンシャルとナッツアドバンテージへ移り、プローブもオーバーベットもナッツ優位が条件になる。
3. **エクイティ保持力を常に意識する**。マルチウェイではコールされた後に残るエクイティが急落するため、サイズは小さく、ツーペア程度でのスタックオフはオーバープレイになりやすい。
4. **後ろに残るプレイヤーは脅威であり収益源**。中間ポジションではよく降りる一方、小レイズで第三者からエクイティを奪う（例: JToが47〜52%→60〜63%）価値が生まれる。
5. **アクションの意味は文脈依存**。フロップのチェック回りはHUと違いレンジをキャップしないし、コールドコーラーとオーバーコーラーではフォールド耐性がまるで違う。
6. **エクスプロイトの本質はフォールド率ではなく「相手のエクイティ実現コスト」**。降りない相手にもレイズは有効で、バリュー寄りに組み替えるのが正しい調整。
7. **キャップされたレンジは攻めどころ**。マルチウェイのチェックダウン後リバーは双方弱く、積極的なブラフ・シンバリューの好機。
8. **ブロッカーとポジションの価値は人数とともに増幅**する。継続レンジをブロックするハンドで攻め、フォールドレンジをブロックするハンドでは控える。
9. **上達は体系と一貫性**。プリフロップ→フロップ→見逃しスポット→通しの順で、スタック帯別・頻度ミックス前提（RNG）で毎日ドリルするのが最短経路。

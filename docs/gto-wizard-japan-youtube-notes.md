## GTOの基礎理論と数式

### GTO戦略とは何か

出典: [GTO戦略とは何か](https://www.youtube.com/watch?v=YF0Tfb7taFo)

**GTO（ゲーム理論最適）戦略**は、次の3つの性質で定義されます。

- **均衡の定義**: 両者が戦略を変更する動機（インセンティブ）を持たない状態。2人ゲームの均衡から片方の戦略を取り出したものがGTO戦略。
- **エクスプロイト不可能性**: もしエクスプロイトされ得るなら、相手は戦略変更でEVを上げられる＝そもそも均衡でなかったことになる（背理）。
- **EVの保証**: 相手がどんな戦略でも、均衡時のEVより減少することがない。ゆえに ①ミスをしない強豪相手に最適 ②全ての相手に「負け越さない」 ③相手のリークが読めない未知の相手に対して安全（下手にエクスプロイトを始めるとカウンターを食らうが、GTOにはそれがない）。

**ソルバーの仕組み（GTOの構築法）**: エクスプロイト合戦の反復。ランダム戦略Bに対する最適応答A′を作り、A′に対してB′を作り…と更新を繰り返すと、互いにエクスプロイトできない状態（均衡）へ収束する。「エクスプロイトをし切った先にあるバランス」がGTO。脳内では不可能なので、GTO Wizard（プリソルブドのアーカイブ＋Wizard AIによる未解決スポットの計算）で理解を深めるのが実践的。

**GTO vs エクスプロイト**:

- GTOは「消極的」＝堅牢。相手に大きなリークがあってもそこへEVを取りに行かない。誰にも負けない。
- エクスプロイトは「積極的」＝リークを直接攻めて利益最大化を狙うが、リーク想定の誤り・相手の戦略更新（カウンターエクスプロイト）で自分がマイナスになる脆弱性を持つ。

**相手のミスの2分類（最重要）**:

- **混合戦略のミス（頻度のミス）**: 均衡で例えば60%コール/40%フォールドすべきインディファレントなハンドを100%フォールドする類のミス。→ **GTOはここから利益を得られない**。
- **純粋戦略のミス**: 100%コールすべきハンドをフォールドする類のミス。→ **GTOが追加利益を得るのはこちらのみ**。

**特定ハンドのマイナスはレンジ全体で回収される**: 相手がナッツしか打たない状況でGTO通りブラフキャッチをコールすると、そのハンド単体は均衡EVよりマイナス。しかし相手のベット頻度が低い分、より弱いハンドで降ろされない・こちらのブラフのEVが上がる等で、レンジ全体のEVはプラスに保たれる。

**クイズによる確認**:

- クイズ1（6max 50NL 100BB、SBのGTOはリンプ混合）: GTO相手に「リンプを全くしない」戦略を採ってもEVは全く同じ。リンプ有無は混合戦略であり、混合戦略のミスはGTO相手にEVを損なわない。裏返すと、GTOをそのまま再現する側は相手の混合戦略ミスからのEVを取り逃している。
- クイズ2: GTO相手に「AA（推定）しかオープンしない」戦略はEVを損なう。本来オープンすべき（フォールド頻度ゼロの）ハンドをフォールドする純粋戦略ミスだから。
- クイズ3: 「AAしかオープンしない相手」にBBのGTO戦略のまま応答すると、長期EVはむしろ向上する。オープンされた局面のコール/3ベット単体は不利益でも、相手が他の全ハンドをフォールドしすぎているためウォークでポットを得る機会が増え、レンジ全体・全シチュエーションでEVが回収される。

**エクスプロイト採用の条件**: 相手戦略の仮定が必須。仮定を誤る／カウンターを受けるリスクと、混合戦略ミスからも利益を取れる・純粋戦略ミスをより大きく咎められるという利益最大化を天秤にかける。GTOの正しい理解はエクスプロイトの前提であり、GTOを盲目的に採用し続けるのも誤り。

### 必修の数式（ポットオッズ・α・MDF・バリュー:ブラフ比）

出典: [ポーカープレイヤーが必ず学ぶべき数式](https://www.youtube.com/watch?v=mtHfouTPm8Q)（18分19秒）

> **画面検証済み（2026-07-12）**: 本節は音声字幕の全文に加え、動画のスライド画面（サムネイル／ストーリーボード）と突き合わせて確認しました。実際のスライド構成は「Poker Mathematics（表紙）→ Pot Odds → Risk/Reward での再導出 → Value/Bluff比 → α（アルファ）→ MDF → 総合クイズ → GTO Wizard 実戦検証（ソルバー画面）」の順で、各スライドに `Pot size = …` / `Bet size = …` の数値と数式が板書される構成でした。字幕の読み上げ内容とスライドの数式は一致しており、下記の記述は画面表示とも整合しています。

4つの概念はすべて「**リスク ÷ (リスク + リワード)**」という共通の型から導けます。

**① ポットオッズ（＝コール側の必要勝率）**

- 定義式: **ポットオッズ = リスク ÷ (リスク + リワード)**。コール側のリスク＝コール額、リワード＝ポット＋相手のベット額。
- 例: ポット10BBに5BBベット → コール額5BBで合計20BBを争う → `5 / 20 = 25%`（リスク5、リワード10+5=15、5/(5+15)）。オッズ表記なら4倍 → 1/4 = 25%。
- クイズ: ポット5.4BBに2.7BBベット（50%ポットベット）→ `2.7 / (2.7+2.7+5.4) = 2.7/10.8 = 25%`。
- 意味: ポットオッズ25% ⇔ 必要勝率25%（4回に1回勝てば収支トントン）。

**② バリュー:ブラフ比率（ベッター側の必要ブラフ%）**

- 相手のポットオッズが25%（＝オッズ4倍）なら、ベッターは「4回中3回勝ち・1回負け」の比率、すなわち **バリュー:ブラフ = 3:1（ブラフ25%）** で相手をインディファレントにできる。
- コール側の「何%ブラフが入っていればコールできるか」と、ベッター側の「何%ブラフを入れるべきか」は**コインの表裏（同じ数値）**。

**③ α（アルファ）＝ブラフが利益的になるための相手の必要フォールド頻度**

- ブラフ側のリスク＝ベット額、リワード＝**ポットのみ**（降ろした時に相手のベット額は得られない点がポットオッズとの違い）。
- 導出: 損益分岐は `(1−F)×ベット額 = F×ポット` → **α = F = ベット額 ÷ (ベット額 + ポット)**。
- 50%ポットベット: `α = 0.5/(0.5+1) = 33%`。相手が33%より多く降りればブラフ有利、33%未満なら不利、ちょうど33%なら無差別。
- ポットオッズと同じ型だが、**リワードの中身が違う**（コール側: ポット＋ベット額／ブラフ側: ポットのみ）。

**④ MDF（Minimum Defense Frequency）＝降りすぎにならない最低ディフェンス率**

- **MDF = 1 − α = ポット ÷ (ポット + ベット額)**。
- 50%ベット: α=33% → `MDF = 67%`。「相手が33%まで降ろせて利益的」の裏返しで「自分は67%は守らなければならない」。

**総合クイズ（ベット＝ポットの60%）**:

- ポットオッズ = `bet/(pot+2bet) ≈ 27%` → バリュー:ブラフ = **73:27** → α = `bet/(bet+pot) = 0.6/1.6 = 37.5%` → MDF = 1−α = **62.5%**。
- ※このクイズはASR読み上げ数値（「ポット14.6BB / ベット5.5BB」）と公式解答（27%・73:27・37.5%・62.5%）が不整合で、解答はベット＝ポットの60%に完全一致するため、ベット額の聞き取り誤りと推定し**解答側を正**としています。

**ソルバーでの検証**（BTN vs BB SRP、NL50 100BB、K-J-x 2トーン: フロップ33%CBコール→ターン2チェックアラウンド→リバー7で60%ベット）:

- 理論値 α=37.5%・MDF=62.5% に対し、実際のBBフォールドは40.5%（α+約3%）、コール以上での防御は約60%（MDF近傍）。
- エクイティチャートでは、ベットレンジのうちエクイティ約27%以下（推定）がブラフ、バリューは約73%＝73:27の比率と整合。
- 実戦ではブラフの残エクイティやレイズの選択肢のためα/MDFから多少ずれるが、**リバーが最もトイゲーム（理論値）に近い**。

> 用語補足: これらの数式は姉妹ノートの「ポラライズ -レンジの類別-」（α=b/(b+p), MDF=p/(b+p)）とも一致します。

## プリフロップ体系

### プリフロップの仕組み（総論）

出典: [プリフロップの仕組み](https://www.youtube.com/watch?v=3l8av28PaxM)

- **プリフロップの重要性**: 全ポットはプリフロップから始まり、ポストフロップの全意思決定はプリフロップレンジを参照する。プリフロップ理解＝全ストリートの精度向上。
- **レンジの広さ＝プリフロップのポットサイズ（ブラインド）で決まる**: 思考実験として、SB/BBのポストが無ければBTNはよりタイトに（AA以外オープン不要）。だから**アンティあり＝オープン拡大**（MTTが広い理由）、**レーキ減＝実質ポット増＝オープン拡大**。
- **境界で覚える**: 頻度表の丸暗記より「T6sはオープン可・T5sは不可」「J4sは無差別」「J8oが参加境界」（BTN・50NL）のような損益分岐ハンドを覚える。境界ハンドだけ状況（3ベットが多い卓か等）でアクションを変えればアジャストになる。ポジション別境界のフローチャート自作が有効。
- **リニアとポーラー**:
  - **リニア**（強い順）: コール不要な場面（RFI、SBでコールドコールを作らない場合の3ベット）で優れる。
  - **ポーラー**（超強＋弱、ミドルはコール）: コールの必要がある場面で発生（BB3ベット、オープン後に3ベットを受けた際の4ベット＝AA/KK＋ATs・KTs等）。
  - **マージド**（中強度・高プレイアビリティも混ぜる）: 相手の抵抗が増える環境（レーキの安いNL500等）で、ポーラーに加えT9s・JTs等を3ベットに混ぜる。
- **ブラフの見分け方＝4ベットへの応答**: KJo・AJo・J6s等は3ベット後4ベットにフォールド（ブラフ扱い）、45s・56s等プレイアビリティの高いブラフは4ベットにコール。
- **プリフロップにもブロッカー**: BTNのオープンハンド別にBBの反応が変わる — BTNがAA保持ならBBフォールド59.3%（通常約56%）、22保持なら54.6%（推定）。どのハンドのオープン/3ベット頻度が上がるかの説明原理。
- **オープンサイズ理論**: 「コールが多く見込まれるなら大きく、レイズ（3ベット）が多く見込まれるなら小さく」。UTGは（スチール以外で）3ベットされる確率30%超、SBは20%未満でコールされやすい → レイトほど2.5〜3bbへサイズアップが正当化。ハンド別ではUTG/LJの2bb→2.5bbでJJはEV−0.14（3ベットに降りる筆頭候補）、QQ以上は大サイズが利益的 → 無頓着な相手にはQQ+だけ大きくオープンするエクスプロイトも可。
- **スタック深度**: 200bbのBB防御は100bbよりマージド化 — ナッツを作れないAxoの優先度が下がり、J9s・JTs・KJs・K9s等プレイアビリティ/インプライド重視のハンドが3ベットへ。HUの3ベットサイズは、7.5bbの小さい3ベットは50bb（オールインケア）と250〜300bbディープで好まれ、12.5bb付近は100〜150bbで好まれる。
- **ポジションEV（HU）**: BTN（SB担当・0.5bbポスト＋IP）のEVは50bbで約7.67、200bbで約15（単位はbb/100と推定）— ディープほどポジションの価値が拡大。
- **バンチングエフェクト**: 前のプレイヤーのフォールドはローカード寄り→フォールドが増えるほど残りのデッキ/プレイヤーにAが濃くなる。9maxのBTNオープンは22・46s・34s等のロー投機ハンドが消えA3o等Aブロッカー系が残り、フォールド人数の少ない3maxではローSC/ギャッパーが使える。
- **総括**: 各要因（ポットサイズ・レーキ・ブロッカー・サイズ・深度・バンチング）は独立に働く。アジャストは「各要因がEVを動かす方向」から導く。

### BvB（SB vs BB）プリフロップレンジ

出典: [BvB プリフロップレンジ解説](https://www.youtube.com/watch?v=hAQ39CRNZCY)（NL50 100bb 6max GTO Wizardソリューション基準）

- **SBの基本頻度（全員フォールド後）**: フォールド約51.5% / 継続約48.5%。内訳はコール（リンプ＝コンプリート）11.1%・レイズ37.5%。継続の約4回に1回はリンプ。
- **リンプの存在理由**: コール選択肢なしのSimpleソリューションではレイズ43%・フォールド57%となり、約5%多くフォールドを強いられる。リンプはSBの参加レンジを約5%広げる手段（既に0.5bbポスト済・後ろはBBのみなので広く参加したい）。
- **リンプは混合戦略の産物**: 「ピュアコールのみ」のハンドは存在しない。例: AQs（推定）はオープンEV1.61 > コールEV1.55でピュアレイズ、55はレイズEV=コールEV=0.3で無差別、Axローオフ（A2o〜A6o付近・推定）はレイズEV−0.01でコール/フォールドが無差別。簡略化するなら「レイズorフォールド」に寄せてもEV損は小さい（相手のアジャストには弱くなる）。
- **BBの応答＝ポーラー3ベット**: バリューはTT以上中心。ブラフはAxオフ（A2o〜A5o系）、Q/J/T＋弱オフスート、T5s〜T2s、J4s〜J2s付近（推定）。SBにコールレンジがあるため、強いハンドだけの3ベットは不可→ポーラー化。
- **レンジ表の読み方**: スーテッドは1セル4コンボ、オフスートは1セル12コンボ。ありがちなリークはA2o・A7o・K7o等のブラフ3ベット欠如。相手にこれが無ければ、SBはQ9s（推定）・J9s等の境界ディフェンスをフォールドしてよい。
- **SBの3ベット対応は4ベット偏重**: コールはわずか12.7%。4ベットブラフはAKo〜QJo・ATo付近の2ブロードウェイオフ中心＋K5s・Axs・9絡みスーテッド。4ベットオールインは頻度2.9%でAQo・AKo中心、低頻度でKJs・55。
- **レーキの影響**: NL50（高レーキ）ではブロードウェイオフのコールがほぼ消滅し4ベットに回る。レーキが安いNL500ではAJo・KJo・KQo・AQoの一部がコールに戻り、コール頻度＞4ベット頻度に逆転。

### SBからのCold Call

出典: [SBからのCold Call](https://www.youtube.com/watch?v=nRqZ9Grau78)

- **オープンサイズが最大の判定要因**: SBのコール頻度は vs UTG 2bb=6.2%（レイズ6.3%でほぼ50/50）、vs HJ 2bb=6.4%、vs CO 2.3bb=2.3%（レイズ11.5%）、vs BTN=0.5%。相手を2.5bbオープンにすると vs アーリー2.5bb=1.6%、vs HJ 2.5bb=2.1%まで低下。SBは0.5bbポスト済なので「2bbの安いオープンにはオッズでコール正当化、2.3〜2.5bbにはほぼレイズorフォールド」。
- **採用理由**: コールドコールが無いとミドルポケット（77〜TT）が3ベットレンジに入りすぎる／微妙なスーテッドを大量フォールドする羽目になる。2bbオープン相手なら77〜TTはピュア継続（低頻度3ベット＋高頻度コール）にできる。
- **BBの応答は減らない**: vs HJ 2bbのBBディフェンスは約45%。SBがコールしてもBBの防御は約45%のまま（コール33%・スクイーズ9.1%）。スクイーズハンドはAQo・AJo等の2ブロードウェイオフに偏る。**対照的に、BTNのコールドコールにはBBは10%以上多くフォールドする**（IPコールドコーラーは0.5bb未ポスト＆ポジション有りで強いレンジ、SBのコールドコールは弱め寄りのため）。
- **スクイーズへの対応は「ほぼ全フォールド」**: HJが抵抗した場合はほぼ全部フォールド（AKo・QQ等トラップの一部だけリスチールオールイン）。HJがフォールドした場合でもSBは約92%フォールド。
- **ポストフロップ（SBコール・BBフォールド・HU）**: SBは非オリジナルながら約18.8%でドンクベット。ミドル2枚連結ボード（Qハイ以下）等でスモールドンク多用。SBはポケット偏重、オープン側はハイカード偏重 — ポケットで薄いバリュー＋オーバーカードのエクイティ拒否が目的。オープン側のフォールドは21.1%のみ。

### BBからのPolarな3ベット

出典: [BBからのPolarな3ベット](https://www.youtube.com/watch?v=yB2PLCJlhXw)

- **レンジ形の分類**: 通常の3ベット（IPからの3ベット、SBのvs CO等）はリニア（強い順）。BB vs BTNはポーラー（超強＋弱、真ん中はコール）。BTN vs UTGは中間。
- **BBがポーラーになる理由**: 既に1bbポスト済＋コールすれば即フロップ、の2条件でBBはコールを大量に持ちたい。「強い順にレイズ・残り全部コール」だと ①コールレンジがキャップされ脆弱 ②リニアに強すぎるレイズに相手が降りすぎ、の2点で損 → 超強ハンド＋コールが苦しい弱ハンドの一部をレイズへ。
- **3ベットサイズは常識より大きい**: HJ vs UTG 2bb=6.5bb（約3.25倍）に対し、BB vs BTN 2.5bb=13bb（5倍超）、BB vs UTG 2bb=12bb（6倍）。後ろの残り人数が減るほど大きくできる（プレミアム衝突リスク減）。適正サイズの目安: vs UTG 2.5bbに対しHJ 7〜8bb → CO 7〜8bb → BTN 9bb → SB 10bb → BB 13〜14bb。
- **BB vs BTNの構成**: バリュー＝TT以上・AJs以上・AQo以上。ブラフ＝スーテッドコネクター、A5s/A4s（Aブロッカー＋ホイール＋ナッツFD）、Q2s〜Q4s・J4s〜J6s等の弱スーテッド、Axオフの一部。ブラフは「BTNのオープン下限＝自分の抵抗境界」から選ぶ（92s・72o等の純フォールドを無理に3ベットしない）。
- **低頻度ワイドブラフ＝ボードカバレッジ**: 境界より少し強いハンドにも低〜中頻度の3ベットを散らし、あらゆるボードに対応。この分を無視すると「強いところだけ3ベットするリニア・リーク」に退化する。
- **vs アーリー（UTG）は別物**: ピュアに3ベットしたいのはAA・AKs程度で、JJ・TTすらほぼ3ベットしない。ブラフは「コール境界より少し強い」ハンド（UTGがオープンしているAxs・Kxs・Qxs付近）。最弱ハンド（スーテッドギャッパー・オフコネクター）はUTGレンジに弱すぎてブラフ不適格。レイズ頻度は約5〜6%で大サイズ。
- **エクスプロイト視点**: 多くの人はBB3ベットをリニアに組む。相手にブラフが無いと読めれば大きく降り、自分は境界ブラフを装備して非対称を作る。

### IPにおけるCold CallとBvMCB

出典: [IPにおけるCold CallとBMCB](https://www.youtube.com/watch?v=TqRh_ItKrrE)

- **前提**: NL50 GTOのUTGオープンは2bb。安いオープンにIPが降りすぎるとアーリーに安価なスチールを許すため、一定の抵抗（コール以上）が必要。「EPオープン→IPコール→BBフォールド」は頻出形。
- **コール頻度は後ろの人数で決まる**: vs HJはコールなし（レイズのみ）、vs COは極低頻度でレイズ主体、BTNはコール:レイズ≒50:50。
- **コールドコールレンジの構造**: 継続レンジはリニア。最強部（AQs以上・QQ以上・AQo/KQo以上）と最弱部（ATo〜AJo・KTo〜KJo等）はレイズし、**中間のマージナル層（Jxs・Txs、SC、ポケットの一部＋一部Axs・AQo）をコールに回す**。
- **よくあるリーク3つ**: ①ローポケット偏重のコールドコール（実際はローポケットは大半フォールド）②KQs・AJs・ATs等の強い2ブロードウェイスーテッドをコールに残さない（A/Kハイボードで戦えなくなる）③「レイズが怖いから」K7s/K8s・QJo・JTo・弱Axo等の弱すぎるハンドでコール。**原則: コールドコールしてよいのはレイズできる強さのハンドだけ。「かなり強いが超強くはない」層をコールへ。**
- **レンジの力関係**: IPコールドコールレンジはEPオープンレンジより平均的に強い（下限に3ベットする分、下が削れ上の最強部も抜けた形）。EP側の唯一の優位はAA/KK/QQ等プレミアオーバーペアの存在のみ。ミドルハイボードではUTG 46.3% vs BTN 53.7%でIP優位。
- **ポストフロップ／BvMCB（Bet vs Missed C-Bet）**: ミドルカードがハイのボードでOOP（UTG）はほぼチェック → IPはポケット中心のレンジで**小さいサイズをほぼレンジで高頻度ベット**（Aハイ/Kハイのフロートからの薄いバリュー＋オーバーカード2枚を降ろすプロテクション）。
- **A/Kハイボードは逆**: OOPが広く強化されるので小さく高頻度CB。チェックが回ったときのIPのベットは強くポラライズ — セット・2ペア＋AQ以上のAヒットをメインにラージ/オーバーベット（125%ベットにはEP側がAxs弱やATo・AJoをフォールド）。

### レーキとプリフロップの関係

出典: [レーキとプリフロップの関係](https://www.youtube.com/watch?v=kn245JYMjaI)

- **基準（NL50=5%レーキ、キャップ4bb〈字幕。別動画では6bb言及、要確認〉）**: 6max UTGオープンは22〜55が無差別、66以上ピュア。BTNのコールドコールはポケット＋Txs/Jxs系中心、SCは低頻度、2ブロードウェイオフはほぼコールしない。
- **レーキなし（プリフロップオンリーのChip EV）**＝タイムレーキのカジノ/アミューズが参照: UTGオープンは微拡大。BTNはローポケット・SC・Axsが全てコール以上に、AJo/KJo/QJoにも一部コール頻度。BBは激変 — T5s/T4s/T3sがピュアコール化、オフコネクターほぼピュアコール、K8o等の弱オフにもピュアコール出現。
- **アンティあり・レーキなし → MTT Chip EVで代用**: LJオープン2.3bbで97s・QTo等も参加。BBはほぼ全スーテッド＋J8o・K6oまでコール。
- **ライブ10%レーキ（キャップ2bb〈字幕〉、8max）**: LJ（6maxのUTG相当）は22/33/44ピュアフォールド、88にすらフォールド頻度、SCはほぼオープン不可。一方KTo・ATo・A9o等「3ベットしてくるハンドへのブロッカー」を持つハンドはオープン拡大 — 投機ハンドを絞りブロッカー系を広げる構造。BTNディフェンスは抵抗約10%のうちコール1.2%のみ（コール＝フロップ進行＝レーキ徴収のため3ベット主体）。BBはQ7s・J7sすらフォールド、抵抗計約27.2%のうちレイズ6.1%。
- **一般則**: レーキ減・アンティ増＝プリフロップのポットが実質大きい＝コール（ポストフロップ参加）が広がる。レーキ増＝3ベット寄せ・コール消滅。打つ前にフィールドのレーキ構造（%・キャップ・タイムレーキか）を確認し、参照ソリューションを切り替える。GTO Wizardにはストラドル/ダブルストラドル/ボタンストラドル等のソリューションもある。

## ハンド別プリフロップ講座

各ハンドは「スタディタブ解説シリーズ」（コーチAM氏）から。EV等の数値はASR由来のため参考値です。

### KQo

出典: [KQoの正しいプレイ](https://www.youtube.com/watch?v=nBeXrQrWrMc)

- **基本形**: 全ポジションからオープン／オープンには原則3ベット／自分が3ベットされたら原則フォールド。表示EVは0.05でレンジ内上位。KとQの2ランクが相手のコールドコール／3ベットレンジを抑え、スチールが通りやすい。
- 3ベットすると相手のコールレンジはJJ以下・QQ以下のポケットが中心 → 2オーバーカードで戦える。レイトポジション同士（ブラインド戦等・推定）では4ベットも可能。
- **3ベットポットのブラフ設計**（例: HJ vs BTNの3BP、フロップJ64）: K/Qが落ちて昇格したら素直にバリュー。2オーバーのまま滑っても75%ベットで相手はTT・99・88・77をフォールド — KQoはこのフォールドレンジ（T・9絡み）をブロックしないためブラフ適性が高い。
- **ターンのコンボ別打ち分け**（フロップCBコール後、ハートのバックドアが進展するターン）: Q♥系3コンボ（相手の継続レンジAQ♥♥・KQ♥♥をブロック）はピュアブラフ継続。Q♦はブラフ不向き（相手がフォールドするAQ♦♦・KQ♦♦をブロックし、降ろせる相手を消す）。スペードも同じブロッカー理論。
- **総括**: 3BPのKQoは相手のコールレンジ主体（AQs・KQs）に干渉するブロッカーを持つことが多い。「どのレンジ帯を降ろしたいか」を明確にし、そこへのブロッカー有無で判断する。

### BWs（ブロードウェイ・スーテッド）

出典: [BWsの正しいプレイ](https://www.youtube.com/watch?v=yGbNj9BJg_g)

- **定義**: 狭義はKQs〜JTsの三角形（KQs・KJs・KTs・QJs・QTs・JTs）。AQs〜ATsを含めることも。テーマは「**スチールで稼ぐハンド**」。
- 全ポジションからオープン可能（UTG境界はJ9s・推定）。EV例（UTGオープン）: AQs=0.46、JTs=0.06 — AQsでもスチール成功（+1.5BB）は大儲け。ポストフロップは「頑張って耐える」イメージ。
- **オープンへの対応**: コールドコールなし構成なら強い順に3ベット（ATs・KTs以上目安）。コールドコールを使うならBWsはかなりコールに回る（弱ポケットだけのコールにするとスクイーズでエクスプロイトされるため）。
- **BBでの扱い**: BBの3ベットはポーラー。BWsは「バリュー3ベットには弱く、ブラフ3ベットには強すぎる」ため基本コール。vs BTNオープンではAQ・AJ・KQ付近がバリュー3ベット、vs UTGオープンでは同じハンドがかなりコールに収まる。
- **3ベットを受けた場合**: BWs帯は高頻度でブラフ4ベット。代表格は**ATs・AJs・KJs・KTs**の4つ。レイトポジション同士ではより弱いハンドへ降格（BTNオープンvs SB3ベットではBWs本体をコールに止め、A9s・A8s・A7s・Q9sを4ベットブラフ）。
- **最重要の落とし穴**: **QJs・QTsは3ベットを受けたら基本フォールド**。ラフにコールするとキッカー負け・ドミネイトが多発しウィンレートが壊滅する。

### A5s

出典: [A5sの正しいプレイ](https://www.youtube.com/watch?v=teWt-CmzJjI)

- **特別枠**: A5sはA6s〜A9sと違い、Aと5がコネクトしてホイールストレート完成の可能性が残る。ナッツFDのインプライドと合わせ「ATsの次にA5sが強い」感覚。UTGオープンにHJはA6s〜A9sをかなりフォールドするが、A5sはピュア3ベット。
- **オープンに対して**: どのポジションからも基本3ベット可。コールドコールを使うポジションではコール／レイズ混合。
- **3ベットを受けた時**: レイズ／コール／フォールドの**3択混合**（レイズ一辺倒にしない）。ポジション別頻度感: UTGオープンvs HJ3ベット＝約50%で4ベット／BTNオープンvs BB3ベット＝かなりコール／COオープンvs BB＝フォールド少し伸びる／HJオープンvs BB＝レイズ増・コール依然高い／UTGオープンvs BB＝フォールドさらに増。
- **5ベットオールイン**: 4ベットに直面したらブラフ筆頭候補。バリューではなく、①Aブロッカー ②相手のブロードウェイ（フォールド側）を抑えていない ③フォールドエクイティ、の合算で推奨。相手が4ベットブラフを降りないタイプなら価値減。
- **SRPのポストフロップ**（フロップJ84）: BTN vs BBではA5sのCB頻度は非常に低い（SDVのないKハイ・Qハイを優先ブラフ／A5s自体SDV／チェックレイズでダブルバックドアを苦しくフォールドさせられる）。**UTG vs BB**（同ボード）ではレンジ全体のベット頻度が約70%に上がりA5sも同程度ベット（狭いレンジではエースハイでもブラフに回さないとブラフ不足）。

### スーテッドコネクター（SC）

出典: [プリフロップでのスーテッドコネクターの扱い方](https://www.youtube.com/watch?v=ZBpyHkj0NFY)

- **定義**: 98s〜54sの斜めライン（T9sはハイカード価値がありUTGオープン可でSC括りには強すぎる）。真価は**BBの3ベットブラフ要員**。
- **43s・32sは打たない**: フロップでオープンエンドが完成する確率が54s・65sより大幅に低く（下側がガットショット止まり）、EVマイナス表示。54sと43sの間に大きな断絶がある。
- **ポジション別オープン**: アーリー＝T9s以上＋98s〜54s低頻度／HJ＝98sがほぼフル／CO＝87s以上高頻度／BTN＝54s以上基本参加。
- **65s・54sの特別価値**: エースハイ／AAとぶつかった時の価値が高い（上側/ホイールのストレートを作れる）→ 相手がエースに寄る場面（HJの3ベットレンジ等）で3ベット採用。
- **ディフェンスの非対称性**: アーリーで低頻度に開けたSCは3ベットに高頻度でディフェンス。レイトのオープンはハイカード主体なので、K9s等とぶつかる際はSCよりKQ・KJを優先ディフェンスしSCはフォールド寄り。
- **落とし穴**: 「どこからもかなりの頻度で参加」は珍しい（UTGオープンにCOがSCをコールド/3ベットすることはほぼ無い）。**SCで4ベットはしない**（投機ハンドは相手の強いレンジに負けている）。

### JJ

出典: [JJの危険性](https://www.youtube.com/watch?v=SZGhAM7Ixn4)

- **基本**: 全ポジションからオープンでき、ほぼどのオープンにも3ベット可。UTGオープンEVは0.52（1.5BBスチールが成功するだけで価値以上）→ アーリーのJJは「スチールの方が期待値が高いくらい」と念頭に無理にコミットしない。
- **BBディフェンスの分岐**: vsレイト＝3ベット自然、**vsアーリー＝コール主体**（BBはアーリーに非常にポーラーな3ベットを返すため、JJはコールに混ぜる方が自然）。
- **レイト同士**では発展: BTNオープンvs SB3ベット→BTNのJJは基本4ベット。UTGオープンvs HJ3ベット→UTGは4ベットとコールの混合。
- **3ベットポットのポストフロップ**:
  - **ローボード**: JJは非常に強い（相手のコールレンジがJJより下のポケット中心）。Tハイ以下のオーバーペアボードでは50〜75%サイズでTT・99・88をいじめる。
  - **オーバーカード（K/Aハイ）ボード**: レンジ全体が20%・33%の安いCB → JJもレンジに合わせて安くCB。コールされたらターンは原則チェックでSDV狙い（AのようにレンジCB頻度が上がるカードが落ちた場合を除く）。

### 弱いポケットペア（22〜55）

出典: [弱いポケットペアの正しいプレイ](https://www.youtube.com/watch?v=m0lHfzz3Q2I)

- **オープンの境界**: CO付近で22・33がオープン/フォールドの境界、アーリーでは55すらフォールドすることあり、BTNは33+ピュア、SBはリンプ込みで22+全参加。**アーリーからローポケットを開けすぎない**。
- **BB対応**: リーズナブルなオープンサイズなら全ポケットコール可（vs UTGも2bpと小さいためコール可）。
- **3ベットを受けた時**: アーリーで低頻度に開けた22・33はコール寄り、レイトのローポケットはフォールド寄り。4ベットはほぼしない（レイトの66くらい）。
- **主要3ラインの戦い方**（受け身にしないのが肝）:
  - **(a) 自分がオープン→BBコールのSRP**: K83等のドライボードはレンジで広くスモールベット。ポーラー戦略ボード（QJ3等）ではセットは高頻度オーバーベット、非セットのポケットは基本チェックだが、**該当スート持ちのローポケットは高頻度でオーバーベットブラフ**。特にUTG vs BBのハイボードでは、セットでないローポケットを75%・オーバーベットのブラフに回さないとブラフ不足になる。
  - **(b) BBでコールしたSRP**: 安いCBはSDVがあるので一度コールで耐える。Kハイドライで大きいサイズが来たら素直にフォールド。**ペアボードは要注意** — ローポケットにはかなりのレイズ頻度があり、早めのチェックレイズで相手のオーバーカード2枚を降ろす「エクイティを奪うベット」が利益的（ボードに絡んでいないローポケットほど高頻度でレイズ）。
  - **(c) オープン→3ベットにコールした3BP**: 3ベッター有利ハイボードでは20〜30%の小CBに基本フォールド。ローカードのランアウト（例: 9-5-3-2…）ではコーラー側のポケットが強化され、3ベッター側に9や7が少ないため、ターンにOOPからスモールベット（プローブ）でAKハイ・AQハイからバリューを取れる。

## ポストフロップ戦術

### AKが滑った時

出典: [AKが滑った時の正しいプレイ](https://www.youtube.com/watch?v=HrtZcVIHYLU)

- **プリフロップ（AKoの一生）**: 全ポジションでピュアオープン。UTGオープンEVは0.81BB。SBのみリンプ採用時はコール/レイズ混合。vsオープンはアーリーでピュア3ベット、BTNでも高頻度3ベット、BBのポーラー3ベットではバリュー側。**AKoが3ベットにコールで留まるのは例外的（主にUTG vs BB）**。100BB高レーキ設定ではUTGオープン+HJ3ベットにUTGは4ベットオールイン。学習は「SRPのAKo」「3BPアグレッサーのAKo」「4BP以降のAKo」の3類型で足りる。
- **SRPで滑った形**（HJオープンvs BBコール、Jハイ/Qハイ/ローボード）: AKoで**約60〜70%の頻度でCB**。相手がAハイの一部をコールするため、これは**薄いバリューベット**。ターンはT/Q（AKにストドロが付くカード）で高頻度ブラフ継続、A/Kでバリュー、ローカードは基本チェック。「フロップ1発バリュー→以降はチェックし、打たれたらブラフキャッチorフォールド」の型を持つ。
- **3BP（HJオープン→BTN3ベット→HJコール、BTNがAKo）のローボード**: 基本ポーラーなベット（この例では75%）。ヒットをインディファレントにするより「コーラーのポケットペア（77/88・オーバーペアのTT等〈TTは推定〉）をいじめる」ベットで、AKハイはブラフ側。ターンでA/Kが落ちればバリューへ昇格 → AKハイは「A・K計6枚のドローハンド」とも扱える。75%後のターンは高頻度でブラフ継続（伸びたスートのA/K持ちが継続候補）。
- **フロップチェックを選んだ場合**: OOPがターンにワイドなスモールベット → AKハイは6枚アウツ+SDバリューでコール。このラインではIP側のグッドポケットがレイズで削られるため、リバーでOOPはエニーペアで35〜60%サイズのバリューを打て、AKハイはブラフキャッチ側に回る。

### ドンクベット

出典: [ドンクベットが有効なシチュエーション](https://www.youtube.com/watch?v=0lVeTPbulAw)

ドンクベット（アグレッサーでない側がフロップ/ターンで先にベットすること）が発生する3類型:

- **ケース1: フロップがBBに有利（コネクトローボード）**: UTGオープン→BBコール、フロップ865でBBが約50%の頻度でドンク。プリフロップはUTGが強いのにエクイティ拮抗、BB側はポーラーな分布。スモールドンクでUTGのAハイをいじめる。レポートタブではコネクトボードで圧倒的にドンク頻度が高い。Aハイボードでも「エースホイール」（A5ハイ以下）ではドンク発生。コンプレックスソリューションではBBは125〜150%のラージドンクも使い、UTGのAKoをインディファレントにする。
- **ケース2: ターンがコーラーに有利（フラッシュ完成等）**: BTN vs BB、KハイツートンのフロップでBTNがオーバーベット→BBコール→**ターン8♠でフラッシュ完成**でBBが高頻度ドンク（BTNのエクイティ36.5%まで低下）。スペードのターンだけドンク頻度が突出（フロップのオーバーベットにBBはFD持ちを基本コールで回すため、完成カードでコールレンジ全体がナッツ寄りに強化される）。
- **ケース3: サイズ入力由来**: UTGオープン→BBコール、Q88でUTG 33%CB→BBコール→ターン4♣（ラグ）で20%サイズの小ドンクが発生。正体はフロップの最小レイズ入力が50%で、「もっと安いレイズがしたかった」ハンドの持ち越し。フロップに20%/33%の小レイズを追加すると合計25〜30%のレイズ頻度になり、ターンのドンクはほぼ消える。**不合理に見えるドンクは「サイズ入力を増やす」「コンプレックスソリューションを見る」で原因を特定**。

### BBからのチェックレイズ

出典: [BBからのチェックレイズ](https://www.youtube.com/watch?v=ui3SkSosy6A)

- **原則**: BBはレンジが弱いのにチェックレイズはアグレッシブに行う。**相手のCBが安いほど高頻度で返す**。チェックレイズ頻度の不足は即エクスプロイトされる典型リーク。
- **頻度の基準**（BTN 2.5bbオープン→BBコール）: 33%CBに対し 50%レイズ7.9%＋ポットレイズ5.1%＝**合計約13%**。CBサイズ別のXR頻度: 50%CB→約9.8%、75%CB→約7.3%、125%CB→約5〜6%（安いCBほど多くのハンドでレイズを返す）。
- **判断軸**: 相手のフォールドラインより上ならバリュー感覚、下ならブラフ感覚、境目のミドルはコール。
- **ボード別**:
  - **992ペアボード**: コール33.5% vs レイズ27.2%でほぼ1:1。限界ハンド（K5s/K6sのバックドア持ち）を幅広くブラフレイズ、2ヒット・33/44/55・9トリップスも高頻度。ただしA8s/AToはコール止め（相手が50%レイズにA8付近をフォールドし、ドミネイトしている下だけ降ろす形になるため）。
  - **AT7（ハイカードボード）**: レイズはポットサイズで狭く。バリューは2ペア以上、ブラフはサードペア以下。**トップペア/セカンドペアはほぼレイズしない**（相手に一方的にトップペア・グッドキッカーがあり、プロテクション不要）。
  - **UTG vs BB、TT6（推定）ペアボード**: XR27.4%でコール頻度超え。33/44・Tトリップスの一部・Aハイの一部で返す。
- **心得**: ディフェンスするたびに「レイズの選択肢はあるか」を毎回考える。低ポケ・ボトムペアの「プロテクションレイズ」を常に選択肢に。

### DepolarizedとUrgency

出典: [DepolarizedとUrgency](https://www.youtube.com/watch?v=5Y1T9aTPVOE)

- **核心**: オーバーベットはポラライズ専用ではない。まくられやすい（ダイナミックな）ボードでは「**ナッツの一段下・アージェンシー（緊急性）のあるハンド**」がデポラライズドに大きく打ち、先にオーバーカードを降ろす。
- **BTN vs BB SRP、J-T-4**: レンジの12.5%でオーバーベット。使い手はKJ/AJ/QJ/J9等のトップペア、トップ2ペア（JT）、オーバーペア。**JJ（セット）やJ4s（下の2ペア）等の最強部はチェック/スモールに回る**。源泉はBBが3ベットしなかったことで抜けているQQ/KK/AA帯のナッツアドバンテージ。
- **SB vs BB、862レインボー（コンプレックス）**: 321%ベットが16.5%もの頻度で使用。選ばれるのは99/TT/JJ/QQ/KKのうち**特にランクの低いオーバーペア優先**＋A8/K8付近。321%へのBBは2オーバー（AJo/KJo）も基本フォールド → 先にオーバーカードを降ろせば上のカードが落ちてもオーバーペアの優位が保たれる（＝プロテクションを意識したベット）。
- **アージェンシー**: プロテクション必要性の高いハンド。99はオーバーカードが怖い→急ぐ、AAは怖くない→急がない。ナッツではなく一段下の帯でラージベットする構成が**デポラライズド戦略**。
- **3BPの例**: BTN vs SB 3BPのJT8ではQQがほぼピュアにフロップからオーバーベットオールイン（ストレート/セット/2ペアは押さず、オーバーペア/トップペアが押す）。BTN vs BB 3BP（BB3ベッター）のローボードでは、直上の66/77ではなく**88/TT/JJがオールイン**（BTNはTT以上を4ベットに回すためコールレンジにTT以上のオーバーペアが基本無く、相手の主要ポケット全てに勝ちプロテクション必要性が最大のJJ付近が押すのが最適）。
- **教訓**: オーバーベットのハンド選定は「ボードのまくられやすさ（アージェンシー）× プリフロップで相手レンジから何が抜けているか」で決まる。

### AKハイボードでのオーバーベット／ジオメトリック

出典: [AKhiボードでのオーバーベット](https://www.youtube.com/watch?v=b_zqgaPY5zs)

- **AK4（BTNオープン→BBコール、レインボー）**: BTNは**125%オーバーベットをレンジ戦略のほとんど**として使用。125%→100%→約123%と打つとちょうどオールインになる**ジオメトリックサイズ**（各ストリート同倍率でスタックを使い切る設計）で、3ストリートかけて相手のマージナルをいじめる。
- **バリュー側**: Aヒットはキッカーが弱いほど頻度低下、下限はA5付近（A5はBDFDのあるスートのみ、A3はキッカー弱すぎて打たない）。2ペア（A4/K4/AK）、4のセット、KKはオーバーベット。**AAは打たずチェックレンジ保護**（相手のコールレンジを強くブロックし、まくられも極少のため）。
- **ブラフ側の選定**: ストレートドロー（QJ/QT/JT）、ボトムヒット（4ヒット＝Q4/J4/45は実質5アウツのドローとして高頻度）、ローポケット、バックドアFD（無関連のT7でもBDFDのある3スートは打ち、BDFDの無いクラブ×クラブは打たない）。
- **Kヒットのブラフ化とブロッカー**: K♠9♠/K♦9♦やK♠/K♦を含むKxオフを選ぶ。オーバーベットに相手が耐えるのは「BDFD付きのKxスーテッド」→ 同スートのKを持つ＝**相手のコールレンジをブロック**。BDFDの無いスート（クラブ）のKは相手の**フォールドレンジをブロック**するので選ばない。
- **ターン運用**（例K♠8♦）: ♠や♦が伸びたターンはブラフ継続、Kや8を拾えばバリューへ切替。スペードが伸びたターンでは相手が♠♠のKxをディフェンスするのでK♠がブロッカーとして優秀。ローポケットは基本ターンで止まり、セット化・ストドロ進展・スート好転時のみ継続。
- **Aだけ色が違うツートン**: レインボーよりキッカー精査が厳しく「FD無しのAは高キッカーのみ、FD有りのAは低キッカーから」。

### EP vs BB のオーバーベット設計（オールインへ向かう）

出典: [EP vs BB オールインに向かう戦略](https://www.youtube.com/watch?v=vUmEcDtO4Ro)

- **核心**: EP(UTG) vs BBのSRPでも、GTOはK94のようなボードでフロップから大きめサイズ→ターン・リバーのオーバーベットで**SRPのままオールインまで到達**し、ナッツアドバンテージを最大化する。3ベットポットでしかオールインラインを組めないプレイヤーは、SRPでのこのEV（セット・2ペア級をスタックインするEV）を取り逃している。
- **フロップCB（K94）**: 33/50/75%が広く混合。多くの人はKハイでスモールに寄せすぎ。UTGはAA・AK等BBより強いハンドを多く持つため、50/75%で生かす。75%へのBBは、プリフロップでコールしたTT（推定）がフォールド/コール無差別に。
- **ターン7♠（75%ライン）**: フロップで強弱を分けたUTGはポーラー、BBはマージナル → UTGは非常に広く125%オーバーベット。バリューはKQ以上・KKトップセット・AAも高頻度、ブラフは55/66でスペード絡み・Aハイの一部。**EPはレンジが狭いため「AハイはSDVだからチェック」ばかりだとブラフが枯れる** — Aハイをどれだけベットへ回せるかが鍵。
- **リバー2♥（75%→125%ライン）**: UTGは86%と204%（オールイン）の2サイズを使い分け。オールインのバリューは99/77のセット・K9/K7のトップ2ペア・KKトップセット。86%は「オールインには足りないがもう1度打てる」AK・AA用で、そこにナッツ級の一部を混ぜてレンジ保護しレンジ全体のEVを高める。
- **KKで33%から入る別ライン**: フロップ33%（インディファレントでも十分EV）→ ターン7♠でポラライズ（125%と175%を打ち分け／33%はBBが広く守るため55/66はSDVを追う側に昇格）→ リバー2♥でOOPチェックに残り300%超をそのままオールインし、相手のKをインディファレントに。

## GTO Wizard ツール／機能の使い方

### Study Tab（と使い方の中心）

出典: [【字幕付き】Study Tabの使い方](https://www.youtube.com/watch?v=RRwtSao5teU)（同内容の[Study Tabの使い方](https://www.youtube.com/watch?v=9ZcLWfEDfbU)を統合）

- **位置づけ**: 3大タブ（Study／Practice／Analyze）のうち最も参照頻度が高く、既解済みGTOソリューションの閲覧とハンドレビューの中心。
- **ソリューション選択**: 左上「Cash 100BB 6max NL50」等の「Change」→候補一覧。インプットはスタック／タイプ／レーク／オープンサイズ／3ベットサイズ／ヒーロー位置。スターでお気に入り登録。最もよく参照されるのは「NL50 GTO GTO」。プレミアム/エリートではHU・8max・9max・プリフロップ専用の詳細SIMも参照可。
- **戦略閲覧**: 上部のアクションセレクターにラインを1つずつ入力。ポジションにカーソル→レンジ全体、個別ハンド（AJhh等）にカーソル→スート別戦略。色: チェック＝緑、小さいベット（33%）＝薄い赤、サイズが大きいほど濃い赤。全色混合＝「どのサイズでもEVがほぼ等しい混合戦略」。表示切替: Strategy → Strategy+EV（例 Bet125%＝EV18.53が最大）→ Strategy+EQ（AJhh＝EQ81.1%）等。
- **Rangesタブ**: 左＝OOP(BB)、右＝IP(BTN)のレンジ比較。中央に統計（例 OOP62.2% vs IP37.8%のエクイティ）、下部にエクイティグラフ。読み方例: BTN上位25%の境界がQJ（EQ約77%）、50%地点はBTN＝A5（EQ20.3%）vs BB＝J3トップヒット（EQ67.4%）→ BBはコンデンスト、BTNはポーラー。
- **Breakdownタブ**: 戦略分布をハンド強度クラス別に表示（セット/2ペア/オーバーペアは125%ベット、トップペアはAJ/KJに境界＝125%のバリュー下限がAJ）。ブラフはコンボドロー/FD/OESD/ガットショット/ドローなしに分類され、FDが優先的にベットへ。EQ帯別（80%超＝ベット、60〜80%＝チェック、それ未満＝ブラフ選定）でポラリティを確認。
- **Reportsタブ（集合分析・プレミアム以上）**: フロップ/ターンの全カードのレンジ全体戦略を一覧。ローカード＝ポットオーバーorチェックのポーラー、ハイカード＝中間サイズ含む打ち分け、ペアしたカード＝チェック多用。表示はグリッド/チャート/テーブル。フロップ集合分析はスート等価ボードを統合表示。**リバーの集合分析は動画時点で未提供**。右下Filtersで特定ハンド単体のカード別頻度も見られる。
- **表示高さ**: Range Height（ノード到達頻度反映・低頻度ノードは見づらい）／Full Height（全ハンド100%高さ）／Normalized（最多残存を最大高さに正規化）。ショートカット: Shift+上下＝スート変更、左右＝ランク変更。

### Study Tab を使ったハンドレビューの型

出典: [ハンドレビューの仕方](https://www.youtube.com/watch?v=53X67m2_OXY)

「**学びたいことに応じて見る場所を変える**」のが核心です（題材: UTG 2bbオープン→BBコール、KJs、フロップK93で33%CB→コール、ターンJでトップ2ペア完成、リバー2）。

- **レンジ全体の疑問 → レポート（集合分析）**: 「Kハイは33%レンジベット」は誤り。ペアボード除外→モノトーン除外→コネクティッドネス分類→ハイカード分類、と絞ると、33%が顕著なのはミドルカード8以下のローランクKハイ（K83等）に限られると分かる。
- **ハンド単位の疑問 → レンジ表で似た強さと比較**: QQ/JJはプロテクション価値が低く75%頻度低、KQ/AKは75%を広く使用、KJは33〜75%どれでも大差なし、等。
- **アクションの利益性 → 相手のリアクトで判断**（自分の頻度の有無ではない）: フロップ33%にBBの8ポケ以下やAJ/A10がフォールド → これらが実戦でタフコールするほどKJのバリューは利益増。「リドロー無しの9とK全部がコールしてくれるなら利益的」と読む。
- **リバーには集合分析が無い → カードを動かして規則化**: Shift+矢印でリバーのランク/スートを変え、「どんなリバーでどのサイズが消える/現れるか」を覚える（ラグのリバーは400〜500%級、リバー9でオールイン激減など）。
- **総括**: 均衡を漫然と眺めない。①レンジ全体→レポート ②ハンド→レンジ表比較 ③利益性→相手のリアクト ④リバー→カードを動かす。「このハンドから何を学びたいか」を先に整理してからツールを開く。

### GTO Wizard AI（カスタムソルバー）

出典: [GTO Wizard AIの使い方](https://www.youtube.com/watch?v=9jzcM2xiip0)

- **目的**: エリートプランのリアルタイムソルバー。標準SIMにない任意のレンジ・ベットサイズ・設定を数十秒〜数分で計算（従来ソルバーはSRPでも30分以上）。
- **起動**: (a) Studyのソリューション設定→「カスタムソリューション」、(b) ボード選択画面の「AIソルブ」ボタン。
- **ソリューション設定**: ストリート（プリフロップ＝HUのみ／フロップ＝6MAX一般）、エクイティモデル（Chip EV／ICM）、**Prefill**（普段のSIMとラインを選ぶとポット・レーク・レンジを自動入力・初心者推奨）、レンジ編集（GTOにないレンジもExport/Importで共有可）。
- **ベットサイズ**: **Automatic**（各スポットで最もEVの高いサイズを1つ自動選択）／**Dynamic**（2〜3個に増やす）／**Fixed**（全サイズ手動指定。※レイズ/リレイズ枝の欠けたツリーは「レイズが返ってこない」瑕疵をソルバーが悪用し歪むので、ゲームツリーの完全性の確認が重要）。一括適用（Apply flop to river 等）あり。
- **Advanced Options（4項目）**: Force All-in Threshold（ベットがスタックの指定%超で強制オールイン）／Add All-in Threshold（SPRが指定値でオールインを追加）／Bet Size Margin Threshold（近いサイズを統合。判定式 `(1+higher)/(1+lower)−1`）／Max raises per street（推定・1ストリートの最大レイズ回数、3〜4推奨）。
- **保存/再利用**: Save→Load。Apply欄は「All Settings」or「Only Bet Sizes」。他にノードロック・レンジコンペアもある。

### ノードロック（旧UI / 2.0）

**ノードロック（旧UI）** — 出典: [ノードロック機能の使い方](https://www.youtube.com/watch?v=jAnmRumQGVQ)

- **目的**: 相手の「均衡からの乖離（リーク）」を特定ノードの戦略として固定（ロック）し、それに対する最適エクスプロイトをWizard AIで計算。題材: BTNオープン→BBコール、K73レインボー、BB33%ベットへの応答（GTOではBBは約10%超をレイズだが、実戦は「2ペア以上・セットのみレイズ」の相手が多い）。
- **手順**: 標準SIMから直接は不可 → まずAIソルブで解き直す → ロックしたいノードで鍵マーク → ノードロック画面へ。設定3種:
  - **Set Frequency**: レンジ全体のアクション頻度をバーで指定（GTOから少しだけレイズ少ない等の相手向け）。
  - **Set Strategy**: 塗る頻度を先に設定しハンドごとに塗り絵（Filtersのハンドランク・エクイティで一括塗りも可）。
  - **Lock/Unlock**: ハンド単位でロック/解除。**重要**: ノードロックは「塗った戦略を相手が必ず取る」機能ではなく「ロックしたハンドは固定、未ロックはソルバーが動かして均衡を取り直す」機能。バリューだけロックしブラフを未ロックにすると、ソルバーがブラフを勝手に補う → 相手の戦略全体を固定するなら「Lock All」。
- **結果**: BBのレイズが2ペア以上確定になると、BTNはCB頻度0%（ほぼ全レンジでCB正当化）・ポットオーバーベット使用、AKを含む多くをフォールド（約95%）。**Compare Nodes**でロック後とGTOを並べて比較（A9s/A8sがピュアチェック→ピュアベット化等）。ロックの影響は手前ノードにも波及する点に注意。従来2〜3時間の計算が数秒〜数十秒。

**ノードロック2.0（新UI）** — 出典: [【New】ノードロック機能2.0の使い方](https://www.youtube.com/watch?v=A6iNJPqWrgs)

- 題材: SB 3BBオープン→BBコール、A-Q-4でKKを持つSBがチェック→BBの75%ベットへの対応（プリソルブ済ではKKはピュアコールだが、均衡での75%ベット頻度はわずか1.7% → 多用してくる相手は均衡外と想定）。
- **入り口**: アクションセレクターのフロップ下の「AI solve」→Wizard AIへ。「Edit Actions」（ペンマーク）で不要サイズ削除。「ノードロック」ボタンで画面へ。
- **Range Frequency**: レンジ全体の頻度をスライダーでロック（バリュー/ブラフのバランスを取ったまま高頻度ベットを構築）。**Hand Frequency**: 各ハンドにカーソルで「塗って」割り当て。**右側タブ**: Range / Hand Class（ノーメイド全体をチェック100%等クラス一括）/ Combos（エクイティ・EQR順表示）。
- **セルのロック**: 完了後、右上のロックボタン（ロック済みは再計算されない）。**Lock previous nodes設定**（重要）: 「Don't lock」だとSBが将来のリークを織り込んで手前のチェック頻度自体を変える。SB側を表示済みレンジのまま固定するには「Lock previous nodes」。
- **Apply結果**: バリュー偏重の75%ベットに対しSBは約90%という極端な頻度でフォールド（＝KKのピュアコールは相手次第で崩れる）。使い方は「均衡での使用頻度が極端に低いライン（1.7%等）を相手が多用したら均衡外」というシグナル発見＋感度分析。

### Range Builder

出典: [Range Builderの使い方](https://www.youtube.com/watch?v=dEDxMHEOXus)

- **目的**: Practice内。お絵かき感覚でレンジ表を塗って提出し、GTOレンジとの適合率・間違いを採点。「頻度」を意識したGTO理解のトレーニング。
- **手順**: スポット選択→Difficulty（Hardで普段の画面に近い）→Start Building。右「Set Strategy」のバーで頻度設定しハンドを塗る（左クリック長押しで一括）。See Results→左＝自分/右＝GTO、中央にスコア（例94%）。**Combos by Score**: Perfect/Good/Inaccuracy/Mistakeの4段階、ミス傾向（レイズ過多等）も確認。
- **発見例**: BTNオープンでJ2s/J3sは不適、75sは開けるべき、22は頻度オープン。多アクション（BB 3ベット/コール/フォールド）ではSet Strategyが4分割、「Hint」で目標頻度との差を確認（A2s/A3sはコール不可、SGは広くコール可）。
- **ポストフロップ**（BTN vs BB AK4のCB）: サイズ別（33〜125%）に分割。**Lock機能**（確定ハンド保護・AAはチェックで固定）、**スート別の塗り分け**（T7s名クリック→右下ペインでT7ssのみ125%指定）、Filter/Summary（♠♠一括、エクイティ順ソート）も可能。

### トレーナー

出典: [トレーナー機能の使い方](https://www.youtube.com/watch?v=IZzEqR-cfsU)

- **目的**: Practice内。ポーカーテーブル形式で実際にアクションを選び、GTO観点のEVロスを即時採点。ドリル自作・共有可。
- **評価区分**: Best Move（EV最大かつ最頻）／Correct Move（EV最善同等だが低頻度）／誤りは Inaccuracy・Wrong Move・Blunder にEVロスの大きさで段階分け（推定）。誤答時は選択に赤標識＋EVロス（例 J9oオープンで0.07）＋ベストムーブ表示。
- **ドリル作成（New Drill）**: Game/Solutions（歯車でSIM選択）、Starting Spots（SRPのBTN vs BB CB等）、Board（モノトーン/ペア/コネクト、ハイ/ミドル/ロー、Subset）、Hands（特定ハンド・Hand Class・Close Decisions）、Modes（Number of Tables、Game Mode＝Spot/Street）、Display（ヒント表示ON/OFF）。SaveしてExport/Importで共有。
- **Manage Drills**: 各ドリルの実績・**GTO Wizardスコア**（100に近いほどGTO。EVロスなしは0〜100、ありは0〜−100で評価・蓄積）。Close Decisions・Hand Class絞り込みで境界ハンドを反復し、Blunderから優先的に潰す。

### 各種ソリューション（MTT / ICM / HU SnG / 3way / プリフロップソルバー）

**MTTソリューション** — 出典: [【Events】MTTソリューションの使い方](https://www.youtube.com/watch?v=EHDtuke1ug8)

- 4区分「ヘッズアップ／チップEV／ICM／イベント」の使い分け。
- **HU**: 各プレイヤーが0.125BBずつアンティ（ポット1.75BBスタート）。大型大会はBBアンティでポット2.5BBスタートのため戦略が大きく変わる（厳密にはエリートのプリフロップソルバー推奨）。
- **チップEV**: レーキを取らないアンティありのゲーム＝「アンティあり・レーキなしのキャッシュ」と解釈。使ってよいのは優勝以外プライズが出ない大会か優勝のみ狙うプレイヤー。
- **ICM**: クラシック/PKO、人数、残り割合など多くの設定が必要。
- **イベント（新機能）**: WSOP・SCOOPの実FT局面をソリューション＋YouTube映像付きで学べる。YouTubeアイコン付きハンドをクリックすると右にYouTube配信がタイムスタンプ付きで表示され、左の均衡と並べて「観戦型スタディ」ができる。

**ICMソリューション** — 出典: [ICMソリューションの使い方](https://www.youtube.com/watch?v=j8ToHqQpAKo)

- Studyタブ上部からMTT→HU/Chip EV/ICMの3種。**Chip EV**は「アンティあり・レーキなしのキャッシュ」。**ICM**はFormat（Classic/PKO）、フェイズ（ニアバブル/残り50%/37.5%（推定）/FT）、参加者数（1000/200）等を設定。
  - 例1: ニアバブル・SB27BB vs BB53BB（BBカバー）→ SBはレイズせず全リンプ、BBはポーラーにレイズ。
  - 例2: SB33BB vs BB20BB（SBカバー）→ SBはリンプなしで全ハンドをレイズかオールイン、BBはレイズ2.5に約40%・オールインに約86%フォールド。
- **バブルファクター表**（左上「MTT」右の泡マーク）: 各プレイヤーが相手ごとに負うバブルファクター/リスクプレミアムの一覧（例 HJはSBに対しリスクプレミアム6.3・バブルファクター1.29）。**PKO**はスタックにカーソルでバウンティ額、「バウンティパワー」でBB換算価値を表示（ニアバブルでもバブルファクターが0.89等と低くなる）。

**HU SnGソリューション** — 出典: [【PokerArena】HU SnGソリューションの解説](https://www.youtube.com/watch?v=MJRu6uVSJCc)

- レーキなし・アンティなしのHU SnG。72BB〜1BB（ショートは0.5BB刻み）のスタック別プリフロップ＋ポストフロップ。25BB取り切りのポーカーアリーナ学習に最適。スタック別の型:
  - **25BB**: フォールドはわずか5.7%（約95%参加、Q4o・J3oも）。レイズとコール（リンプ）は多くが混合。レイズへのBBは約10回に1回オールイン（AXオフ＋ローポケット中心）。BBの3ベットサイズは5BB/8BBの2種。
  - **20BB**: 22等に直接オールインが出始める。vsレイズのBBオールインがAXo＋K5o/Q5oに拡大。
  - **15BB**: 22はピュアオールイン。33やAXオフの一部もオープンオールイン。
  - **10BB**: オープンレイズが消え「リンプ or オールイン」の二層構造。
  - **5BB**: 全ハンドがオールイン or フォールド（相手BBは約37〜38%フォールドでFE残存）。
- 使い方: 「25BBでフォールド約5.7%」を基準にオーバーフォールドを点検。リサーチソリューション（多サイズ検証）で高頻度サイズを確認。

**3wayソルバー** — 出典: [3wayソルバー機能の使い方](https://www.youtube.com/watch?v=xtv5neQw6Og)

- 3ウェイポストフロップをWizard AIで解く（従来ソルバーでは不可だった領域）。ライブラリに項目は無いので、3ウェイになるプリフロップ（オープン→IP/SBコール→BBコール）を入力→「Solve postflop with AI」。レンジ欄に3人分が自動入力される。
- ベットサイズは**Fixed固定のみ**。ツリー肥大化に注意（例: 20%/66%/100%の3サイズ＋レイズ50%統一。レイズは1ストリート3回まで）。
- 結果の原則: **マルチウェイでは各プレイヤーが高いフォールド頻度を持ってよい**（BTNの20%ベットにBBが約70%フォールドでも、3ウェイ＋BBレンジが弱いことから正当化）。スクイーズ後にBTNがオールインしか持たない等、入力の副作用で歪むノードに注意。

**プリフロップソルバー（MTT 1bb ante HU）** — 出典: [プリフロップソルバーの使い方 - MTTでの1bb anteのHU](https://www.youtube.com/watch?v=_dzEgZrTFfE)

- **背景**: 標準MTTのアンティは「全員から0.125BBずつ」方式で、HUでは計0.25BBにしかならない。日本の大型大会標準の「BBアンティ1BB」（約4倍）とは条件が違う → エリートのカスタムソリューションで1BBアンティHUを自作。
- **手順**: カスタムソリューション→New solution→Street「Preflop」。設定例: スタック20BB、SB/BB比0.5、アンティ「BBアンティ1BB」、リンプ採用、レーク「ノーレーク」。ベットサイズツリー: SBオープン2BB＋リンプ、BB3ベット4.5BB、4ベットはオールインのみ、リンプへのアイソ2.5BB、アイソへの3ベット5.5BB。Advanced: Force all-in threshold 100%、Add all-in threshold 500%（推定）。「?」ボタンで各項目説明。
- **結果**: SBはフォールド/2BBオープン（ポラライズ）/リンプ。2BBオープンにBBは4.5BB3ベットとオールインの2本立て、4.5BBにSBはオールイン/コール。標準MTTを使う前に「アンティ徴収方式」を理解し、HU・少人数では実戦とズレることを意識する。

## 用語集（YouTube由来の追加分）

姉妹ノート [`amu-goole-poker-notes.md`](./amu-goole-poker-notes.md) の用語集と重複しない、本チャンネル由来の追加・補足分です。

- **BvMCB（Bet vs Missed C-Bet）**: アグレッサーがCBを打たずチェックした（missed c-bet）局面で、後手（主にIP）が代わりに打つベット。ミドルハイボードでOOPが広くチェックした際、IPがポケット中心のレンジで小サイズを高頻度で打つのが典型。（動画表記では「BMCB」等の揺れあり）
- **デポラライズド（Depolarized）戦略**: ナッツではなく「一段下のかなり強い帯（ランクの低いオーバーペア・トップペア等）」でラージ/オーバーベットするレンジ構成。ダイナミック（まくられやすい）ボードで用いる。
- **アージェンシー（Urgency／緊急性）**: あるハンドがプロテクションを必要とする度合い。オーバーカードが怖い99は「急ぐ」（アグレッシブに打ってオーバーカードを先に降ろす）、オーバーカードの無いAAは「急がない」。
- **ジオメトリック（Geometric）ベットサイズ**: 各ストリートで同じ倍率をかけ、リバーでちょうどオールインになるよう設計するサイジング（例 AK4で125%→100%→約123%）。3ストリートで相手のマージナルをいじめ切る。
- **バブルファクター／リスクプレミアム**: トーナメント（ICM）で、チップを失うことの重み。相手ごとに異なる（カバーされている相手には高くなる）。GTO Wizardのバブルファクター表で対人別に確認できる。バウンティ（PKO）ではバブルファクターが下がる。
- **バウンティパワー**: PKOで、あるバウンティが現在何BB相当の価値かを示す指標。
- **ノードロック**: 相手の特定局面のアクション頻度を固定（ロック）し、そのリークへの最適エクスプロイトをWizard AIで計算する機能。ロックしたハンドのみ固定され、未ロックはソルバーが再均衡させる点に注意（相手戦略全体を固定するなら Lock All）。
- **バンチングエフェクト**: 前のプレイヤーのフォールド（ローカード寄り）により、残デッキ/残プレイヤーにAが濃くなる現象。フォールド人数の多い9maxではローSC/ギャッパーが消えAブロッカー系が残る。
- **アージェンシーのあるボード＝ダイナミック／スタティック**: JTハイ等まくられを気にするボードがダイナミック（デポラライズド・オーバーベット頻度が上がる）、AKハイ等まくられケア不要がスタティック。
- **エースホイール（A5ハイ以下のAハイボード）**: 一見アグレッサー有利のAハイでも、ローのストレート/ドローが絡むためコーラーがポーラーにドンクできるボード。
- **コンプレックス／レガシー ソリューション**: 標準より多彩なベットサイズ（125〜321%等）を含むソリューション。不合理に見えるドンクやオーバーベットの原因を探る際に参照する。

## 実戦チェックリスト集

各バッチの実戦チェックリストを集約しています（出典動画は各節参照）。

### 基礎理論・数式

- [ ] 相手が未知・強豪・カウンターが怖い場面では、GTOベースの安全運転に切り替えているか（EV保証を思い出す）。
- [ ] 相手のミスを「頻度（混合）のミス」か「純粋戦略のミス」かに分類し、GTOのままで咎められるのは後者だけだと意識できているか。
- [ ] 特定ハンドのEVマイナス（ナッツしか打たない相手へのブラフキャッチ等）に動揺せず、レンジ全体・他シチュエーションでの回収まで含めて評価しているか。
- [ ] エクスプロイトに踏み出す前に「相手戦略の仮定の根拠」と「外れた/カウンターされた場合の損失」を言語化したか。
- [ ] ベットを受けたら即座に「ポットオッズ＝コール額÷(ポット+ベット+コール額)」を暗算し必要勝率として読めるか（50%ベット=25%、60%ベット=27%）。
- [ ] リバーで自分がベットする時、サイズに応じた必要ブラフ%でバリュー:ブラフを組めているか（50%ベットなら3:1）。
- [ ] ブラフ判断は「α＝ベット額÷(ベット額+ポット) 以上降りるか？」で（50%→33%、60%→37.5%、100%→50%）。
- [ ] 受け手はMDF＝1−α（50%→67%、60%→62.5%）を下回る降りすぎになっていないか。

### プリフロップ

- [ ] レンジは頻度でなく境界で記憶し、境界ハンドだけを卓の性質（3ベット頻度等）で出し入れする。
- [ ] 場面判定: コール不要→リニア、コール必要（BB3ベット・4ベット）→ポーラー、相手の抵抗増→マージドへ。
- [ ] オープンサイズは「3ベットが多い相手/ポジションでは小さく、コールが多いなら大きく」。無頓着な相手にはQQ+のみサイズアップも検討。
- [ ] ディープ（200bb〜）ではAxoを減らしJ9s/KJs等プレイアビリティ重視へ、3ベットサイズもスタックに応じ7.5bb/12.5bbを使い分け。
- [ ] SBのリンプ候補は「レイズでもフォールドでも大差ないハンド」。BB3ベットにA2o/A7o/K7o級のオフスートブラフを入れているか。
- [ ] SBコールドコールは相手が2bbオープンのときだけ本格採用。2.5bb以上はレイズorフォールドへ戻す。コールドコール後のスクイーズには原則フォールド。
- [ ] BBの3ベットサイズはオープンの5〜6倍（vs BTN 2.5bb→13bb目安）。ブラフは「相手のオープン下限＝自分の抵抗境界」から選び、純フォールドハンドでは打たない。vsアーリーではJJ/TTもコールに回す。
- [ ] IPコールドコールは「3ベットできる強さの中のマージナル層」から。ローポケット偏重・KQs/AJs/ATsのコール漏れを点検。
- [ ] フィールドのレーキ構造を確認し参照ソリューションを切替（タイムレーキ→Chip EV、アンティあり→MTT ChipEV、ライブ高レーキ→Live 10%）。高レーキではコールドコールを捨て3ベット主体・ブロッカー入りオフスートへシフト。

### ハンド別

- [ ] KQoはどこからでもオープン・原則3ベット・被3ベットは原則フォールド。3BPで2オーバーのまま滑ったら「相手のフォールドレンジ（中位ポケット）を非ブロック」を確認して積極ベット。
- [ ] BWsの4ベットブラフ第一候補はATs/AJs/KJs/KTs。QJs・QTsで3ベットにコールしない（原則フォールド）。
- [ ] A5sはレイズ一辺倒にせずレイズ/コール/フォールド混合。4ベットには5ベットオールインのブラフ筆頭。SRPのCBはレンジの広さで決める。
- [ ] アーリー〜COからSCを参加させすぎない。43s/32sはどこからも参加しない。BBの3ベットブラフにSCを混ぜる。SCで4ベットしない。
- [ ] アーリーのJJは「スチール成功で御の字」。BBはvsレイト＝3ベット、vsアーリー＝コール主体。3BPでオーバーペアになったら50〜75%で下のポケットから搾取。
- [ ] アーリーからローポケットを開けすぎない。BBのペアボードでは絡んでいないローポケットのチェックレイズ（オーバーカード2枚へのエクイティ奪取）を選択肢に。アーリー vs BBのハイ/ポーラーボードでは非セットのローポケットを75%/オーバーベットのブラフへ。

### ポストフロップ

- [ ] AKoは3ベットにコールが例外（主にUTG vs BB）。SRPで滑ったらフロップCB（60〜70%頻度）は薄いバリュー、ターン無進展はチェック。3BPアグレッサーのAKハイは「6枚ドロー付きブラフ」。
- [ ] コネクトローボード（865系）のBBは約50%までドンクしてよい。フロップのオーバーベットをコールした後のフラッシュ完成ターンはドンクの絶好機。ターンの小さいドンクは前ストリートの安いレイズの代用を疑う。
- [ ] 相手の33%CBに対し合計約13%のレイズ頻度が基準。レイズ構成は「相手がフォールドする最上位」を境に上=バリュー/下=ブラフ、境目（A8〜ATクラス）はコール。低ポケ・ボトムペアのプロテクションレイズを常に選択肢に。
- [ ] オーバーベット＝ポラライズと決めつけない。自分のオーバーペアに「急ぐ理由」があるか自問（99は急ぐ、AAは急がない）。3BPでは「相手のコールレンジの全ポケットに勝つ最小のペア」をオールイン候補に。
- [ ] AKハイボードのIPアグレッサーは125%ジオメトリック（3発オールイン設計）を第一候補に。バリュー下限を決めてから打つ。AAは温存。ブラフはスート（相手のコールへのブロッカー）まで確認。
- [ ] EP vs BBのKハイでは33%レンジベットに逃げず50/75%を検討。ターンで「自分ポーラー vs 相手マージナル」なら125〜175%を選択肢に。AハイをSDV理由でチェック固定せずブラフへコンバート。

### ツール／学習法

- [ ] 自分のステークス・レーク・サイズに最も近いSIMをスター登録し、ハンドレビューを常に同一SIMで統一する。
- [ ] レビュー前に「分からなかったこと」を『レンジ全体／ハンド単位／アクションの利益性』のどれかに分類する。思い込み（「◯◯ボードは△△%ベット」）はReportsで条件を除外・分類して検証する。
- [ ] 自分のベットの良し悪しを、自分側の頻度でなく「相手のどのハンドが降り、どのハンドがコールすると利益的か」で言語化する。リバーの疑問はカードを動かして規則化する。
- [ ] ノードロックは必ずLock All（または意図的アンロック）で行い、手前ノードの歪みまで確認する。Compare Nodesで「GTO→エクスプロイトで変わる層」を覚える。
- [ ] GTO Wizard AIのFixed使用時はレイズ/リレイズ枝の欠落チェックを習慣化し、ツリー不備による歪んだ結論を鵜呑みにしない。
- [ ] Range Builder／トレーナーで「閲覧→実打→採点」のループを作り、Close Decisions・Hand Class絞り込みで境界ハンドを反復、Blunderから優先的に潰す。

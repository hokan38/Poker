## Part 1: 週刊均衡 Stage1「Call判定均衡思考」完全版

Stage1シリーズは「**ベットを受けたときに、あるハンドを call するか fold するか**」を、感覚でなく均衡（レンジ）思考で判定する“型”を、1-1から1-5まで段階的に育てていく連載。ここでは購入済みの **1-2〜1-5** を、1-1のおさらいから積み上げる形で整理する。

### 基礎の3ステップ（Stage1-1のおさらい）

call/fold判定の均衡思考の骨格。**ハンド単体の絶対強度で判断しない**のが出発点。

1. **Step1**：打たれた **bet size** から、自レンジ全体で降りるべき **fold頻度** を決める。
2. **Step2**：**自レンジ**を捕捉し、**弱いハンドから順に**「降り群」を選ぶ。
3. **Step3**：**自分の実ハンド**がその降り群に入るかで call/fold を決める。

注目点は Step1=size, Step2=自レンジ, Step3=自ハンド。**どこにも相手レンジが出てこない**（1-2で理由を掘り下げる）。

### Stage1-2：3bp と「相手レンジを見ない」原則／MDF・α

**扱うスポット**：3bet pot の Flop で CB に直面。3bpはPF時点で双方のレンジがSRPより狭いので、役単体でなく**レンジ意識**が重要。

**核心1：均衡のcall/fold判定で相手レンジ・戦略を語るのは基本的に誤り。**
- 均衡には強い前提「**相手のレンジはバランスが取れている**」が成立している。だから自分は「**降りすぎず・callしすぎず**」機械的に自レンジを守るだけでよい。
- 相手レンジから「相手は強い/弱い」と推論して call/fold を決めるのは、均衡思考としてはNG（それはExploit=後のLevelの話）。

**核心2：bet sizeごとの適正fold頻度（MDF / α）。**
- **MDF**（Minimum Defense Frequency, 最小防御頻度）＝数学的に守るべき頻度。**α**＝数学的に降りるべき頻度（＝1−MDF＝ベット額÷(ベット額+ポット)）。
- 例：**50%ベット → MDF 67% / α 33%**（＝33%を降りる）。
- ただし実戦では **MDFほど守らない（＝MDFより多く降りる）** ことがほとんど。ざっくり **40%前後降りる**イメージで判断すると実践的なボードが多い（この例題も均衡fold頻度は約35.5%とαより高め）。

**核心3：3bpのレンジ構成を暗記して、構成的にfold頻度を作る。**
- 3bpのコールレンジ（例：222でHJ call vs BTN 3bet）の内訳の目安：
  - **Ahi・Khi ≒ 40%**
  - **ポケット ≒ 50%**
  - スーコネ等 ≒ 10%
- 例：Ahi/Khiを全部降りても40%のfold頻度にしかならない。ボードにドロー（FD/BDFD）があれば Ahi/Khi の一部（≒10%）は守るので、**残りのfold頻度はポケットから捻出**（≒10%）する、という構成的な組み方をする。
- 補足：3bpのポケットは、**色持ちをcallしておくとset完成時にフラッシュのないボードになりやすい**という性質が価値の主因（フラッシュ完成自体が狙いではない）。

> 誤答の典型：3bpの99を「降りたら降りすぎ」と過大評価してcallする。実際は均衡が99を**pure fold**しているケースがある＝3bpでの99（自レンジ内での相対的強さ）を誤認している。

### Stage1-3：EQ差 と オーバーフォールドの正当化

**扱うスポット**：EP（特に2bb open）vs BB。EPの小さいopenにBBが広く守るため、post戦略に歪みが出る。

**核心：レンジEQ差が大きいスポットでは、αより大きくオーバーフォールドしてよい（すべき）。**
- 同じボード・同じハンド（AT）でも、**相手のポジションが違えばcall/foldが変わる**。相手が強いレンジ（UTG）なら、BTN相手にcallできるATがUTG相手には fold になる。
- 比較例：
  - **BB vs BTN**：相手レンジEQ ≒ 53% → fold頻度 ≒ 30%（Stage1-2の適正域）
  - **BB vs UTG**：相手レンジEQ ≒ 60% → fold頻度 ≒ **40%**（αは25%なので驚くほど多い）
- 理屈：**そもそも負けている（EQ劣勢の）状態で無理にdefenceする必要はない**。EQ差が大きいほど、MDF/αをそのまま使わずオーバーフォールドが肯定される。

**レンジEQ差が生まれる2要因：**
1. **前ストリート終了時点でEQ差がもともと極端に大きい**（EP vs BB はこちら。open 2bbでBBが弱いハンドをPFで持ち越すため）。
2. **ボードが片方に味方した**ためにEQ差が発生。

**Step1の更新**：`Step1. bet sizeからfold頻度を判定（**EQ差を考慮**）`。

### Stage1-4：Turn/River と「持ち越しレンジ」

**扱うスポット**：Turn/River。前ストリートのactionで双方のレンジに歪みが乗っている。

**核心：Turn/Riverのcall/foldは、自分が“そのストリートまでにどんなレンジを持ち越したか”に大きく左右される。**
- レンジ全体のfold頻度推定は正しくても、**役ごとの内訳を読み違える**と誤答する。
- 例：Turnで自レンジのTop pair（Ahit）が18%を占めるなら、それらを守れば Second pair（Khit）は半分ほど降りてよい。ところが「Flopで33%betにcallした自レンジにAhitがどれだけ残っているか」を過小評価すると、Khit（KhJc等）を過剰にcallして誤る。
- **PFから現在までの自レンジの変化を正確にトレースする**ことが要。

**研究：bluff catchの優先順位。**
- 相手（BTN）が例えばAJをvalue下限に125%betしている場合、BB側でそれより弱いKhitは**軒並みブラフキャッチャー**になる。
- このとき各Khitは「相手のブラフには勝つがvalueには負ける」点で**平等**。だから**キッカーの高い順に優先callするのではなく、blockerで判定する**のが主。

**Step2の更新**：`Step2. （現状の）自レンジを捕捉し、弱い順にfoldを選ぶ`。

### Stage1-5：Shift（ボードによるレンジ進展）

**扱うスポット**：Turn/Riverで、双方のレンジ像を大きく変えるカードが落ちた局面。**Stage1-4の発展版**。

**核心：shift＝前ストリートで持ち越したレンジの“弱い部分”が、落ちたカードで強化される現象。**
- 例：BBがTurn 125%betに対して「ただの1pair」は全fold、**最低でもガットショット付きの1pairからcall**している。River K が落ちると、これら弱い部分が一斉に役を進める：
  - K9 → 2pair、QJ → straight、56ss → flush …と「shiftした」。
- 結果、**BBのレンジ下限が引き上がり**、River時点でBBの最弱役が Two pair になる。だから **set が“下から数えた方が早い”ほど弱い役に成り下がる** → 例題の99は pure fold。
- 誤答の典型：「BBのレンジに1pairが残っている」前提で bluff catch を組む。実際にはshiftで1pairが消えている。

**Step2の再更新**：`Step2. **shiftに気を付けて**現状の自レンジを捕捉し、弱い順にfoldを選ぶ`。

### 完成版フレームワーク

Stage1-1〜1-5をかけて育てた **call判定均衡思考の完成形**：

1. **Step1**：bet size から fold頻度を判定する。**（EQ差を考慮してオーバーフォールド調整）**
2. **Step2**：**shiftに注意して現状の自レンジ**を捕捉し、**弱いハンドから順に** fold群を選ぶ。**（PF→現在のレンジ変化を想起）**
3. **Step3**：自分の実ハンドが fold群に入るかで call/fold を決める。

この手順を踏めば、ほぼ全スポットで均衡のcall/fold判定を正しく行える、というのがStage1の結論。**次のStage2からは「Value判定均衡思考」**（打つ/打たない側）に進む予定。

**学習の進め方（著者推奨）**：GTO Wizardのトレーナーで多数のボードを自作し、各スポットのレンジ全体call/fold頻度と「どのハンドが降り群か」を反復。MDF/αは日本語文献も多いので発展的に確認（例：GTO Wizard の "mathematical misconceptions in poker"）。

## Part 2: Amu「Flop CBの基礎 (BTN vs BB)」

中級者向け、**BTN vs BB SRP** の Flop CB（コンティニュエーションベット）を体系化した高額テキスト（¥3,980）。CO vs BB でも多くのボードで援用可。

### 全体像と学習ゴール

- **ゴール**：GTO Wizard **100bb General GTO-GTO** の全FlopのCB解を、**Exploitされない精度で再現・暗記**できるようになること。Exploitではなく、Exploitを語る前提としての“均衡の型”。
- 構築は2段階：
  - **Step1**：ボードを見た瞬間に「**使うサイズ候補と各頻度**（＝レンジ全体のCB戦略）」がわかる。
  - **Step2**：その戦略を「**どのハンドにどう振り分けるか**」がわかる。
- 均衡実践の思考順：**Step2に到達するまでハンドの中身は忘れて、レンジのバランス（Exploitability）に注目**する。
- **サイズ候補は 33% / 50% / 75% / 125%（potover）** の4つ。

### Step1：ボードのClass分類（7種＋Connected）

ボードを**特殊系**と**標準系**に分け、標準系はハイカードでさらに分類。3枚を高い順に **H / M / L** と表記。標準系のA〜Jhiボードは **HM（Hi-Middle）でストレートドローの有無** により HMSD / HMnSD に分ける。**事実上7種（Connected込みで14種）を暗記すればFlop CBが完結**。

| Class | ボード種別 | CB戦略の要点（頻度は目安） |
|---|---|---|
| **1** | monotone（3枚同スート） | **低頻度で安ベット**。33%を約25% / 50%を約5%。 |
| **2** | trips（3カード） | OriginalのEVが高く**レンジCB**。vs BB SRPは基本CB100%。range 33% or 50%。（999↑は33/50、888↓は50/75寄り） |
| **3** | pair（ペアボード） | **レンジ33%bet**でOK。33%を約50% / 50%を約15%（著者は実戦で約70%を33%betに単純化）。補足：2pair/3pairはもう一枚がlowなほど50/75増、AXXはCB頻度やや低、AAX/KKXは高。 |
| **4** | A〜Jhi **HMSD** | **125%(potover)が選択肢に入るpolarボード**。HM強度で傾斜。 |
| **5** | A〜Jhi **HMnSD** | いわゆる「Khiボード」型で**安く打て**。33%:50% ≒ 35%:20%。 |
| **6** | Thi / 9hi | **全ボード全サイズ混合**（Class4の中HMと同じ）。33:50:75:125 ≒ 15:10:10:15。 |
| **7** | u8（8hi以下） | 超高確率でConnect。基本3サイズ混合 33:50:75 ≒ 15:15:15、Connectedなら 33:50 ≒ 30:15。 |

**Class4のHM傾斜**（A〜Jhi HMSD）：
- **強HM**（AK, AQ級の超2hi）：33:50:75:125 ≒ 0:0:0:50（**125%only寄りのpolar**）
- **中HM**（KJ, Q9級）：≒ 15:10:10:15
- **弱HM**（Q8, J7級・ギリギリ条件を満たす）：≒ 15:15:15:5（125%はあまり使わない4サイズ混合）
- Bluff側は直感より多めに含める必要あり。

**Connectednessの概念**（スパイス的な補正、判定は最初に行う）：
- Connected＝Flop時点で何らかの2枚でストレート完成の可能性がある（レンジ内外問わず）。例：T76はConnected、AJ8は非Connect。
- Connectedなら：**potoverを候補から外す／安いbetを好む／bet頻度を少し高めに見積もる**。

**分類例**：AhJs2s → monotoneでもpairでもない＝標準系、Ahiだから A〜Jhi、HM=AJでストレートドローあり＝**HMSD（Class4）**。

### Step2：ハンド振り分けの方針

**基本方針の2系統：**
- **安bet主体のボード**（Class1/3/5/7）：まず**レンジのCB頻度を全ハンドに一律配分**し、そこから**頻度調整**（強いバリュー/ドローを上げ、弱いSDVを下げる）。
- **3サイズ以上混合のボード**（Class4 mix / 6）：
  - **A type**＝全サイズ混合（レンジのCB頻度に準拠）
  - **B type**＝最大サイズ基調の全サイズ混合（超高頻度bet）
  - **C type**＝安bet or check（超低頻度bet）
  をベースに組む。

**Class1（monotone, 例J85）**：Baseを30%CB率とし、
- **バリュー高頻度群**：Nuts FD / 2nd Nuts FD / set / overpair（rank低いほど）/ Top2pair。
- **ブラフ高頻度群**：Nuts FD / 2nd Nuts FD / straight draw / Hi-Low suited。monotoneはスーテッド関係なくある程度打つ。
- **激低頻度群（≒check可）**：SDVはあるがバリューに入らない hit系・ポケット。
- 覚え方：**monotoneのバリュー＝tophit good kicker以上**。

**Class3（pair）**：まず全ハンド等頻度で打つ。余裕が出たら加点・減点で微調整：
- Trips +3 / 2pair good kicker・set +2 / SD+overcard +1 / A-Middleのhitなし −1 / ボードに色のないハイカード持ち −1 / XXYペアボでYの直上に近い +2〜+1・直下に近い −1。高得点は頻度↑、減点は頻度↓。

**Class4 polar**：**バリュー＝tophit good kicker以上**。カテゴリ上位ほど高頻度、下位ほど低頻度でpotover。ブラフは直感より多く。例外：topのみ色違いのtt系はtophit FDが高頻度で入る。

**Class5（A〜Jhi HMnSD, 例K63）**：Baseを55〜60%CB率として頻度調整。
- **tophit**：キッカー準拠で傾斜（良いほど高頻度）。
- **middle/bottom hit**：キッカーにあまり依存せずレンジ頻度で。ただしtop kickerは高頻度。
- **ポケット**：rankが低いほど頻度↓。
- **色補正**：hi色持ち＝高評価、low色持ち＝中評価、色なし＝低評価。
- 補足：HMが低いほど大きいサイズが出る（J32/J42は例外的に125%も、J65は75%が50%と同頻度級）。Qhi/Jhiはhmによらず全サイズ混合になりやすい。

**Class6（Thi/9hi）**：Class4のhiが低い(mix)と同一に扱い、A/B/C typeで構築。Mが678付近だと125%が消えやすく、HMがhiだと33%が消えやすい。

**Class7（u8）**：基本はClass5準拠。**overpairが多い**のが特徴（直上のものほどbet頻度↑）。KQ等はtophi-middle kickerが低頻度なところにKhi top kickerが追加される。

**まとめ方の指針**：ボードを見た瞬間に「**サイズ候補と頻度**（Step1）」→「**ハンド振り分け**（Step2）」が出るのが理想。記事に載っていないボード（AJXr等）や、スート振り分けの細部は、この型をベースに自分で GTO Wizard で埋めていく。BB 3betのCB（特にnon-linearな3bet）は難度が上がる良い練習台。
